# Chr拡張入力の変換契約

XL-228で0〜65535の代表境界をExcel実機照合し、Chr/Chr$とString/String$の受理後の
文字コード写像を共通ヘルパーへ統合した。CP932の254/255、256超の高位バイト、
AscWの符号付き結果を回帰テストで固定した。ChrW/ChrW$は対象外として別評価に残す。
