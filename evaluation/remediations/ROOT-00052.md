# Chr拡張入力の変換契約

今回の直接修正は、Excel実機で確認した255超入力をChr/Chr$が受理する範囲に限定した。
受理後にどの文字コードへ変換するかは別責務であり、String/String$の既存変換差と
混同しない。追加の実機境界を収集してから共通化の要否を判断する。
