# 冪乗演算子とLongLongサフィックスの分類統一

数値リテラルの直後に現れる `^` は、後続トークンが冪乗の右辺を開始する場合は
演算子としてLexerからParserへ渡し、それ以外の式区切りではLongLongサフィックスとして
消費する。Currency演算の未実装は別のEvaluator対処で扱う。
