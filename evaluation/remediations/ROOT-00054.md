# 冪乗演算子とLongLongサフィックスの分類統一

数値リテラルの直後に現れる `^` は、前に空白がある場合は冪乗演算子としてLexerから
Parserへ渡し、隣接している場合はLongLongサフィックスとして扱う。サフィックス後に
括弧や別のリテラルが続く場合は、Parserが不正な隣接として拒否する。Currency演算の
未実装は別のEvaluator対処で扱う。
