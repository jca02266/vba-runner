# FileSystemコピー異種別衝突契約の共通化

Nodeの`fs.cpSync`へ到達する前にsource種別と相対パスごとのdestination種別を検査し、
MemoryFileSystemと同じEEXIST/ENOENT契約へ正規化する。既存の正常コピーと衝突時の
部分変更なしを回帰テストで維持する。
