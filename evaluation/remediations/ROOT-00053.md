# VBA Dateシリアル変換のTZ依存除去

暦日をVBAシリアルへ変換する層と、ホストの現在時刻・外部時刻を表す層を分離する。
JavaScriptのローカルepoch差分を使わず、暦日要素から決定的にシリアルを計算し、
復元時も同じ不変条件を保つ。
