# 逐次Lock境界の共通責務

逐次モード固有の全体ロック正規化へ入る前に、VBAの範囲引数を検証する責務を置く。
Excel実機で未確認の追加境界はこの対処範囲に混ぜず、別の照合候補として管理する。
