# CDec・CCur短桁基数パターン修正

CDecとCCurでは16ビット幅の短い基数パターンを符号付き整数として拡張せず、
32ビット以上の完全なパターン幅でのみ符号拡張する。Valなど他の変換入口は
この修正の対象外とし、RC-00010の型別ポリシー検討へ残す。
