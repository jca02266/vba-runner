# クラスインスタンスのEnvironment境界分離

クラスインスタンスのEnvironmentが呼出元の一時Environmentを親にしていたため、
クラスに存在しない同名フィールドがcallerの変数へフォールスルーしていた。
安定したmodule/global環境を親にし、クラス固有のメタデータ取得・イベント判定・
書き込みをown scopeへ限定した。
