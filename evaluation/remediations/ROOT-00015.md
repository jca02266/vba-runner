# Object引数契約の共通化タスク

RC-00033で確定した、ModuleとClassで異なるObject引数検証とOptional Object既定値処理を、
宣言型に基づく単一のバインド境界へ統合する。VariantのOptional Missing契約は維持し、
host/COM参照を値型へ誤変換しないことを回帰で固定する。
