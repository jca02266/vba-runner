# Select CaseのEmpty文脈変換

独立評価で、Variant `Empty` が `Case 0` と一致せず `Case Else` に進む問題を
再現した。`Case ""` も同様だった。`evaluateSelectCaseStatement` の等価比較に、
相手が文字列なら空文字、数値文脈なら0へ変換する処理を追加し、回帰テストで
expressionと`Case Is <>`を確認した。数値文字列やNullの実Excel仕様は未確定のため、
今回の修正範囲には含めていない。
