## 評価内容

ネストした手続き呼び出しでの`Err.Raise`伝播が、`On Error GoTo`と`On Error Resume Next`で一貫するかを確認する。

## 実施方法

```vba
Function Inner() As String
    Err.Raise 11
End Function

Function Outer() As String
    On Error GoTo Handler
    Outer = Inner()
    Exit Function
Handler:
    Outer = "ERR:" & CStr(Err.Number)
End Function

Function OuterResume() As String
    On Error Resume Next
    Call Inner()
    OuterResume = "ERR:" & CStr(Err.Number)
End Function

Function Probe() As String
    Probe = Outer() & ";" & OuterResume()
End Function
```

## 期待値

プログラム上の期待出力: `Probe()` は`ERR:11;ERR:11`を返す。

文章での期待: 内側の実行時エラー11は、外側の`On Error GoTo`ではハンドラへ伝播し、`On Error Resume Next`では呼び出し側のErrに保持される。

## 結果

プログラム上の実測出力: `Probe()`は`ERR:11;ERR:11`を返した。独立プローブでも`Inner()`のエラー番号は11として伝播した。

文章での結果: `On Error GoTo`と`On Error Resume Next`の隣接経路でエラー番号11の伝播が一致し、不整合は再現しなかった。

## 判定

判定状態: verified-no-bug（調査したネストエラー伝播の範囲で不具合なし）。
