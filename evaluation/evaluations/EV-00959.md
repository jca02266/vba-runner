## 評価内容

同名のPrivate変数を異なる型で複数モジュールに定義し、モジュールのロード順を変えても各手続きが自モジュールの型情報を参照できるか確認する。

## 実施方法

次の2モジュールをA→B、B→Aの順でロードし、それぞれのPrivate変数のVarTypeとTypeNameを取得する。

```vba
' ModuleA
Option Explicit
Private x As Long
Public Function ProbeA() As String
    ProbeA = CStr(VarType(x)) & ":" & TypeName(x)
End Function

' ModuleB
Option Explicit
Private x As String
Public Function ProbeB() As String
    ProbeB = CStr(VarType(x)) & ":" & TypeName(x)
End Function
```

## 期待値

期待出力：ロード順に関係なくAは`3:Long`、Bは`8:String`。Private宣言の型情報はモジュールスコープに属し、同名であっても他モジュールの宣言に影響されないと仮説する。

## 結果

実測出力：A→Bでは`8:String / 8:String`、B→Aでは`3:Long / 3:Long`。後からロードしたモジュールの型情報が先行モジュールを上書きし、期待したモジュール分離が崩れていた。

## 判定

判定状態: bug-found

ロード順による型情報汚染を再現した。直接原因と設計上の真因仮説を登録し、修正と回帰テストを行う。
