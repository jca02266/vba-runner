## 評価内容

`ByRef Long`へ、関数戻り値、数値リテラル、括弧付き式を渡す経路を比較し、
ランナーが一時値として扱う境界とExcelの実際の受理・エラー契約を確認する。

## 実施方法

次の最小ソースをランナーとExcelで実行する。

```vba
Sub TakeLong(ByRef value As Long)
    value = value + 1
End Sub

Sub Probe()
    On Error Resume Next
    Err.Clear: TakeLong CLng(10)
    Debug.Print "FUNCTION ERR=" & CStr(Err.Number)
    Err.Clear: TakeLong 10
    Debug.Print "LITERAL ERR=" & CStr(Err.Number)
    Err.Clear: TakeLong (10)
    Debug.Print "PAREN ERR=" & CStr(Err.Number)
End Sub
```

## 期待値

Excelで各呼出しが受理されるか、ByRef型不一致または別の引数エラーになるかを
個別に記録する。括弧付き式は一時値化されるという既知契約と、関数戻り値・
リテラルの非LValue契約を分離して判定する。

## 結果

実測出力（vba-runner）：

```text
FUNCTION ERR=0
LITERAL ERR=0
PAREN ERR=0
```

文章による結果：ランナーは3経路を一時値として受理し、呼出し元への書戻しを
行わない。Excelの同一ソース結果は未確認である。

## 判定

判定状態: needs-excel-probe

ランナー側の挙動は記録したが、Excelの非LValue ByRef境界を確定できていないため、
現時点でバグまたは仕様一致とは判定しない。
