## 評価内容

ホストからVariantへ渡されたJavaScriptの`true`が、組み込み変換と算術で同じVBA Boolean値として扱われるか確認する。

## 実施方法

```vba
Function ConvertInt(value As Variant) As Long
    ConvertInt = CInt(value)
End Function
Function ConvertLong(value As Variant) As Long
    ConvertLong = CLng(value)
End Function
Function AddZero(value As Variant) As Long
    AddZero = value + 0
End Function
```

各手続きへホスト値`true`をVariant引数として渡し、戻り値を比較する。

## 期待値

プログラム上の期待出力: `ConvertInt(true) = -1`、`ConvertLong(true) = -1`、`AddZero(true) = -1`。
文章での期待: 同じVariant値を受ける変換経路と算術経路で、VBAのTrue値`-1`が一致する。

## 結果

Runner実測出力: `ConvertInt(true) = 1`、`ConvertLong(true) = 1`、`AddZero(true) = -1`。
Excel実機確認: 対象はExcel内部のBooleanではなくRunner公開APIから注入されるホスト値の契約であるため不要。

## 判定

判定状態: fixed（数値変換の共通経路を修正し、回帰テストを追加）。
