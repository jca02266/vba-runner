## 評価内容

VBE形式のProductクラスで、クラスレベルPrivate Constを各メンバーから参照したときのOption Explicit診断を確認する。

## 実施方法

```vba
VERSION 1.0 CLASS
Attribute VB_Name = "Product"
Option Explicit
Private Const MIN_PRICE As Long = 1
Public Sub Verify()
    Dim value As Long
    value = MIN_PRICE
End Sub
```

## 期待値

期待出力: `MIN_PRICE`に対する未宣言診断 0件。
クラスレベルのPrivate Constは同一クラスの手続きから参照できるため、Option Explicitは宣言済みとして扱う。

## 結果

実測出力: 修正前は `Variable 'MIN_PRICE' not declared` が2件、修正後は0件。
`ClassDeclaration.body`に格納されたConstをクラス宣言集合へ追加する修正後は0件。

## 判定

判定状態: fixed

クラス内Constの収集漏れによるLSP誤診断を再現し、回帰テストを追加した。アクセススコープ保持は別候補へ分離した。
