# EV-00800の再評価

## 評価内容
Property LetのOptional引数と名前付き指定を、通常SubのOptional ByRef結果と混同せず再評価する。

## 実施方法
次の自己完結したVBAソースを実行し、Property LetでOptional添字の省略と
名前付き指定を確認する。

```vba
Class OptionalPropertyBox
    Private total As Long
    Public Property Let Item(Optional index1 As Long = 0, Optional index2 As Long = 0, ByVal value As Long)
        total = index1 * 100 + index2 * 10 + value
    End Property
    Public Function Read() As Long
        Read = total
    End Function
End Class

Function VerifyOptionalProperty() As String
    Dim box As New OptionalPropertyBox, errNo As Long
    On Error Resume Next
    box.Item(, 2) = 3
    errNo = Err.Number
    VerifyOptionalProperty = "pos=" & CStr(errNo) & ":" & CStr(box.Read())
    Err.Clear
    box.Item(index2:=2) = 3
    VerifyOptionalProperty = VerifyOptionalProperty & "|named=" & CStr(Err.Number) & ":" & CStr(box.Read())
End Function
```

## 期待値
プログラム上の期待出力: `pos=0:23|named=0:23|value=0:3|setnamed=0:20|setvalue=0:0`

省略された添字の既定値と名前付き指定が保持され、value引数の実効ByVal規則も維持される。

## 結果
プログラム上の実測出力: `pos=0:23|named=0:23|value=0:3|setnamed=0:20|setvalue=0:0`

Property Let/Set専用ケースでOptional省略と名前付き指定が成功し、添字の既定値と指定値が保持された。

## 判定
判定状態: `verified-no-bug`

Property Let/Set専用の実測値が期待値と一致したため、新規バグなしと判定する。
