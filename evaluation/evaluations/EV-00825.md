## 評価内容

引数を宣言していないFunctionを、1個の引数付きで呼び出す境界を確認する。
必須引数省略のコンパイルエラーとは異なり、余分な引数の扱いを評価する。

## 実施方法

```vba
Function MyFuncNoArg()
End Function

Sub Case_function_call_with_excess_argument_runtime()
    Dim value As Variant
    On Error Resume Next
    Err.Clear
    value = MyFuncNoArg(1)
    Debug.Print "CASE=function_call_with_excess_argument_runtime ERR=" & CStr(Err.Number)
    On Error GoTo 0
End Sub
```

同じ境界をRunnerではFunctionの引数数行列で実行し、実行時エラー13を確認する。

## 期待値

期待出力: `Err.Number = 13`

説明上の期待値: VBEのコンパイル時には拒否されず、実行時に「型が一致しません。」
となる。

## 結果

実測出力: `CASE=function_call_with_excess_argument_runtime ERR=13`

Runner結果: Functionの余分な引数を実行時のType mismatchとして返した。

## 判定

判定状態: verified-no-bug

ExcelとRunnerのエラー段階およびエラー番号が一致した。
