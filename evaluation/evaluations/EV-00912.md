## 評価内容

Parser・Lexerの低収束領域から、日付リテラルのVBA最小年境界と時刻ゼロの組み合わせを評価する。

## 実施方法

次の自己完結VBAを評価する。

```vba
Public Function Probe100() As Date
    Probe100 = #1/1/100#
End Function

Public Function Probe101() As Date
    Probe101 = #1/1/101#
End Function
```

戻り値のDateシリアル値を取得し、日付部分と時刻部分を確認する。

## 期待値

期待出力: `Probe100` は `100/01/01 00:00:00`、`Probe101` は `101/01/01 00:00:00` となり、時刻部分のシリアル値は両方とも `0`。
日付リテラルは指定した暦日を表すため、実行ホストの歴史的タイムゾーンの時刻が混入してはならない。

## 結果

実測出力: `Probe100` のシリアル値は `-657434.0131828703`、`Probe101` は `-657069.0131828703` となり、両方に `00:37:58` 相当の小数が混入した。
`evaluateDateLiteral` が `new Date(year, month, day)` を使用し、ホストのローカルタイムゾーン規則を歴史的日付へ適用している。
