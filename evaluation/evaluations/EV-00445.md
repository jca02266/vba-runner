# ParamArray・CallByName opaque配列relay境界

ParamArray内でVariantとして保持されたopaque配列をtyped binderへ再渡しする経路を
検証した。標準Module、Class Property Let、CallByName VbLetはいずれも共通validatorを
通り、metadataなしprimitiveはError 13、Variant()は受理された。
