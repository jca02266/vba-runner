# SetAttr Directory属性境界

通常ファイルへ`SetAttr "x.txt", vbDirectory`を実行すると、修正前runnerはError 0
だった。VBAではDirectoryはSetAttrで設定できずError 5である。属性保存前の共通入口
でDirectory bitを検証し、Error 5へ変換した。回帰テストを追加した。
