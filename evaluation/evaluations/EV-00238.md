# Append複数ハンドルの追記位置

独立評価で、同一ファイルをAppend Sharedで開いた2ハンドルのうち、MemoryFileSystemでは
2回目の追記が1回目を上書きする不具合を再現した。Append書込み時に物理末尾を再計算し、
Node O_APPENDと同じ追記動作および論理位置更新を回帰テストで固定した。
