# Resume遷移とエラーハンドラ境界

## 評価内容
Resume labelの再開位置と、アクティブなエラーがないResumeのError 20を確認する。

## 実施方法
```vba
Function VerifyResume() As String
    Dim value As Long, errNo As Long
    On Error GoTo Handler
    value = 1
    Err.Raise 5
    value = value + 10
Done:
    VerifyResume = CStr(value) & ":" & CStr(errNo)
    Exit Function
Handler:
    errNo = Err.Number
    Resume Done
End Function

Function VerifyInactiveResume() As Long
    Dim errNo As Long
    On Error Resume Next
    Resume Next
    errNo = Err.Number
    VerifyInactiveResume = errNo
End Function
```

## 期待値
プログラム上の期待出力: `VerifyResume = 1:5`、`VerifyInactiveResume = 20`

## 結果
プログラム上の実測出力: `VerifyResume = 1:5`、`VerifyInactiveResume = 20`

## 判定
判定状態: `verified-no-bug`

Resume labelは指定位置へ再開し、アクティブなエラーがないResumeはError 20となり、期待値と一致した。
