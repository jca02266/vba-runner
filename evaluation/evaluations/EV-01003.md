## 評価内容

Event宣言とRaiseEvent発火側の引数個数が一致しない場合に、Runnerが静的診断するかを確認する。

## 実施方法

```vba
' Source.cls
Option Explicit
Public Event Ping(ByVal firstValue As Long, ByVal secondValue As Long)

Public Sub Fire()
    RaiseEvent Ping(1)
End Sub

' Module1.bas
Option Explicit
Public Function Caller() As Long
    Dim source As New Source
    source.Fire
    Caller = 1
End Function
```

クラスをロードして診断を取得し、`Caller`を実行する。引数を2個にした一致対照も確認する。

## 期待値

プログラム上の期待出力: `RaiseEvent Ping(1)`は宣言の2引数契約に違反するためコンパイル診断となり、`Caller`は実行されない。

文章での期待: RaiseEventは対象Eventの位置引数リストと互換でなければならず、引数個数不一致はイベント発火前の静的検査で拒否される。

## 結果

プログラム上の実測出力: Runnerのロードは成功し、診断は`[]`、`Caller`は`1`を返した。Eventにハンドラーがない場合でも不一致を検出しなかった。

文章での結果: `evaluateRaiseEventStatement`がEvent宣言を解決せず、引数個数を比較しないため、仕様上不正な発火を実行可能として扱っている。

## 判定

判定状態: bug-found。

独立評価は最小クラスで診断空配列と実行値1を再現した。横展開では引数過少・過剰、ByRef/ByVal不一致、型不一致のEventハンドラーも同じ契約検査を欠くことを確認した。独立RCA提案と反証レビューはEvent契約の静的検査欠落を支持したが、Excelの正確な診断時期・エラー番号、ホストの再入・スケジューリングは未確定とした。RC-00124は未確定仮説として登録した。
