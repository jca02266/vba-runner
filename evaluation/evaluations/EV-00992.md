## 評価内容

Private Typeを宣言したモジュールとは別のモジュールで、同じ型名を非修飾で`Dim`に使用した場合の可視性を確認する。

## 実施方法

```vba
' ModuleA
Option Explicit
Private Type T
    X As Long
End Type
Public Function OwnType() As Long
    Dim value As T
    value.X = 22
    OwnType = value.X
End Function

' ModuleB
Option Explicit
Public Function CrossType() As Long
    Dim value As T
    value.X = 7
    CrossType = value.X
End Function
```

`ModuleA.OwnType`と`ModuleB.CrossType`を実行し、同一モジュールと別モジュールの型名解決を比較する。

## 期待値

プログラム上の期待出力: `OwnType`は`22`を返し、`CrossType`はPrivate Typeを参照できずコンパイルエラーになる。

文章での期待: Private Typeの宣言範囲は所有モジュールに限定され、別モジュールの型解決で暗黙に利用可能にならない。

## 結果

プログラム上の実測出力: Runnerは`OwnType=22`、`CrossType=7`を返した。

文章での結果: 同一モジュールの型解決は正しいが、別モジュールのPrivate Typeが非修飾で解決され、値を返す不一致を再現した。

## 判定

判定状態: fixed（Private Typeのモジュール境界を修正し、回帰確認済み）。
