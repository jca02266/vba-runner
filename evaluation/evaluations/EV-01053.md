## 評価内容

UDTメンバー配列境界に`Double`のConst値`1.5`を指定し、LongへのLet-coercionを評価する。

## 実施方法

```vba
Const LAST_INDEX As Double = 1.5
Type IndexedRecord
    Values(LAST_INDEX) As Integer
End Type

Function RunCase() As Long
    Dim record As IndexedRecord
    RunCase = UBound(record.Values)
End Function
```

## 期待値

期待出力：`2`

境界値`1.5`をVBAのLongへ丸めた`2`が上限になる。

## 結果

修正前の実測結果：`Compile error: Invalid array bound`

修正後の実測出力：`2`

## 判定

判定状態: fixed

UDT専用の`Number`・整数判定を、通常配列と共有するLong変換・境界検証へ置き換えた。
