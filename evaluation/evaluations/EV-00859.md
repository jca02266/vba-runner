## 評価内容

FV、PV、PMTで修正した線形結合の中間Overflow問題が、IPMT、PPMT、NPV、NPer、Rate、MIRR、DDBにも存在するかを確認する。

## 実施方法

既存の金融関数テストへ、各関数の大値・キャンセル・不正領域境界を追加せず、評価専用の最小ソースとして次をRunnerで実行する。

```vba
Sub ProbeFinancialExpansion()
    Dim huge As Double, value As Double, errNo As Long, flows As Variant
    huge = 1E+308
    flows = Array(-huge, huge)
    On Error Resume Next
    Err.Clear: value = IPmt(0.5, 1, 2, huge, 0, 0): errNo = Err.Number
    Debug.Print "IPMT ERR=" & CStr(errNo)
    Err.Clear: value = PPmt(0.5, 1, 2, huge, 0, 0): errNo = Err.Number
    Debug.Print "PPMT ERR=" & CStr(errNo)
    Err.Clear: value = DDB(huge, 0, 2, 1, 2): errNo = Err.Number
    Debug.Print "DDB ERR=" & CStr(errNo)
    Err.Clear: value = NPV(0.5, flows): errNo = Err.Number
    Debug.Print "NPV ERR=" & CStr(errNo)
    Err.Clear: value = NPer(0.5, -huge, huge, 0, 0): errNo = Err.Number
    Debug.Print "NPER ERR=" & CStr(errNo)
    Err.Clear: value = Rate(2, -huge, huge, 0, 0, 0.1): errNo = Err.Number
    Debug.Print "RATE ERR=" & CStr(errNo)
    Err.Clear: value = MIRR(flows, 0.1, 0.1): errNo = Err.Number
    Debug.Print "MIRR ERR=" & CStr(errNo)
    On Error GoTo 0
End Sub
```

## 期待値

期待出力:

```text
IPMT ERR=0
PPMT ERR=0
DDB ERR=0
NPV ERR=0
NPER ERR=0
RATE ERR=5
MIRR ERR=0
```

プログラム上の期待値: 数学的に有限な結果はError 0、真に範囲外または領域不正な入力だけが仕様に定められたError 5/6になる。

文章による期待値: FV・PV・PMTで修正した計算契約に反する中間Overflow経路を新たに検出しない。

## 結果

Runner実測出力:

```text
IPMT ERR=0
PPMT ERR=0
DDB ERR=0
NPV ERR=0
NPER ERR=0
RATE ERR=5
MIRR ERR=0
```

FV、PV、PMTで確認した中間Overflowと同じError 6差異は再現しなかった。
