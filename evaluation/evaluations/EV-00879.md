## 評価内容

`copyDirectorySync`について、空source、空の入れ子ディレクトリ、ファイルと空ディレクトリの混在、既存空宛先、既存ファイル・ディレクトリエントリとの衝突をMemoryFileSystemとNodeFileSystemで比較する。

## 実施方法

同じsource/destination構造を両バックエンドへ作成し、`overwrite: false`でコピーした後のディレクトリ構造とファイル内容を確認する。既存ファイル衝突ではエラー番号、既存内容、source保持を確認し、`overwrite: true`では上書き結果を確認する。

## 期待値

両バックエンドの出力が一致し、空source、空ディレクトリ、入れ子ディレクトリ、ファイル内容が保持されることを期待する。既存の空destinationは成功し、ファイルまたはディレクトリエントリの衝突時は`EEXIST`、既存内容保持、source保持となり、上書き時は新しい内容になる。

期待出力:

```text
Memory {"empty":true,"mixed":[true,true,true,"value"],"directoryCollision":"EEXIST","collisionState":["EEXIST","old",true],"overwriteState":["new"]}
Node {"empty":true,"mixed":[true,true,true,"value"],"directoryCollision":"EEXIST","collisionState":["EEXIST","old",true],"overwriteState":["new"]}
```

## 結果

実測出力:

```text
Memory {"empty":true,"mixed":[true,true,true,"value"],"directoryCollision":"EEXIST","collisionState":["EEXIST","old",true],"overwriteState":["new"]}
Node {"empty":true,"mixed":[true,true,true,"value"],"directoryCollision":"EEXIST","collisionState":["EEXIST","old",true],"overwriteState":["new"]}
```

空source、空ディレクトリ、入れ子ディレクトリ、混在ファイルの構造と内容が一致した。既存ファイルおよびディレクトリエントリの衝突では両バックエンドが`EEXIST`を返し、既存内容とsourceを保持した。`overwrite: true`でも両バックエンドが同じ内容へ更新した。

## 判定

判定状態: bug-found

空source、空ディレクトリ、入れ子ディレクトリ、混在ファイルの構造・内容とファイルエントリ衝突は一致した。一方、source側がディレクトリ、destination側が同名ファイルというディレクトリエントリ衝突では、MemoryFileSystemが`EEXIST`、NodeFileSystemが`ERR_FS_CP_DIR_TO_NON_DIR`となり、エラー契約が一致しなかった。この差異をBUG-00545へ記録する。
