## 評価内容

要素型メタデータを持たないCOM/host配列を、typed Long()とVariantの2つの代入先へ渡す。1次元と2次元の形状について、typed destinationの拒否とVariant destinationの値・次元保持を確認する。

## 実施方法

```vba
Function Probe() As String
    Dim source As Object, target() As Long, values As Variant, errNo As Long
    Set source = CreateObject("Test.NoMeta")
    On Error Resume Next
    target = source.Values
    errNo = Err.Number
    Probe = "T=" & CStr(errNo)
    Err.Clear
    values = source.Values
    errNo = Err.Number
    Probe = Probe & ";V=" & CStr(errNo) & ":U1=" & CStr(UBound(values, 1)) & ":U2=" & CStr(UBound(values, 2)) & ":X=" & CStr(values(0, 1))
End Function
```

`Test.NoMeta.Values`は要素型メタデータを付けない1次元`[7]`と2次元`[[1, 2], [3, 4]]`を順に返すhostモックとして評価する。

## 期待値

期待出力:

```text
1D: T=13;V=0:U1=0:X=7
2D: T=13;V=0:U1=1:U2=1:X=2
```

型情報のないopaque配列は、宣言型が必要なLong()へ安全に代入できないためError 13になる。一方Variantではopaque配列の値を保持し、未指定の下限を0として矩形のrankと上限を推定できる。

## 結果

実測出力:

```text
1D: T=13;V=0:U1=0:X=7
2D: T=13;V=0:U1=1:U2=1:X=2
```

要素型メタデータなしのtyped destination拒否と、Variant destinationでの値・次元推定は期待値と一致した。これはadapterがVARTYPEを供給しない場合に、Runnerがprimitive型を推測して誤って受理しない契約を満たす。

## 判定

判定状態: verified-no-bug。型メタデータなしのopaque配列をLong()へ渡した場合のError 13と、Variantへ渡した場合の値・次元保持は期待どおりだった。実COM SAFEARRAYのVARTYPEをadapterが付与する責務、および誤ったメタデータを供給した場合の契約は、Runnerの配列代入意味論とは別のadapter評価として扱う。
