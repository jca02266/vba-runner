## 評価内容

DateAddの負方向・正方向の日付移動、月末・閏日補正、DateDiffの負方向差分と日付・時刻境界を8ケースの行列で確認する。

## 実施方法

既存の`date-arithmetic-signed-boundary-matrix.test.ts`を実行し、DateAddの`d`/`q`/`yyyy`/`m`、DateDiffの`q`/`yyyy`/`d`を組み合わせる。各ケースのErr、型、日付または数値を出力する。

## 期待値

期待出力:

```text
DATE-MATRIX DateAdd("d", -1, #1/1/2024#) => 0|Date|31/12/2023
DATE-MATRIX DateAdd("d", 1, #12/31/2023#) => 0|Date|1/1/2024
DATE-MATRIX DateAdd("q", -1, #3/31/2024#) => 0|Date|31/12/2023
DATE-MATRIX DateAdd("yyyy", -1, #2/29/2024#) => 0|Date|28/2/2023
DATE-MATRIX DateAdd("m", -1, #3/31/2024#) => 0|Date|29/2/2024
DATE-MATRIX DateDiff("q", #3/31/2024#, #12/31/2023#) => 0|Long|-1
DATE-MATRIX DateDiff("yyyy", #2/29/2024#, #2/28/2023#) => 0|Long|-1
DATE-MATRIX DateDiff("d", #1/1/2024 00:00:00#, #12/31/2023 23:59:59#) => 0|Long|-1
```

## 結果

実測出力:

```text
DATE-MATRIX DateAdd("d", -1, #1/1/2024#) => 0|Date|31/12/2023
DATE-MATRIX DateAdd("d", 1, #12/31/2023#) => 0|Date|1/1/2024
DATE-MATRIX DateAdd("q", -1, #3/31/2024#) => 0|Date|31/12/2023
DATE-MATRIX DateAdd("yyyy", -1, #2/29/2024#) => 0|Date|28/2/2023
DATE-MATRIX DateAdd("m", -1, #3/31/2024#) => 0|Date|29/2/2024
DATE-MATRIX DateDiff("q", #3/31/2024#, #12/31/2023#) => 0|Long|-1
DATE-MATRIX DateDiff("yyyy", #2/29/2024#, #2/28/2023#) => 0|Long|-1
DATE-MATRIX DateDiff("d", #1/1/2024 00:00:00#, #12/31/2023 23:59:59#) => 0|Long|-1
```

8ケースすべてで期待値と実測値が一致した。

## 判定

判定状態: verified-no-bug

日付の符号、月末、閏日、四半期、年、日単位の境界に新しい差異は確認されなかった。
