# 先頭小数点浮動小数リテラルの評価

独立評価で、VBA仕様が許す`.fractional-digits`形式（`.5`、`.5E2`、`-.5`など）が
`OperatorDot`としてLexerに分類され、Parserのメンバーアクセス構文エラーになった。
一方、`obj.Member`はメンバーアクセスとして維持する必要がある。

小数点の直後が数字の場合だけ浮動小数リテラルとして共通の指数・サフィックス処理へ
渡し、その他のドットは従来どおりOperatorDotにした。仕様のFLOAT文法は
`floating-point-literal = ... / "." fractional-digits [exponent]`でこの形式を定義している。
回帰テストで分数、E指数、符号、メンバーアクセスの境界を確認した。
