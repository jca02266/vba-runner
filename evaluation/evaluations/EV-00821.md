## 評価内容

Scripting.Dictionary.Existsのkeyを省略した`value = dict.Exists`と
`value = dict.Exists()`を比較し、有効な`value = dict.Exists("key")`も確認する。

## 実施方法

```vba
Public Function Probe() As String
    Dim d As Object, value As Variant, out As String
    Set d = CreateObject("Scripting.Dictionary")
    d.Add "key", True
    On Error Resume Next
    Err.Clear: value = d.Exists
    out = "OMITTED=" & CStr(Err.Number) & ":" & TypeName(value)
    Err.Clear: value = d.Exists()
    out = out & "|PARENS=" & CStr(Err.Number) & ":" & TypeName(value)
    Err.Clear: value = d.Exists("key")
    out = out & "|KEY=" & CStr(Err.Number) & ":" & TypeName(value) & ":" & CStr(value)
    Probe = out
    On Error GoTo 0
End Function
```

## 期待値

期待出力: `OMITTED=450:Empty|PARENS=450:Empty|KEY=0:Boolean:True`

Existsのkeyは必須であると仮定する。Excel実機のXL-202で省略形式のエラー番号と
戻り値を確認するまで、仮説を確定期待値として扱わない。

## 結果

実測出力（Runner）: `OMITTED=0:Object|PARENS=0:Boolean|KEY=0:Boolean:True`

Runnerは省略形式をエラーなしのObjectとして返し、括弧付き省略もBoolean Falseを
返した。有効keyはTrueになった。

実測出力: Excel実機

```text
XL-202 OMITTED ERR=450 TYPE=Empty
XL-202 PARENS ERR=450 TYPE=Empty
XL-202 KEY ERR=0 TYPE=Boolean VALUE=True
```

Excelは省略形式と括弧付き省略形式をError 450として扱った。Runnerは省略形式を
エラーなしのObjectまたはBooleanとして扱い、Excelと一致しなかった。

## 判定

判定状態: bug-found

Dictionary.Existsの省略引数境界を確認し、動的メンバーの必須引数契約が未適用である
ことを記録した。
