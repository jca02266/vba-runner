## 評価内容

Optional添字を持つindexed Property Letで、添字を明示する代入と省略する代入の束縛を比較する。

## 実施方法

`Data(Optional index As Long = 0, value As Long)`を定義し、`c.Data(0)=3`と`c.Data()=5`を順に実行した。

## 期待値

プログラム上の期待出力: 最終累積値`8`。

文章での期待: 明示添字0と既定値0の省略添字が同じsetter経路に到達し、値3と5が累積される。

## 結果

プログラム上の実測出力: `8`。

文章での結果: 明示・省略の両代入が期待どおりに束縛され、新規不具合はなかった。

## 判定

判定状態: verified-no-bug。
