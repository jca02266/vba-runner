# EV-00799の再評価

## 評価内容
Property Let代入形式に配列要素を渡した場合のvalue引数の実効ByVal境界を、配列全体代入と区別して再評価する。

## 実施方法
次の2ケースを分けて実行する。

```vba
' 配列全体を受けるProperty Let（型検査）
Class TypedArrayBox
    Public Seen As Long
    Public Property Let Values(ByRef incoming() As Long)
        Seen = incoming(0)
    End Property
End Class

' 配列要素と暗黙型変換を受けるProperty Let
Class PropertyBoundaryBox
    Private Seen As Long
    Public Property Let Item(ByRef value As Long)
        Seen = value
        value = value + 1
    End Property
    Public Property Let Converted(ByRef value As Long)
        Seen = value
    End Property
    Public Function Read() As Long
        Read = Seen
    End Function
End Class

Function VerifyPropertyBoundaries() As String
    Dim whole As New TypedArrayBox
    Dim elementBox As New PropertyBoundaryBox
    Dim source As Integer
    Dim values(0 To 0) As Long
    values(0) = 7

    ' 配列全体を渡し、要素型 Long を検査する
    whole.Values = values

    ' 配列要素を渡し、Property内の変更が呼出元へ戻らないことを検査する
    elementBox.Item = values(0)
    source = 12
    elementBox.Converted = source
    VerifyPropertyBoundaries = CStr(elementBox.Read()) & ":" & CStr(values(0)) & ":" & CStr(source)
End Function
```

配列全体の型検査と、配列要素のProperty Let value引数の書戻しを別々に
確認し、実測出力は `12:7:12` とする。

## 期待値
プログラム上の期待出力: `12:7:12`

Property Letのvalue引数は実効ByValなので、Property内で値を変更しても呼出元配列要素は変化しない。Integer値はLong引数へ変換される。

## 結果
プログラム上の実測出力: `12:7:12`

Property専用ケースで配列要素は7のまま保持され、別のInteger値12はLong value引数へ変換されて受け渡された。

## 判定
判定状態: `verified-no-bug`

配列要素のProperty専用実測が期待どおりで、value引数から呼出元配列要素への書戻しは発生しなかった。
