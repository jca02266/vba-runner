## 評価内容

Property LetとProperty Setの右辺値が暗黙の最終引数として追加されるとき、先行する
必須インデックス引数の省略が許可されないことを確認する。

## 実施方法

```vba
Class ArityProperty
    Public Property Let Value(index As Long, value As Long)
    End Property
    Public Property Set ObjectValue(index As Long, value As Object)
    End Property
End Class

Sub Caller()
    Dim instance As New ArityProperty
    instance.Value = 2
End Sub
```

Property Setは`Dim child As New ArityProperty`を用意し、`Set instance.ObjectValue = child`を
同じように実行する。

## 期待値

期待出力: `Argument not optional`

Property Let/Setの右辺値は暗黙の最終引数だが、先行する必須インデックスを補完しない。

## 結果

実測出力: 修正前はLet/Setが実行され、修正後は両方で`Argument not optional`となった。

`callPropertySetterAssignment`で右辺値を追加する前に、必須インデックスを検査する実装へ
変更し、回帰行列が通過した。

## 判定

判定状態: retired

この評価はEV-00826と同一のProperty Let/Set境界を重複して記録していたため退役した。
実装修正と正本の回帰テストはEV-00826に保持し、Property Get・Module修飾・With・動的COMの
別境界はFZ-GRAMMAR-064および既存の動的メンバー候補で継続確認する。
