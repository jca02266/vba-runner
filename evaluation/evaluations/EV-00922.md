## 評価内容

標準モジュールの0引数Property Getが返す配列について、正常な添字、下限・上限外、
添字数不一致を確認する。併せて、同じモジュール修飾経路の必須引数・Optional引数を確認する。

## 実施方法

次の2モジュールをRunnerへ渡して実行する。

`Provider.bas`:

```vba
Option Explicit

Public Property Get Scalar() As Long
    Scalar = 42
End Property

Public Property Get Values() As Variant
    Dim data(0 To 1) As Long
    data(0) = 7
    data(1) = 8
    Values = data
End Property

Public Property Get Required(ByVal index As Long) As Long
    Required = index * 10
End Property

Public Property Get OptionalValue(Optional ByVal index As Long = 3) As Long
    OptionalValue = index * 10
End Property
```

`RunProbe.bas`:

```vba
Option Explicit

Public Sub RunProbe()
    Dim value As Variant, number As Long, errNo As Long
    On Error Resume Next
    Debug.Print "SCALAR=" & CStr(Provider.Scalar)
    Debug.Print "VALUES0=" & CStr(Provider.Values(0))
    Debug.Print "VALUES1=" & CStr(Provider.Values(1))
    Err.Clear: value = Provider.Values(2): errNo = Err.Number
    Debug.Print "VALUES2 ERR=" & CStr(errNo) & " VALUE=" & CStr(value) & " TYPE=" & TypeName(value)
    Err.Clear: value = Provider.Values(-1): errNo = Err.Number
    Debug.Print "VALUES-1 ERR=" & CStr(errNo) & " VALUE=" & CStr(value) & " TYPE=" & TypeName(value)
    Err.Clear: value = Provider.Values(0, 0): errNo = Err.Number
    Debug.Print "VALUES00 ERR=" & CStr(errNo)
    Err.Clear: number = Provider.Required: errNo = Err.Number
    Debug.Print "REQUIRED ERR=" & CStr(errNo)
    Err.Clear: number = Provider.Required(): errNo = Err.Number
    Debug.Print "REQUIREDP ERR=" & CStr(errNo)
    Err.Clear: number = Provider.Required(2): errNo = Err.Number
    Debug.Print "REQUIRED2 ERR=" & CStr(errNo) & " VALUE=" & CStr(number)
    Err.Clear: number = Provider.OptionalValue: errNo = Err.Number
    Debug.Print "OPTIONAL ERR=" & CStr(errNo) & " VALUE=" & CStr(number)
    Err.Clear: number = Provider.OptionalValue(): errNo = Err.Number
    Debug.Print "OPTIONALP ERR=" & CStr(errNo) & " VALUE=" & CStr(number)
    Err.Clear: number = Provider.OptionalValue(4): errNo = Err.Number
    Debug.Print "OPTIONAL4 ERR=" & CStr(errNo) & " VALUE=" & CStr(number)
    Err.Clear: number = Provider.Values: errNo = Err.Number
    Debug.Print "VALUESLONG ERR=" & CStr(errNo)
    On Error GoTo 0
End Sub
```

## 期待値

期待出力: `Values(0)`と`Values(1)`は7、8、範囲外と添字数不一致はError 9、
必須引数省略はError 449、Optional省略は既定値30、`Values`のLong代入はError 13になる。

```text
SCALAR=42
VALUES0=7
VALUES1=8
VALUES2 ERR=9 VALUE=0 TYPE=Empty
VALUES-1 ERR=9 VALUE=0 TYPE=Empty
VALUES00 ERR=9
REQUIRED ERR=449
REQUIREDP ERR=449
REQUIRED2 ERR=0 VALUE=20
OPTIONAL ERR=0 VALUE=30
OPTIONALP ERR=0 VALUE=30
OPTIONAL4 ERR=0 VALUE=40
VALUESLONG ERR=13
```

## 結果

実測出力:

```text
SCALAR=42
VALUES0=7
VALUES1=8
VALUES2 ERR=0 VALUE=0 TYPE=Empty
VALUES-1 ERR=0 VALUE=0 TYPE=Empty
VALUES00 ERR=9
REQUIRED ERR=449
REQUIREDP ERR=449
REQUIRED2 ERR=0 VALUE=20
OPTIONAL ERR=0 VALUE=30
OPTIONALP ERR=0 VALUE=30
OPTIONAL4 ERR=0 VALUE=40
VALUESLONG ERR=13
```

Module修飾Property Getの配列戻り値では、範囲外の`Values(2)`と`Values(-1)`がError 9に
ならずEmptyとして評価された。裸参照、必須引数、Optional引数、添字数不一致、型不一致は
期待値どおりであり、同じModule修飾Property Getの配列境界を横展開対象とする。

## 判定

判定状態: bug-found。配列戻り値のModule修飾Property Get分岐で、添字範囲検査が欠落している。
