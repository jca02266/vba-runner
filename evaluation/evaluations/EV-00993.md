## 評価内容

Public Typeを宣言したモジュールとは別の手続きで、`Module.Type`として型を指定した変数へメンバーを書き込めるか確認する。

## 実施方法

```vba
' ModuleA
Option Explicit
Public Type T
    X As Long
End Type

' ModuleB
Option Explicit
Public Function UseQualifiedType() As Long
    Dim value As ModuleA.T
    value.X = 9
    UseQualifiedType = value.X
End Function
```

`ModuleB.UseQualifiedType`を実行し、修飾型名の実体化とメンバー代入を確認する。

## 期待値

プログラム上の期待出力: `UseQualifiedType`は`9`を返す。

文章での期待: Public UDTはモジュール修飾された型名でも解決され、値型のメンバーへ代入できる。

## 結果

プログラム上の実測出力: 修正後のRunnerは`UseQualifiedType=9`を返した。

文章での結果: 修飾UDT解決を共通化し、Public型を共有環境から実体化できることを確認した。Private型は従来どおり所有モジュール外の非修飾参照を拒否する。

## 判定

判定状態: fixed（Public Module.Type修飾参照を実体化し、回帰テストを通過）。
