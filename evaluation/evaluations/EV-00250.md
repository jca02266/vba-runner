# FSO Boolean引数と欠落ファイルのError境界

独立評価で、VBA Boolean(False)がJavaScript objectとしてtruthyになるため、既存ファイルへの
CreateTextFile/CopyFileが上書き禁止を無視していた。またOpenTextFileのENOENTがVBA Error 53
ではなくError 1000になっていた。共通Boolean判定とOpenTextFileのENOENT変換を追加し、
最小回帰テストを追加した。EOF後の読み取りは実Excel照合が必要なため別の未解決境界として残す。
