# LongLongと安全範囲外の数値文字列

独立評価で、`CLngLng("9007199254740993")` と同値のVariant Stringを比較すると、
Select Caseの等価・範囲判定と通常の`=`比較が誤判定した。Select Caseおよび通常比較が
文字列をJavaScript `Number`へ変換してからLongLongへ変換していたことが原因である。
整数形式の文字列は直接`BigInt`へ解析する経路を追加し、64ビット境界の等価・範囲回帰を
追加した。横展開で見つかった通常算術とDecimal/Currency混在式は別候補として残した。
