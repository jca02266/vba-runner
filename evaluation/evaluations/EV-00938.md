## 評価内容

同じ正負値集合を8通りに並べ替え、ReinvestRate=-1近傍で位置依存の差異を確認する。

## 実施方法

```vba
Sub ProbeMirrPositions()
    Dim cases As Variant, item As Variant, f(0 To 4) As Double
    Dim i As Long, j As Long
    cases = Array( _
        Array(-100, -50, 0, 50, 100), Array(-100, 50, -50, 0, 100), _
        Array(-100, 50, 0, -50, 100), Array(-100, 50, 100, -50, 0), _
        Array(50, -100, -50, 0, 100), Array(50, -100, 0, 100, -50), _
        Array(100, 50, 0, -50, -100), Array(100, -50, 0, 50, -100))
    For i = 0 To UBound(cases)
        item = cases(i)
        For j = 0 To 4: f(j) = item(j): Next j
        Debug.Print i + 1, MIRR(f, 0.1, -0.9999999999)
    Next i
End Sub
```

## 期待値

期待出力: `XL-241 CASE=<1..8> VALUE=<value> TYPE=Double`。
各順列のExcelとRunnerの値またはError番号を比較する。
