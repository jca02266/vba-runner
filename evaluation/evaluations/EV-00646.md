# Property ParamArrayの名前付き引数受理

`Property Let Item(ParamArray indexes(), value As Variant)` に対する
`bag.Item(1, value:=9)` が成功した。ParamArrayを含む手続きは名前付き引数で
呼び出せないため、通常のParamArray呼出しと同じError 448相当へ修正する。
