# 非有限数値の出力境界

独立評価で、`Val("1E+309")`、`1E308*100`、`FV`、`PMT`、`SLN` がInfinityまたはNaNを
Error 0で返した。これはVBAのDouble範囲外エラーと一致するか、また関数ごとに特殊値を
返す仕様かを実Excelで裁定する必要がある。数値リテラルと累乗は先行修正でError 6に
なったため、今回の実機キューでは残りの関数・演算経路だけを確認する。
