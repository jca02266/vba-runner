# Select CaseのDecimal高精度等価比較

独立評価で `CDec("12345678901234567.1")` と
`CDec("12345678901234567.2")` が同じCaseに一致した。原因はDecimalを
`Number`へ変換してから比較していたことである。Decimalのmantissaとscaleを
整列して比較するよう修正した。また、Currency/Decimalの`To`と大小比較も
同じ固定小数点比較へ通し、異なる高精度値と範囲境界の回帰テストを追加した。
