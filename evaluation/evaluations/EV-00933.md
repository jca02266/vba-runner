## 評価内容

MIRRのReinvestRate=-1近傍について、3要素と4要素のキャッシュフロー、および正の
キャッシュフローの位置を変えたときのError番号・戻り値・型を比較する。

## 実施方法

`tests/excel/queue/ExcelQueueVerification.bas` の
`VerifyMirrReinvestNearMatrix` をRunnerとExcelで実行する。次の5ケースを同じ
手続きから出力する。

```vba
flows = Array(-100, 50, 100): rate = -0.999999
flows = Array(-100, 50, 100): rate = -0.99999999
flows = Array(-100, 50, 100): rate = -0.9999999999
flows = Array(-100, 0, 50, 100): rate = -0.9999999999
flows = Array(-100, 50, 0, 100): rate = -0.9999999999
```

## 期待値

期待出力:

```text
XL-236 A1=<err-or-value>:<value>:Double
XL-236 A2=<err-or-value>:<value>:Double
XL-236 A3=<err-or-value>:<value>:Double
XL-236 B1=<err-or-value>:<value>:Double
XL-236 C1=<err-or-value>:<value>:Double
```

Runnerの暫定出力はA1=`0:2.499999687266552e-7:Double`、
A2=`0:2.4999999848063226e-9:Double`、A3=`0:2.5000002068509275e-11:Double`、
B1=`0:1.666666804567285e-11:Double`、C1=`0:0:Double`である。これは仮説比較であり、
Excel照合前にバグとは判定しない。

## 結果

実測出力:

```text
XL-236 A1 VALUE=2.50000002477435E-07 TYPE=Double
XL-236 A2 VALUE=2.4992732328144E-09 TYPE=Double
XL-236 A3 VALUE=2.25147456234254E-10 TYPE=Double
XL-236 B1 VALUE=2.51975773579716E-10 TYPE=Double
XL-236 C1 VALUE=2.35309105534043E-10 TYPE=Double
```

## 判定

判定状態: fixed

RunnerのA1〜C1はすべてError 0・Doubleだが、Excelの有限値と一致しなかった。
A3はRunnerの`2.5000002068509275E-11`に対してExcelが
`2.25147456234254E-10`であり、A1・A2・B1・C1にも差異がある。これは
BUG-00570の直接原因がキャッシュフロー形状へ横展開することを示すため、bug-foundとする。
