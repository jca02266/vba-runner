## 評価内容

MIRRのReinvestRate=-1近傍について、3要素と4要素のキャッシュフロー、および正の
キャッシュフローの位置を変えたときのError番号・戻り値・型を比較する。

## 実施方法

`tests/excel/queue/ExcelQueueVerification.bas` の
`VerifyMirrReinvestNearMatrix` をRunnerとExcelで実行する。次の5ケースを同じ
手続きから出力する。

```vba
flows = Array(-100, 50, 100): rate = -0.999999
flows = Array(-100, 50, 100): rate = -0.99999999
flows = Array(-100, 50, 100): rate = -0.9999999999
flows = Array(-100, 0, 50, 100): rate = -0.9999999999
flows = Array(-100, 50, 0, 100): rate = -0.9999999999
```

```text

XL-236 A3=<err-or-value>:<value>:Double
XL-236 B1=<err-or-value>:<value>:Double
```
