## 評価内容

Property Let/SetをWith式とCallByNameから呼び出し、必須インデックスの省略時と指定時の
アリティ検査が、直接Property経路と同じVBA仕様になるかを確認する。

## 実施方法

次の2モジュールをRunnerへ渡して実行する。

```vba
Option Explicit

`PropertyTarget.cls`:

```vba
Option Explicit

Private values(0 To 5) As Variant

Public Property Let Item(ByVal index As Long, ByVal value As Variant)
    values(index) = value
End Property

Public Property Set ObjectItem(ByVal index As Long, ByVal value As Object)
    Set values(index) = value
End Property

Public Function Read(ByVal index As Long) As Variant
    Read = values(index)
End Function
```

`RunProbe.bas`:

```vba
Option Explicit

Public Sub RunProbe()
    Dim target As PropertyTarget, child As Object, errNo As Long
    Set target = New PropertyTarget
    Set child = New PropertyTarget

    On Error Resume Next
    With target
        .Item = 1
        errNo = Err.Number
        Debug.Print "WITH-LET-OMITTED=" & CStr(errNo)
        Err.Clear
        .Item(2) = 7
        Debug.Print "WITH-LET-INDEX=" & CStr(Err.Number) & ":let:2:" & CStr(.Read(2))
        Err.Clear
        Set .ObjectItem = child
        errNo = Err.Number
        Debug.Print "WITH-SET-OMITTED=" & CStr(errNo)
        Err.Clear
        Set .ObjectItem(3) = child
        Debug.Print "WITH-SET-INDEX=" & CStr(Err.Number) & ":set:3:child"
    End With
    Err.Clear
    CallByName target, "Item", VbLet, 8
    errNo = Err.Number
    Debug.Print "CBN-LET-OMITTED=" & CStr(errNo)
    Err.Clear
    CallByName target, "Item", VbLet, 4, 8
    Debug.Print "CBN-LET-INDEX=" & CStr(Err.Number) & ":let:4:" & CStr(target.Read(4))
    Err.Clear
    CallByName target, "ObjectItem", VbSet, child
    errNo = Err.Number
    Debug.Print "CBN-SET-OMITTED=" & CStr(errNo)
    Err.Clear
    CallByName target, "ObjectItem", VbSet, 5, child
    Debug.Print "CBN-SET-INDEX=" & CStr(Err.Number) & ":set:5:child"
    On Error GoTo 0
End Sub
```

The runner receives the `.cls` and `.bas` files together; no host-specific object is required.

## 期待値

期待出力: 必須インデックスを省略した4ケースはError 449、インデックスを指定した4ケースは
Err=0であり、Letは値、Setはオブジェクトを指定位置へ書き込む。

```text
WITH-LET-OMITTED=449
WITH-LET-INDEX=0:let:2:7
WITH-SET-OMITTED=449
WITH-SET-INDEX=0:set:3:child
CBN-LET-OMITTED=449
CBN-LET-INDEX=0:let:4:8
CBN-SET-OMITTED=449
CBN-SET-INDEX=0:set:5:child
```

## 結果

実測出力:

```text
WITH-LET-OMITTED=449
WITH-LET-INDEX=0:let:2:7
WITH-SET-OMITTED=449
WITH-SET-INDEX=0:set:3:child
CBN-LET-OMITTED=449
CBN-LET-INDEX=0:let:4:8
CBN-SET-OMITTED=449
CBN-SET-INDEX=0:set:5:child
```

WithとCallByNameのProperty Let/Setは、必須インデックスを省略するとError 449になり、
指定すると正常に書き込まれた。直接Property経路の修正範囲を越える差異は確認できなかった。

## 判定

判定状態: verified-no-bug。WithおよびCallByNameの必須引数アリティは仕様どおりであり、
新たなバグや横展開候補は作成しない。
