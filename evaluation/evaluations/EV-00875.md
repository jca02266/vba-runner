## 評価内容

空バッファ、0x00、0xFF、UTF-8バイト列をcopyFileSyncで保存し、MemoryFileSystemと
NodeFileSystemの内容を比較する。overwrite=Falseの初回コピー・衝突、overwrite=True、
およびコピー後に入力Uint8Arrayを変更した場合の保存内容も確認する。

## 実施方法

同じバイト列を各バックエンドのsourceへUint8Arrayとして書き込み、copyFileSyncで
destinationへコピーする。コピー後に入力配列を変更し、destinationのバイト列が変化
しないことを確認する。既存destinationに対するoverwrite指定も同じ行列で実行する。
バイナリ行列は `npx tsx tests/tooling/filesystem-backend-binary-copy.test.ts`、
バックエンドの衝突確認は `npx tsx tests/tooling/filesystem-backend-copy.test.ts`、
VBA経路の回帰確認は `npx tsx tests/spec/filesystem-extra.test.ts` で実行する。

## 期待値

期待出力:

```text
Memory empty bytes= overwrite=false=ok overwrite=true=ok input-owner=ok
Memory zero bytes=00 overwrite=false=ok overwrite=true=ok input-owner=ok
Memory ff bytes=ff overwrite=false=ok overwrite=true=ok input-owner=ok
Memory utf8 bytes=e3 81 82 41 overwrite=false=ok overwrite=true=ok input-owner=ok
Node empty bytes= overwrite=false=ok overwrite=true=ok input-owner=ok
Node zero bytes=00 overwrite=false=ok overwrite=true=ok input-owner=ok
Node ff bytes=ff overwrite=false=ok overwrite=true=ok input-owner=ok
Node utf8 bytes=e3 81 82 41 overwrite=false=ok overwrite=true=ok input-owner=ok
```

各バイト列が同一に保存され、overwrite=Falseの衝突は既存内容を保持して失敗し、
overwrite=Trueは更新に成功する。入力配列の変更はコピー済みdestinationへ影響しない。

## 結果

実測出力:

```text
Memory empty bytes= overwrite=false=ok overwrite=true=ok input-owner=ok
Memory zero bytes=00 overwrite=false=ok overwrite=true=ok input-owner=ok
Memory ff bytes=ff overwrite=false=ok overwrite=true=ok input-owner=ok
Memory utf8 bytes=e3 81 82 41 overwrite=false=ok overwrite=true=ok input-owner=ok
Node empty bytes= overwrite=false=ok overwrite=true=ok input-owner=ok
Node zero bytes=00 overwrite=false=ok overwrite=true=ok input-owner=ok
Node ff bytes=ff overwrite=false=ok overwrite=true=ok input-owner=ok
Node utf8 bytes=e3 81 82 41 overwrite=false=ok overwrite=true=ok input-owner=ok
```

独立評価と専用回帰テストで全ケースが期待値と一致し、保存内容、上書き結果、入力配列の
所有権にバックエンド差異は確認されなかった。
