## 評価内容

Enum型の固定長配列について、配列全体の型情報、要素の型情報、未代入要素の既定値を確認する。

## 実施方法

次の最小ソースをvba-runnerで実行し、同じケースをExcelキューのXL-253で実行する。

```vba
Option Explicit
Private Enum ColorKind
    Red = 3
End Enum
Private values(0 To 1) As ColorKind
Public Function Probe() As String
    Dim errNo As Long, text As String
    On Error Resume Next
    Err.Clear: text = CStr(values(0)): errNo = Err.Number
    On Error GoTo 0
    Probe = CStr(VarType(values)) & "/" & CStr(VarType(values(0))) & "/" & CStr(errNo) & "/" & text
End Function
```

## 期待値

期待出力：`8195/3/0/0`。EnumはLong相当の値型なので、配列はLong配列のVarType、要素はLongのVarType、未代入要素は0として文字列化できることを仮説とする。仕様レビューとExcel実機で確定する。

## 結果

vba-runner実測出力：`8204/5/0/0`。修正前は配列全体がVariant配列、要素がDoubleとして扱われていた。Excel実機出力は`XL-253 ARRAY=8195/3/0/0`で、Long配列相当と一致しない。

## 判定

判定状態: fixed

Excel実機とvba-runnerの型情報が一致しないため、Enum配列の要素メタデータ欠落バグとして確定した。Long相当の配列要素メタデータへ修正し、回帰テストを通過した。
