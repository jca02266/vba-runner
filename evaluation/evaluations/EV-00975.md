## 評価内容

Select Caseの`Case 5 To 1`のような逆順範囲が、範囲を持たないものとして扱われるか確認する。

## 実施方法

```vba
Function SelectReverse(value As Long) As String
    Select Case value
        Case 5 To 1
            SelectReverse = "range"
        Case Else
            SelectReverse = "other"
    End Select
End Function
```

`value`に`3`と`5`を渡して結果を比較する。

## 期待値

プログラム上の期待出力: `SelectReverse(3) = "other"`、`SelectReverse(5) = "other"`。
文章での期待: 逆順のTo範囲は開始値以上かつ終了値以下を同時に満たす値がないため、Case Elseが選択される。

## 結果

プログラム上の実測出力: Runnerは`3`、`5`のいずれも`"other"`を返した。
文章での結果: 実装の範囲比較は開始値以下かつ終了値以上を要求しており、逆順範囲を空として扱っていた。期待との差はなく、追加の修正は不要と判断した。

## 判定

判定状態: verified-no-bug（最小実行で期待動作を確認した）。
