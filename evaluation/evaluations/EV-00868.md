## 評価内容

MIRRのFinanceRate境界が、キャッシュフローの符号・位置・個数によって異なるかを
3形状と7つの金利値の行列で確認する。形状Bは既存のXL-218と同じ制御ケースである。

## 実施方法

次の自己完結したVBAをRunnerで実行し、各形状と金利の組合せについて`Err.Number`と
戻り値を記録する。Excel照合用には同じ行列を`ExcelQueueVerification.bas`のXL-220
として実行する。

```vba
Public output As String

Sub ProbeMirrFinanceRateShapes()
    Dim rates, i As Long, value As Double, errNo As Long
    Dim a(0 To 2) As Double, b(0 To 2) As Double, c(0 To 3) As Double
    rates = Array(-2, -1.1, -1.0000000001, -1, -0.9999999999, -0.5, 0.1)
    a(0) = -100: a(1) = 50: a(2) = 75
    b(0) = -100: b(1) = -50: b(2) = 200
    c(0) = -100: c(1) = 100: c(2) = -20: c(3) = 75
    For i = 0 To 6
        On Error Resume Next
        Err.Clear: value = MIRR(a, rates(i), 0.1): errNo = Err.Number
        output = output & "A:" & CStr(rates(i)) & ":" & CStr(errNo) & ";"
        Err.Clear: value = MIRR(b, rates(i), 0.1): errNo = Err.Number
        output = output & "B:" & CStr(rates(i)) & ":" & CStr(errNo) & ";"
        Err.Clear: value = MIRR(c, rates(i), 0.1): errNo = Err.Number
        output = output & "C:" & CStr(rates(i)) & ":" & CStr(errNo) & ";"
        On Error GoTo 0
    Next i
End Sub
```

## 期待値

プログラム上の期待値: 3形状×7金利値の21ケースがすべて実行され、各ケースが有限値
または制御されたVBAエラーになり、同じ金利境界を形状ごとに別の暗黙条件で処理しない。

文章としては、FinanceRate=-1近傍・-1未満の結果を形状ごとに比較でき、Excel照合で
Error 5、有限値、機械epsilon差のどれに該当するかを確定できることを期待する。

期待出力: 3形状×7金利値それぞれについて、RunnerとExcelの
`ERR`および`VALUE`が一致することである。代表的な境界は次のとおりである。

```text
A RATE=-1 ERR=5
B RATE=-1 ERR=5
C RATE=-1 ERR=5
```

## 結果

実測出力: RunnerとExcelは20ケースで一致したが、Shape AのFinanceRate=-1だけが不一致となった。
Runnerは`ERR=0 VALUE=0.140175425099138`、Excelは`ERR=5`だった。Shape B・Cの同境界や
FinanceRate=-1未満の形状差は一致した。

## 判定

判定状態: fixed

XL-220でShape AのFinanceRate=-1におけるError 5差異を確認した。FinanceRate=-1を
キャッシュフロー形状に依存させずError 5へ統一し、回帰テストで固定した。FinanceRate
<-1と計算順序・epsilon差はRC-00011の未解決範囲として残す。
