## 評価内容

CDateの数値シリアル値について、実装が採用している下限・上限と隣接する値を比較し、境界の受理とエラー番号をExcel実機で確定する。

## 実施方法

次の自己完結VBAを実行する。

```vb
Option Explicit
Public Function Probe() As String
    Dim values As Variant, i As Long, value As Variant, errNo As Long, out As String
    values = Array(-657435, -657434, 2958465, 2958466)
    On Error Resume Next
    For i = LBound(values) To UBound(values)
        Err.Clear
        value = CDate(values(i))
        errNo = Err.Number
        If Len(out) > 0 Then out = out & "|"
        out = out & "SERIAL=" & CStr(values(i)) & " ERR=" & CStr(errNo) & " VALUE=" & CStr(value)
    Next i
    Probe = out
    On Error GoTo 0
End Function
```

## 期待値

プログラムとしての暫定期待出力:

```text
SERIAL=-657435 ERR=6|SERIAL=-657434 ERR=0 VALUE=0100/01/01|SERIAL=2958465 ERR=0 VALUE=9999/12/31|SERIAL=2958466 ERR=6
```

実装の境界式から導いた仮説であり、実機照合までは確定値として扱わない。
