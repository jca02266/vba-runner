## 評価内容

Date Property Let/GetをCallByNameのVbLet/VbGetで呼び出し、保存値が取得できるかを確認する。

## 実施方法

```vba
' Class module: DateMutator
Private stored As Date

Public Property Let Stamp(ByVal value As Date)
    stored = value
End Property

Public Property Get Stamp() As Date
    Stamp = stored
End Property

' Standard module
Function RunCase() As String
    Dim m As New DateMutator
    CallByName m, "Stamp", VbLet, DateSerial(2024, 1, 2)
    RunCase = DateKey(CallByName(m, "Stamp", VbGet))
End Function

Function DateKey(ByVal value As Date) As String
    DateKey = CStr(Year(value)) & "-" & CStr(Month(value)) & "-" & CStr(Day(value))
End Function
```

## 期待値

期待出力：`2024-1-2`

CallByNameのVbLetで保存したDate値をVbGetで取得したとき、年・月・日が保持されることを期待する。

## 結果

実測出力：`2024-1-2`

RunnerはCallByNameのVbLet/VbGetでDate値を正しく保持した。

## 判定

判定状態: verified-no-bug

対象のClass CallByName Property経路で不一致は再現せず、新規Findingは確認されなかった。
