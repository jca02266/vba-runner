## 評価内容

Public UDT配列を返すFunctionの戻り値を、呼出し側の`Module.Type`修飾配列へ代入したとき、要素型の意味的同一性が維持されるか確認する。

## 実施方法

```vba
' Producer.bas
Option Explicit
Public Type RecordT
    Id As Long
End Type
Public Function Make() As RecordT()
    Dim values(0 To 1) As RecordT
    values(0).Id = 5
    values(1).Id = 6
    Make = values
End Function

' Consumer.bas
Option Explicit
Public Function Probe() As Long
    Dim values() As Producer.RecordT
    values = Producer.Make()
    Probe = values(0).Id + values(1).Id
End Function
```

`Probe`を実行し、同じPublic UDT配列の戻り値代入と要素参照を確認する。

## 期待値

プログラム上の期待出力: `11`。

文章での期待: `RecordT()`と`Producer.RecordT()`は同じPublic UDT配列であり、非Byte配列の要素型が一致するため代入できる。

## 結果

プログラム上の実測出力: 修正前は`Run-time error '13': Can't assign to an array`。

文章での結果: 戻り値配列と宛先配列の要素型メタデータが修飾名と裸名で比較され、同じPublic UDTにもかかわらず配列代入が拒否された。

## 判定

判定状態: bug-found。

独立探索エージェントとメイン側の最小再現が一致した。ByRef配列検査とは別の配列全体代入経路で同じ型同一性欠落が現れており、RC-00124の横展開として記録する。
