# Lexer日付候補の区切り誤分類境界

閉じ`#`がある`#1, -1#`をrunnerが日付リテラルとして解釈していた。この入力はVBAの
日付リテラルとして不正であり、ファイル番号・負数構文と混同してはならない。数値日付
には複数区切り、時刻には時刻形式を要求し、正常な日付・時刻とともに回帰テストを追加した。
