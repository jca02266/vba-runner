# Rnd状態引数境界の評価

独立評価で `Rnd(-1)` の後に `Rnd("1")` を呼ぶと、実装が文字列引数を数値分岐へ
入れず、直前値をそのまま返すことを確認した。VBAのNumber引数として数値文字列を
受ける経路と一致しないため、`Rnd` と `Randomize` が共有する数値正規化を追加した。

回帰テストを追加し、Null・Empty・0・負値・連続呼び出しは独立評価で既存の状態遷移
を確認した。
