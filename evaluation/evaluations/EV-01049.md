## 評価内容

Date ByVal引数の通常呼出しとCallByName呼出しで、呼出し元の値が書き戻されない契約を確認する。

## 実施方法

```vba
' Class module: DateMutator
Public Sub Touch(ByVal value As Date)
    value = DateSerial(1899, 12, 30)
End Sub

' Standard module
Function DateKey(ByVal value As Date) As String
    DateKey = CStr(Year(value)) & "-" & CStr(Month(value)) & "-" & CStr(Day(value))
End Function

Function RunCase() As String
    Dim m As New DateMutator, directValue As Date, dynamicValue As Date
    directValue = DateSerial(2024, 1, 2)
    dynamicValue = DateSerial(2024, 1, 2)
    m.Touch directValue
    CallByName m, "Touch", VbMethod, dynamicValue
    RunCase = DateKey(directValue) & "|" & DateKey(dynamicValue)
End Function
```

## 期待値

期待出力：`2024-1-2|2024-1-2`

ByVal引数は呼出し先でDate値を変更しても呼出し元へ書き戻さず、通常呼出しとCallByNameで同じ結果になることを期待する。

## 結果

実測出力：`2024-1-2|2024-1-2`

Runnerは通常呼出しとCallByNameの両経路でDate ByVal値をコピーし、呼出し元の値を保持した。

## 判定

判定状態: verified-no-bug

対象のClass経路で通常呼出しと動的呼出しの不一致は再現せず、新規Findingは確認されなかった。
