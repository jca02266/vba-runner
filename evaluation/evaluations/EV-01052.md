## 評価内容

UDTメンバー配列境界に、別モジュールの修飾Constを指定した場合の名前解決と可視性を評価する。

## 実施方法

```vba
' Bounds.bas
Public Const LAST_INDEX As Integer = 2

' Records.bas
Type IndexedRecord
    Values(Bounds.LAST_INDEX) As Integer
End Type
```

同時に、`Private Const`へ変更したケースが拒否されることも確認する。

## 期待値

期待出力：`2`

Public Constでは`UBound(record.Values)`が`2`になる。Private Constでは期待エラー`Constant expression required`となり、実行前に参照を拒否する。

## 結果

修正前の実測結果：`Constant expression required`

修正後の実測出力：`2`

修正後はPublic Constが`2`として解決され、Private Constは期待エラー`Constant expression required`で拒否された。

## 判定

判定状態: fixed

定数式の可否判定と値評価が別の名前解決を使っていた既存BUG-00620の横展開として修正した。
