# Filter引数境界の評価

独立評価で、FilterのCompare引数に2や-1を指定しても成功し、MatchにNullを指定すると
Error 13になっていた。Excel VBAではAccess専用または無効なCompare値はError 5、必須
文字列引数のNullはError 94である。

Compareを0/1に限定し、MatchのNullをInvalid use of Nullへ統一した。既存の配列形状、
Include、Option Compare、Compare Nullの経路は変更していない。
