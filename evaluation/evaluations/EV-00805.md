# EV-00798の再評価

## 評価内容
Property Letの暗黙ByRef、名前付き引数、型変換が、通常のByRef手続きと同じ書戻しを起こすかを再確認する。

## 実施方法
次の自己完結したVBAソースを実行し、Property専用の名前付き添字、暗黙ByRef
value引数、型変換を確認する。

```vba
Class NamedPropertyBox
    Private seenIndex As Long
    Private seenValue As Long
    Public Property Let Item(Optional index As Long = 0, value As Long)
        seenIndex = index
        seenValue = value
        value = value + 1
    End Property
    Public Function Read() As String
        Read = CStr(seenIndex) & ":" & CStr(seenValue)
    End Function
End Class

Function VerifyNamedProperty() As String
    Dim box As New NamedPropertyBox, source As Integer
    source = 5
    box.Item(index:=2) = source
    VerifyNamedProperty = box.Read() & ":" & CStr(source)
End Function
```

Property内部の値、名前付き添字、IntegerからLongへの変換結果、呼出元値を
個別に出力する。

## 期待値
プログラム上の期待出力: `2:5:5`

名前付き添字2がPropertyへ渡り、Integer値5がLong value引数へ変換される。Property内のvalue変更は呼出元のsourceへ書き戻されない。

## 結果
プログラム上の実測出力: `2:5:5`

Property専用の名前付き添字・暗黙型変換・value引数書戻しを独立したソースで実行し、期待値と一致した。

## 判定
判定状態: `verified-no-bug`

Property専用の名前付き引数・型変換・実効ByVal境界を確認できたため、新規バグなしと判定する。
