# EV-00798の再評価

## 評価内容
Property Letの暗黙ByRef、名前付き引数、型変換が、通常のByRef手続きと同じ書戻しを起こすかを再確認する。

## 実施方法
Property Letの明示・暗黙ByRef value引数と名前付き引数の境界を既存の最小回帰で実行し、Property内部の値と呼出元の値を分けて記録する。

## 期待値
プログラム上の期待出力: `5:5:6:6:False`

Property Let/Setのvalue引数は宣言がByRefでも代入形式では実効ByValであり、Property内部の変更は呼出元へ書き戻さない。名前付きByRefの通常手続き結果は別経路として混同しない。

## 結果
プログラム上の実測出力: `5:5:6:6:False`

Property value引数の回帰は一致したが、EV-00798が対象とした名前付き引数・型変換のProperty固有組合せを独立した出力として記録していなかった。

## 判定
判定状態: `blocked`

一部の実効ByVal境界は確認できたが、旧EVの対象全体を覆う具体的なProperty専用の名前付き引数・型変換結果が不足しているため、verified-no-bugとは確定しない。
