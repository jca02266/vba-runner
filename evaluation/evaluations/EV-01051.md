## 評価内容

`Option Base 1`を持つモジュールで、UDTメンバー配列の下限を省略した場合の境界を評価する。

## 実施方法

```vba
Option Base 1
Type IndexedRecord
    Values(2) As Integer
End Type

Function RunCase() As String
    Dim record As IndexedRecord
    RunCase = CStr(LBound(record.Values)) & ":" & CStr(UBound(record.Values))
End Function
```

## 期待値

期待出力：`1:2`

省略下限は宣言を所有するモジュールの`Option Base 1`を使う。

## 結果

修正前の実測出力：`0:2`

UDT専用の境界解決が省略下限を常に0としていた。共通境界解決へ移行後は`1:2`となった。

## 判定

判定状態: fixed

既存BUG-00620の設計原因がOption Base経路にも及ぶことを確認し、共通解決で修正した。
