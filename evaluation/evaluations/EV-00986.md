## 評価内容

On GoToの分岐番号にNullを渡したとき、汎用数値変換前にNull契約を適用できるかを確認する。

## 実施方法

```vba
Function TestOnGoToNull() As Long
    On Error Resume Next
    On Null GoTo Label1, Label2
    TestOnGoToNull = Err.Number
    Exit Function
Label1:
    TestOnGoToNull = 111
    Exit Function
Label2:
    TestOnGoToNull = 222
End Function
```

## 期待値

プログラム上の期待出力: `ON_GOTO_NULL ERR=94`。
Error 94（Invalid use of Null）を期待する。

## 結果

プログラム上の実測出力: `ON_GOTO_NULL ERR=94`。
RunnerはError 94を返す回帰テストに合格し、Excel実機も `XL-264 ON_GOTO_NULL ERR=94` で一致した。

## 判定

判定状態: verified-no-bug
