## 評価内容

On GoToの分岐番号にNullを渡したとき、汎用数値変換前にNull契約を適用できるかを確認する。

## 実施方法

```vba
Function TestOnGoToNull() As Long
    On Error Resume Next
    On Null GoTo Label1, Label2
    TestOnGoToNull = Err.Number
    Exit Function
Label1:
    TestOnGoToNull = 111
    Exit Function
Label2:
    TestOnGoToNull = 222
End Function
```
