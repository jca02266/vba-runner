# For Each Option Base 1配列境界

`Option Base 1`で`Array("A", "B")`をFor Each列挙すると、修正前runnerは内部の先頭
フィラーを含め`[undefined][A][B]`を返した。VBAは配列要素だけを`[A][B]`として列挙する。
一次元配列の共通flatten経路で`vbaBase`から列挙を開始し、回帰テストを追加した。
