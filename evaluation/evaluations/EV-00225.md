# Like文字クラス境界

## 再現

`Option Compare Text` と `Option Compare Binary` を別モジュールに定義して同じEvaluatorへ
ロードすると、Text側の関数までBinary比較になった。期待値はText側 `T`、Binary側 `F` だが、
修正前は両方 `F` だった。

また、次のLike式は修正前にFalseだった。

```vba
"]" Like "[]]"
```

## 原因と修正

比較モードをモジュール名ごとのMapへ保存し、実行中モジュールに応じてLike、通常比較、
標準関数の比較モードを解決するよう変更した。Like文字クラスでは最初の `]` を終端では
なく文字クラス要素として扱うようにした。

## 回帰

`tests/spec/like-boundary.test.ts` を追加し、Option Compareのモジュール分離と閉じ括弧の
Likeクラスを固定した。既存のOption Compare/演算子テストも通過した。
