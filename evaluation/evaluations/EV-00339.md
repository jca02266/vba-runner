# MkDir既存パス境界

既存ディレクトリへの2回目の`MkDir`は修正前、recursive作成により成功していた。
また、親ディレクトリが存在しないパスも自動作成されていた。VBAでは前者が
Error 75、後者がError 76である。

対象パスと親パスを事前検証し、単一階層だけを作る実装へ修正した。両境界を回帰
テストで固定した。
