# Namespace Tier 6名前付き引数検査

## 再現

モジュール名 `Range` を `VbaNamespaceRef` として登録し、ExcelスタブをTier 6の
defaultBindingObjectに設定した状態で、次を実行した。

```vba
Function Exercise() As String
    On Error Resume Next
    Exercise = CStr(Range(bogus:="A1").Address) & ":" & CStr(Err.Number)
End Function
```

修正前は未知名 `bogus:=` が位置引数化され、`$A$1:0` が返った。期待値はError 448
（Named argument not found）である。

## 原因と修正

VbaNamespaceRefのTier 6 fallbackが通常の`resolveCallArgs`を迂回していた。Tier 6関数を
引数メタデータ経由で呼び出し、さらにoverload binderでも既知パラメーター名を事前に
照合するよう修正した。

## 検証

独立評価ではseed `0, 1, 42, -3`、位置引数、有効なCell1指定、未知bogus指定を確認した。
focused testsとしてTier 6、名前付き引数、評価状態CLIを実行し、すべて成功した。
