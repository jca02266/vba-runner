## 評価内容

`Option Compare Text` と `Option Compare Binary` の `Select Case value` に対して、
`Case "A" To "E"` の範囲比較が大文字小文字、アクセント付き文字、範囲外文字を
正しく分類するかを確認する。

## 実施方法

次の2モジュールと呼出し用Subを実行し、同じ入力行列を返す。

```vba
' TextModule
Option Compare Text
Function ProbeText(ByVal value As String) As String
    Select Case value
        Case "A" To "E": ProbeText = "hit"
        Case Else: ProbeText = "else"
    End Select
End Function

' BinaryModule
Option Compare Binary
Function ProbeBinary(ByVal value As String) As String
    Select Case value
        Case "A" To "E": ProbeBinary = "hit"
        Case Else: ProbeBinary = "else"
    End Select
End Function

' Standard module
Sub RunMatrix()
    Dim values, i As Long, textLine As String, binaryLine As String
    values = Array("A", "a", "À", "à", "Ê", "ê", "E", "Z")
    For i = LBound(values) To UBound(values)
        If i > 0 Then textLine = textLine & ",": binaryLine = binaryLine & ","
        textLine = textLine & TextModule.ProbeText(CStr(values(i)))
        binaryLine = binaryLine & BinaryModule.ProbeBinary(CStr(values(i)))
    Next i
    Debug.Print "Text=" & textLine & "|Binary=" & binaryLine
End Sub
```

入力は `A`, `a`, `À`, `à`, `Ê`, `ê`, `E`, `Z` とし、各関数の戻り値を連結して比較する。

## 期待値

プログラム上の期待出力: `Text=hit,hit,hit,hit,else,else,hit,else|Binary=hit,else,else,else,else,else,hit,else`

文章としては、Textはロケール順のアクセント境界を保持し、Binaryは大文字のASCII範囲
だけを受け入れることを期待する。

## 結果

プログラム上の実測出力: `Text=hit,hit,hit,hit,else,else,hit,else|Binary=hit,else,else,else,else,else,hit,else`

Text/Binaryそれぞれの範囲判定は期待値と一致し、Runnerの再現可能な差異は確認できなかった。

## 判定

判定状態: verified-no-bug

Select Caseの比較モードとアクセント境界は検証済みで、新規Findingは作成しない。
`Like`パターンの無効構文やExcel固有のロケール差はこの評価の対象外である。
