## 評価内容

UDT配列を`TypeName`などの実行時バインディング関数へ渡した場合にExcelでコンパイルエラーとなる境界を`CompileError.bas`で分離確認する。

## 実施方法

`CompileError.bas`の最小ケースをRunnerのprecheckで実行し、Excel実機で確認したコンパイルエラーと比較する。

## 期待値

プログラム上の期待出力: `CompileError=public object module UDT restriction`。

文章での期待: UDT配列を実行時バインディング関数へ渡す操作は、公開オブジェクトモジュール以外ではコンパイル段階で拒否される。

## 結果

プログラム上の実測出力: `Excel=compile-error(public object module UDT), Runner=accepted`。

Excel実機ではUDT配列を`TypeName`へ渡した時点でコンパイルエラーになった。Runnerにも同じ事前検査を追加し、回帰テストを通過させた。

## 判定

判定状態: fixed。

Excel実機結果でコンパイルエラーを確認し、vba-runnerの検出漏れを修正した。
