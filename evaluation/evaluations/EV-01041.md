## 評価内容

ClassのDate配列ByRef引数について、通常のメソッド呼出しとCallByNameのVbMethod呼出しで、
呼出し先による配列要素の書戻しが一致するかを確認する。

## 実施方法

```vba
' Class module: DateMutator
Public Sub TouchArr(ByRef values() As Date)
    values(0) = CDate(0)
End Sub

' Standard module
Function RunCase() As String
    Dim m As New DateMutator
    Dim direct(0 To 0) As Date
    Dim dynamic(0 To 0) As Date
    direct(0) = CDate("2024-01-02")
    dynamic(0) = CDate("2024-01-02")
    m.TouchArr direct
    CallByName m, "TouchArr", VbMethod, dynamic
    RunCase = DateKey(direct(0)) & "|" & DateKey(dynamic(0))
End Function

Function DateKey(ByVal value As Date) As String
    DateKey = CStr(Year(value)) & "-" & CStr(Month(value)) & "-" & CStr(Day(value))
End Function
```

同じ初期値のDate配列を2つ用意し、通常呼出しとCallByName呼出しの結果を比較した。

## 期待値

期待出力：`1899-12-30|1899-12-30`

両経路が配列要素を同じDateのゼロ値へ書き戻すことを期待する。

## 結果

実測出力：`1899-12-30|1899-12-30`

Runnerは通常呼出しとCallByNameの双方で同じDate配列要素を書き戻した。

## 判定

判定状態: verified-no-bug

対象のRunner経路で不一致は再現せず、新規Findingは確認されなかった。COM実オブジェクトの
Date配列ByRef契約はこの評価の対象外である。
