## 評価内容

空文字列をFormatへ渡したとき、単一・複数セクションの数値・日付書式で
どのセクションが選択されるかをExcelとRunnerで照合する。

## 実施方法

```vba
Public Sub RunFormatMatrixVerification()
    ' FormatMatrixVerification.bas の RunFormatMatrixVerification を実行する。
    ' XL-199 は次の5ケースを同じマトリックス行として出力する。
    ' @;EMPTY / 0.00;NEG;ZERO;NULL / yyyy-mm-dd;EMPTY
    ' 0.00;yyyy-mm-dd;EMPTY / 0.00;NEG;ZERO;EMPTY
End Sub
```

## 期待値

期待出力: （Excel実測値）
`XL-199-AT-EMPTY=EMPTY`、`XL-199-NUM-EMPTY=`、
`XL-199-DATE-EMPTY=`、`XL-199-NUM-DATE-EMPTY=`、
`XL-199-NUM-NEG-ZERO-EMPTY=`。

空文字列はNullやEmptyとは異なるString値として扱い、各書式セクションの
選択結果をケースごとに比較する。

## 結果

実測出力: （RunnerおよびExcel）
`XL-199-AT-EMPTY=EMPTY`、`XL-199-NUM-EMPTY=`、
`XL-199-DATE-EMPTY=`、`XL-199-NUM-DATE-EMPTY=`、
`XL-199-NUM-NEG-ZERO-EMPTY=`。

Excel実測値は `tests/excel/queue/FormatMatrix.result` のXL-199に記録され、
5ケースすべてRunnerと一致した。

## 判定

判定状態: verified-no-bug

FormatMatrixVerification.basへXL-199の5ケースを追加し、t.xlsmを再生成した。
実機結果、完了マーカー、ソースハッシュを`excel-sync`で確認したうえで、
Runnerとの一致を検証した。
