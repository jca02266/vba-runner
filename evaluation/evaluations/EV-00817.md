## 評価内容

空文字列をFormatへ渡したとき、単一・複数セクションの数値・日付書式で
どのセクションが選択されるかをExcelとRunnerで照合する。

## 実施方法

```vba
Public Sub RunFormatMatrixVerification()
    ' FormatMatrixVerification.bas の RunFormatMatrixVerification を実行する。
    ' XL-199 は次の5ケースを同じマトリックス行として出力する。
    ' @;EMPTY / 0.00;NEG;ZERO;NULL / yyyy-mm-dd;EMPTY
    ' 0.00;yyyy-mm-dd;EMPTY / 0.00;NEG;ZERO;EMPTY
End Sub
```

## 期待値

プログラム上の期待出力: `XL-199-*` の5ケースについて、Excelの実測値を正本とする。

空文字列はNullやEmptyとは異なるString値であるため、単一の文字列プレースホルダー、
数値セクション、日付セクション、3/4セクションで選択規則が同じとは仮定しない。
実機結果を取得し、ケースごとにRunnerとの差異を判定する。

## 結果

プログラム上の実測出力: `XL-199` は実機確認待ち。

Runnerの先行確認では `EMPTY|||||` となったが、Excelの対応結果がないため、
この時点ではバグ・仕様差を確定しない。

## 判定

判定状態: needs-excel-probe

FormatMatrixVerification.basへXL-199の5ケースを追加し、t.xlsmを再生成した。
実機結果取得後に`excel-sync`で同期状態を確認してから終端判定する。
