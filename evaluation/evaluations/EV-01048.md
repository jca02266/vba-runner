## 評価内容

CallByNameでDate ByRef引数へNullを渡した場合の型変換とエラー伝播を確認する。

## 実施方法

```vba
' Class module: DateMutator
Public Seen As Date
Public Sub Touch(ByRef value As Date)
    value = DateSerial(1899, 12, 30)
    Seen = value
End Sub

' Standard module
Function RunCase() As String
    Dim m As New DateMutator, errNo As Long
    On Error Resume Next
    Err.Clear
    CallByName m, "Touch", VbMethod, Null
    errNo = Err.Number
    On Error GoTo 0
    RunCase = CStr(errNo) & "|" & CStr(Year(m.Seen)) & "-" & CStr(Month(m.Seen)) & "-" & CStr(Day(m.Seen))
End Function
```

## 期待値

期待出力：`13|1899-12-30`

Runnerの動的ByRef境界ではNullの書戻し契約を型不一致13として扱い、呼出し先のDate代入結果を保持したままエラーを返すことを期待する。Excel/COMの最終エラー番号は未照合である。

## 結果

実測出力：`13|1899-12-30`

Runnerは呼出し先のDate代入を実行してから、Nullの動的ByRef書戻し境界でエラー13を返した。

## 判定

判定状態: verified-no-bug

Runnerの動的ByRef境界では、呼出し先の実行結果を保持したままエラー13を返す挙動を確認した。Excel/COMの最終エラー番号は未照合のため、この判定はRunner内Class経路に限定する。
