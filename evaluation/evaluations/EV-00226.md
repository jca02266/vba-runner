# Option Compareのクラス・Select Case経路

## 再現

`Option Compare Text` を含むクラスモジュールのメソッドで、`"ABC" Like "abc"` が
Falseになった。また、Textモジュールの次のSelect Caseが一致しなかった。

```vba
Option Compare Text
Select Case "abc"
    Case "ABC": result = "matched"
End Select
```

## 原因と修正

クラス用パーサーがOption Compare文を未知トークンとして破棄し、クラス手続きにも比較
モードを関連付けていなかった。クラスのOption CompareをASTへ保持し、クラス手続きの
実行モジュール名を設定した。Select Caseの文字列比較にもモジュール比較モードを適用した。

## 回帰

`tests/spec/like-boundary.test.ts` にクラス/Select Caseの回帰を追加し、型検査とLike・
Option Compare・演算子既存テストを通過した。
