## 評価内容

標準モジュール内のPrivate UDTを戻り値型に持つPublic Functionを同一モジュールから呼び出し、標準モジュールに対する仕様制約がないことを確認する。別モジュール側でPrivate型を非修飾宣言する経路は別評価に分離する。

## 実施方法

```vba
' ModuleA
Option Explicit
Private Type T
    X As Long
End Type

Public Function Make() As T
    Dim value As T
    value.X = 7
    Make = value
End Function

同一モジュールの`Make`を実行し、戻り値UDTのメンバーを確認する。
```

`ModuleB.Caller`を実行し、Private UDTの戻り値がPublic境界を越えないことを確認する。

## 期待値

プログラム上の期待出力: `Make`の戻り値の`X`メンバーは`7`になる。

文章での期待: MS-VBALのPrivate UDT戻り値制約はクラスモジュールのPublic手続きに対するものであり、標準モジュールのPublic Functionを一律に拒否する規則ではない。

## 結果

プログラム上の実測出力: Runnerは`Make().X=7`を返した。

文章での結果: 標準モジュール内のPublic FunctionによるPrivate UDT戻り値は仕様に沿って実行できた。別モジュール側の未解決Private型を同じ評価で扱わないよう、別候補へ分離する。

## 判定

判定状態: verified-no-bug（標準モジュールのPrivate UDT戻り値は仕様適用範囲内）。
