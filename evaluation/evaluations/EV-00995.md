## 評価内容

Private UDTを戻り値型に持つPublic Functionを別モジュールから呼び出せるかを確認する。

## 実施方法

```vba
' ModuleA
Option Explicit
Private Type T
    X As Long
End Type

Public Function Make() As T
    Dim value As T
    value.X = 7
    Make = value
End Function

' ModuleB
Option Explicit
Public Function Caller() As Long
    Dim value As T
    value = ModuleA.Make()
    Caller = value.X
End Function
```

`ModuleB.Caller`を実行し、Private UDTの戻り値がPublic境界を越えないことを確認する。

## 期待値

プログラム上の期待出力: `Caller`はPrivate UDTを戻り値として解決できず、コンパイル時に型可視性エラーになる（この期待は仕様上の適用範囲を追加確認する）。

文章での期待: Private UDTは宣言モジュール内だけで有効であり、Public Functionの戻り値型を通じて別モジュールへ公開されない。

## 結果

プログラム上の実測出力: Runnerは`Caller=7`を返した。

文章での結果: RunnerではPrivate UDTを戻り値にしたPublic Functionが別モジュールから呼び出せることを観測した。これは仕様適用範囲を確認するまで、バグ確定ではなく仕様との差異候補として扱う。

## 判定

判定状態: in-progress（Runnerの挙動は再現したが、Public Functionの戻り値に対する仕様適用範囲を確認中）。
