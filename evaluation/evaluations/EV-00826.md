## 評価内容

Property Let/Setの暗黙の右辺値引数が、必須インデックス引数の省略を誤って許可しないかを評価する。

## 実施方法

```vba
Class ArityProperty
    Public Property Get Status() As Long
        Status = 0
    End Property
    Public Property Let Value(index As Long, value As Long)
        Status = 1
    End Property
    Public Property Set ObjectValue(index As Long, value As Object)
        Status = 1
    End Property
End Class

Sub Caller()
    Dim instance As New ArityProperty
    instance.Value = 2
End Sub
```

Property Setも同じ形で、`Set instance.ObjectValue = child`を実行する。

## 期待値

期待出力: `Argument not optional`

Property Let/Setの右辺値は暗黙の最終引数だが、先行する必須インデックスを補完しない。

## 結果

実測出力: 修正前はProperty Let/Setが実行され、修正後は`Argument not optional`となった。

Runnerは右辺値を追加する前に必須インデックスを検査するようになり、Let/Setの両経路で一致した。

## 判定

判定状態: fixed

直接原因を修正し、Property Let/Set双方の回帰テストが通過した。動的COMやWithの共通化は
RC-00070の横展開として未確定である。
