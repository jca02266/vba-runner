## 評価内容

Public UDTを定義したモジュールでの裸名、別モジュールでの修飾名、Function戻り値をVariantへ格納した場合の`TypeName`と`VarType`を比較する。

## 実施方法

```vba
' Producer.bas
Option Explicit
Public Type Point
    X As Long
End Type
Public Function Make() As Point
    Dim p As Point
    p.X = 3
    Make = p
End Function
Public Function LocalInfo() As String
    Dim p As Point
    LocalInfo = TypeName(p) & ":" & CStr(VarType(p))
End Function

' Consumer.bas
Option Explicit
Public Function QualifiedInfo() As String
    Dim p As Producer.Point
    p.X = 3
    QualifiedInfo = TypeName(p) & ":" & CStr(VarType(p))
End Function
Public Function ReturnInfo() As String
    Dim p As Variant
    p = Producer.Make()
    ReturnInfo = TypeName(p) & ":" & CStr(VarType(p))
End Function
```

3つのPublic Functionを実行し、表示された型名とVarTypeを比較する。

## 期待値

プログラム上の期待出力: `LocalInfo=Point:36; QualifiedInfo=Producer.Point:36; ReturnInfo=Point:36`。

文章での期待: 裸名と修飾名は同じPublic UDTを指し、Variantへ戻してもUDT性を表す`VarType=36`を維持する。

## 結果

プログラム上の実測出力: `local=Point:36; qualified=Producer.Point:36; returned=Point:36`。

文章での結果: すべてUDTとして認識され、VarTypeは36で一致した。修飾名のTypeName表示差は表記上の差であり、型同一性や実体化の不整合ではなかった。

## 判定

判定状態: verified-no-bug。

独立エージェントによるメタモルフィック比較で再現し、現行実装に新規の型性欠落は確認されなかった。ExcelでのTypeName文字列の厳密な表記差は別途未確定だが、現時点で仕様バグとは判定しない。
