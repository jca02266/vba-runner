## 評価内容

CollectionのFor Each制御変数をLongに固定し、列挙値に文字列を含めた場合の
`On Error Resume Next`継続位置を確認する。

## 実施方法

```vba
Function ArrayPath() As String
    Dim value As Long, output As String
    On Error Resume Next
    For Each value In Array(1, "bad", 3)
        output = output & CStr(value) & ","
    Next
    ArrayPath = output & "|" & CStr(Err.Number)
End Function
```

Collection経路は別の横展開調査で確認する。

## 期待値

プログラム上の期待出力: `1,3,|13`
文章での期待: Resume Nextが制御変数代入のエラー境界にも適用され、For Each列挙を途中終了させない。

## 結果

プログラム上の実測出力: RunnerはCollectionで`1,|13`となり、文字列要素以降を処理しなかった。
Excel実機確認: 未実施。

## 判定

判定状態: needs-excel-probe（旧プローブはExcelのコンパイルエラー境界と重複するため、再設計待ち）。
