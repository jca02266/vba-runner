# MIRR金利下限境界

`MIRR(Array(-100, 100), -1.1, 0.1)` は現行runnerでErrorなし、
`MIRR(Array(-100, 100), 0.1, -1)` はError 6となった。金融関数の金利は通常
`1 + rate > 0` が必要だが、MIRRの実Excelでのエラー番号と境界を確認してから
共通検証を変更するため、実機照合待ちとして記録する。

照合対象:

```vba
Debug.Print MIRR(Array(-100, 100), -1.1, 0.1)
Debug.Print MIRR(Array(-100, 100), 0.1, -1)
```
