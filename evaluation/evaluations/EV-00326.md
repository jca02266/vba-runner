# MIRR金利下限境界

XL-037のExcel結果では`MIRR`のFinanceRate `-1.1`が`2.22044604925031E-16`、
ReinvestRate `-1`がError 5となった。runnerはそれぞれ`0`とError 6であり、
実機差異を`BUG-00372`として確定した。

照合対象:

```vba
Debug.Print MIRR(Array(-100, 100), -1.1, 0.1)
Debug.Print MIRR(Array(-100, 100), 0.1, -1)
```
