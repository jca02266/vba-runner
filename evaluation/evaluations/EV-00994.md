## 評価内容

標準モジュール内のPrivate UDTを使うPublic手続きの合法な経路と、別モジュールから同じPrivate型を参照する経路を比較する。

## 実施方法

```vba
' ModuleA
Option Explicit
Private Type T
    X As Long
End Type
Public Function AcceptPrivate(ByRef value As T) As Long
    AcceptPrivate = value.X
End Function

' ModuleB
Option Explicit
Public Function Caller() As Long
    Dim value As T
    value.X = 5
    Caller = ModuleA.AcceptPrivate(value)
End Function
```

`ModuleB.Caller`を実行し、不可視なPrivate UDT参照が実行時へ遅延しないことを確認する。

## 期待値

プログラム上の期待出力: `Caller`はコンパイル時に型不一致または未定義エラーになる。

文章での期待: 標準モジュールPublic手続きのPrivate UDT利用は合法だが、Private型の宣言自体は所有モジュール外から参照できない。

## 結果

プログラム上の実測出力: 修正前は実行時エラー91へ遅延した。修正後は`Compile error: Type 'T' is not accessible in this module`となる。

文章での結果: 合法な同一モジュール経路を維持しつつ、別モジュールの不可視型参照を共有precheckで拒否できるようになった。

## 判定

判定状態: fixed。
