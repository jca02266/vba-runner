## 評価内容

Private Typeを引数に持つPublic手続きが別モジュールから呼び出せるかを確認する。

## 実施方法

```vba
' ModuleA
Option Explicit
Private Type T
    X As Long
End Type
Public Function AcceptPrivate(ByRef value As T) As Long
    AcceptPrivate = value.X
End Function

' ModuleB
Option Explicit
Public Function Caller() As Long
    Dim value As T
    value.X = 5
    Caller = ModuleA.AcceptPrivate(value)
End Function
```

`ModuleB.Caller`を実行し、Private UDTがPublic手続きの境界を越えないことを確認する。

## 期待値

プログラム上の期待出力: `Caller`はPrivate型を解決できず、コンパイル時に型不一致または未定義エラーになる。

文章での期待: Private UDTは所有モジュール内だけで有効であり、Public手続きの引数型を通じて別モジュールへ公開されない。

## 結果

プログラム上の実測出力: Runnerは`Caller=5`を返した。

文章での結果: Private UDTを使うPublic手続きが別モジュールから呼び出せ、Private型が境界を越えて利用できる不一致を再現した。

## 判定

判定状態: bug-found（Private UDTのPublic引数境界漏洩を再現）。
