## 評価内容

CVarへLong配列とVBAクラスを渡し、Variant化後のTypeName、VarType、IsArray、IsObject、配列要素とクラスメンバーの参照結果を確認する。

## 実施方法

次の自己完結VBAを実行する。

```vb
Option Explicit
Class Box
    Public Value As Long
End Class
Public Function Probe() As String
    Dim values(0 To 1) As Long, v As Variant, box As Box, out As String
    values(0) = 4: values(1) = 9
    v = CVar(values)
    out = "ARRAY=" & TypeName(v) & ":" & CStr(VarType(v)) & ":" & CStr(IsArray(v)) & ":" & CStr(v(1))
    Set box = New Box: box.Value = 7
    Set v = CVar(box)
    out = out & "|OBJECT=" & TypeName(v) & ":" & CStr(IsObject(v)) & ":" & CStr(v.Value)
    Probe = out
End Function
```

## 期待値

プログラムとしての期待出力:

```text
ARRAY=Long():8195:True:9|OBJECT=Box:True:7
```

Long配列は`Long()`の配列型とVarTypeの配列ビットを保持し、要素9を読み出せる。クラスはBoxのObject参照として保持し、メンバーValueの7を読み出せることを期待する。

## 結果

実測出力:

```text
ARRAY=Long():8195:True:9|OBJECT=Box:True:7
```

配列の形状・要素型・要素値と、クラス参照・メンバー値が期待どおり保持された。CVarが配列をスカラーへ変形したり、Objectを既定値へ誤展開したりする差異は確認されなかった。

## 判定

判定状態: verified-no-bug

CVarの複合値保持経路は期待どおりだった。配列のByValコピーやObjectのProperty Set書戻しは別の評価経路として扱う。
