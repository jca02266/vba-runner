## 評価内容

2020年末から2022年初の週境界について、月曜始まり・日曜始まりとFirstFourDays・FirstJan1の週番号を比較する。

## 実施方法

`tests/spec/date-week-boundary-matrix.test.ts`を実行し、各日付のDatePart("ww")とWeekdayを出力する。

## 期待値

期待出力:

```text
DATE-WEEK 2020-12-28 => 53,53,1,2
DATE-WEEK 2021-01-01 => 53,1,5,6
DATE-WEEK 2021-01-03 => 53,2,7,1
DATE-WEEK 2021-01-04 => 1,2,1,2
DATE-WEEK 2022-01-01 => 52,1,6,7
DATE-WEEK 2022-01-03 => 1,2,1,2
```

## 結果

実測出力:

```text
DATE-WEEK 2020-12-28 => 53,53,1,2
DATE-WEEK 2021-01-01 => 53,1,5,6
DATE-WEEK 2021-01-03 => 53,2,7,1
DATE-WEEK 2021-01-04 => 1,2,1,2
DATE-WEEK 2022-01-01 => 52,1,6,7
DATE-WEEK 2022-01-03 => 1,2,1,2
```

6ケースすべてで期待値と実測値が一致した。

## 判定

判定状態: verified-no-bug

年初の週番号、週開始日、FirstWeekOfYearの境界に新しい差異は確認されなかった。
