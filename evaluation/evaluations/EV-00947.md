## 評価内容

MIRRで確認した`ValueArray() As Double`契約をIRRとNPVへ横展開する。
Currency()およびVariant()配列を渡したときのコンパイル時エラーをRunnerで再現し、
Excelのコンパイル結果と一致するか確認する。

## 実施方法

`tests/vba/CompileError.bas`の次の4ケースを個別のコンパイル単位として実行する。

- `IRR(Currency())`
- `IRR(Variant())`
- `NPV(Currency())`
- `NPV(Variant())`

Runner側では`registerFinancialFunctions`のIRR・NPVの`ValueArray`へ
`arrayElementType: 'Double'`を設定し、生成された`tests/spec/vba_compile_error.test.ts`
を実行する。Excel側では同じ4ケースを`CompileError.bas`で確認する。

## 期待値

期待出力:

```text
IRR(Currency()) COMPILE=ERROR MESSAGE=[array or user-defined type required]
IRR(Variant()) COMPILE=ERROR MESSAGE=[array or user-defined type required]
NPV(Currency()) COMPILE=ERROR MESSAGE=[array or user-defined type required]
NPV(Variant()) COMPILE=ERROR MESSAGE=[array or user-defined type required]
```

## 結果

実測出力:

```text
Runner: 56 cases passed, including the four IRR/NPV cases.
Excel: 実機結果待ち
```

## 判定

`in-progress`。Runner側の型契約と回帰テストは追加済みだが、Excel実機の4ケースを
確認するまで評価を確定しない。
