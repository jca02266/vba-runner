## 評価内容

MIRRで確認した`ValueArray() As Double`契約をIRRとNPVへ横展開する。
Currency()およびSingle()配列を渡したときのコンパイル時エラーをRunnerで再現し、
Excelのコンパイル結果と一致するか確認する。

## 実施方法

`tests/vba/CompileError.bas`の次の2ケースを個別のコンパイル単位として実行する。

- `IRR(Currency())`
- `NPV(Single())`

Runner側では`registerFinancialFunctions`のIRR・NPVの`ValueArray`へ
`arrayElementType: 'Double'`を設定した実装を実行する。Excel側では
同じ2ケースをCompileErrorプローブで確認する。コンパイルエラーで
マクロ実行が停止するため、分離Excelキューには登録しない。

## 期待値

期待出力:

```text
IRR(Currency()) COMPILE=ERROR MESSAGE=[array or user-defined type required]
NPV(Single()) COMPILE=ERROR MESSAGE=[array or user-defined type required]
```

## 結果

実測出力:

```text
Runner: IRR(Currency()) と NPV(Single()) は array or user-defined type required。
Excel: IRR(Currency()) と NPV(Single()) は「配列またはユーザー定義型を指定してください。」
```

## 判定

判定状態: verified-no-bug

Runner側の型契約とExcel実機結果が一致した。Variant配列・直接Array式は同じ
ValueArray型契約の横展開であり、今回の代表ケースの結果から追加照合は不要と判断した。
