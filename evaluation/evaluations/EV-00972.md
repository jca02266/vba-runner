## 評価内容

ホストからVariantへ注入した素のJavaScript Booleanが、文字列化・型情報・単項演算でVBA Booleanとして扱われるか確認する。

## 実施方法

```vba
Function Display(value As Variant) As String
    Display = CStr(value) & "|" & TypeName(value) & "|" & CStr(VarType(value))
End Function
Function Unary(value As Variant) As Long
    Unary = -value
End Function
```

同じホスト値`true`と`false`を各手続きへVariant引数として渡す。

## 期待値

プログラム上の期待出力: `true`は`True|Boolean|11`および単項マイナス`1`、`false`は`False|Boolean|11`および`0`。
文章での期待: ホストBooleanがVBA Booleanの表示・型情報・数値意味を保持する。

## 結果

プログラム上の実測出力（修正前）: `CStr(true)="true"`、`TypeName(true)="Object"`、`VarType(true)=12`を確認した。
修正後のプログラム上の実測出力: `CStr(true)="True"`、`TypeName(true)="Boolean"`、`VarType(true)=11`、単項マイナス`1`。
Excel実機確認: Runner公開APIのホスト値契約であり不要。

## 判定

判定状態: fixed（ホストBooleanの共通正規化を拡張し、回帰テストを追加）。
