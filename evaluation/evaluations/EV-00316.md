# Shellと環境変数のNull境界

独立評価で `Shell("echo", Null)` がError 13、`Environ(Null)` が空文字列に
なることを再現した。Nullを具体的な引数へ渡す既存のVBA境界と異なるため、
共通の `rejectNullArgument` でError 94へ統一した。

最小再現は次のとおり。

```vba
Debug.Print Shell("echo", Null)
Debug.Print Environ(Null)
```

回帰テストは `tests/spec/builtins.test.ts` に追加し、TypeScript型検査と組み込み
テストを通過した。
