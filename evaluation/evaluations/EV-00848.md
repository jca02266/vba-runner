## 評価内容

通常Function、Call文、ByRef Sub、クラスFunction、Property Getについて、必須引数の後ろのOptional中間省略と、後続引数の名前付き指定を組み合わせた引数整列を確認する。

## 実施方法

`F(a As Long, Optional b As Long = 7, Optional c As Long = 9)`を用意し、`F(1,,c:=11)`、`F(1,c:=11)`、`F(c:=11,a:=2)`、Call形式を実行した。必須引数を省略するケース、ByRef書戻し、クラスFunctionとProperty Getでも同じ整列を確認した。

## 期待値

期待出力：

```text
F(1,,c:=11) = 1:7:11
F(1,c:=11) = 1:7:11
F(c:=11,a:=2) = 2:7:11
Call形式も同じ値
必須引数の省略 = Error 449
ByRef書戻しは保持
```

文章による期待値：省略されたOptionalスロットには既定値を適用し、名前付き引数は宣言順へ整列する。必須スロットの省略だけは引数不足エラーになる。

## 結果

実測出力：

```text
F(1,,c:=11) -> 1:7:11
F(1,c:=11) -> 1:7:11
F(c:=11,a:=2) -> 2:7:11
Call F(1,,c:=11) -> 正常
必須引数省略 -> Error 449
ByRef Sub -> 101:21
クラスFunction/Property Get -> 1:7:11|1:7:11
```

文章による結果：通常手続き、Call、ByRef、クラス、Propertyの各経路でOptionalの既定値と名前付き引数の整列が一致し、新しい差異は確認されなかった。

## 判定

判定状態: verified-no-bug

Optional中間省略、名前付き末尾引数、必須引数エラー、ByRef書戻し、クラスおよびProperty経路を確認した。今回の評価範囲では修正不要である。
