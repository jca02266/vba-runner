# 宣言型Longサフィックスと複合演算子

`ByRef n&` の `n& + 1` が文字列連結相当の`41`になり、減算はError 13、乗算・除算は構文エラーになっていた。Lexerが識別子直後の`&`をLongサフィックスとして扱う条件を、前文字が識別子であることと算術演算子境界に基づいて修正した。

独立評価と横展開調査で、同じLexer経路を使う標準手続き、クラス、Property、配列添字の候補を確認した。他の型サフィックスは期待どおりで、実Excelでの空白・改行をまたぐ連結境界だけ未確定である。
