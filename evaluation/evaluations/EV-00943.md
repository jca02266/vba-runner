## 評価内容

固定長`Double()`の`flows=(-100, -50, 50, 100)`を使い、FinanceRateとReinvestRateへ
巨大な有限Doubleを渡したときの有限値、負の比率に対する非整数根、再投資powerの
Overflow、正キャッシュフローNPVのunderflowを区別して評価する。

## 実施方法

```vba
Private Sub VerifyMirrExtremeRateClassification()
    EmitMirrExtremeRateCase "FR+1E308", 1E+308, 0.12
    EmitMirrExtremeRateCase "FR-1E308", -1E+308, 0.12
    EmitMirrExtremeRateCase "RR+1E77", 0.1, 1E+77
    EmitMirrExtremeRateCase "RR+1E78", 0.1, 1E+78
    EmitMirrExtremeRateCase "RR-1E75", 0.1, -1E+75
    EmitMirrExtremeRateCase "RR+1E100", 0.1, 1E+100
    EmitMirrExtremeRateCase "RR+1E154", 0.1, 1E+154
    EmitMirrExtremeRateCase "RR+1E308", 0.1, 1E+308
End Sub

Private Sub EmitMirrExtremeRateCase(ByVal label As String, _
        ByVal financeRate As Double, _
        ByVal reinvestRate As Double)
    Dim flows(0 To 3) As Double, value As Variant, errNo As Long
    flows(0) = -100: flows(1) = -50: flows(2) = 50: flows(3) = 100
    On Error Resume Next
    Err.Clear
    value = Empty
    value = MIRR(flows, financeRate, reinvestRate)
    errNo = Err.Number
    EmitResult "XL-245 CASE=" & label & " ERR=" & CStr(errNo) & _
        " VALUE=[" & CStr(value) & "] TYPE=" & TypeName(value)
    On Error GoTo 0
End Sub

Private Sub EmitResult(ByVal text As String)
    Debug.Print text
End Sub
```

上記は評価単体で実行できるよう`EmitResult`を`Debug.Print`で定義した。
実機キューでは同名の共通出力手続きを使って結果ファイルにも記録する。

## 期待値

期待出力は、FinanceRateの最大級有限値2件とReinvestRate `1E+77`が有限のDouble、
負の比率に対する非整数根がError 5となり、再投資powerのOverflowをExcelが示す
Error番号がRunnerと一致することである。プログラム上はXL-245の8ケースすべてで
値、`Err.Number`、`TypeName`が一致することを期待する。

## 結果

Runner実測出力:

```text
XL-245 CASE=FR+1E308 ERR=0 VALUE=[0.15977799952979965] TYPE=Double
XL-245 CASE=FR-1E308 ERR=0 VALUE=[0.15977799952979965] TYPE=Double
XL-245 CASE=RR+1E77 ERR=0 VALUE=[3.25147861712846E+25] TYPE=Double
XL-245 CASE=RR+1E78 ERR=5 VALUE=[] TYPE=Empty
XL-245 CASE=RR-1E75 ERR=5 VALUE=[] TYPE=Empty
XL-245 CASE=RR+1E100 ERR=5 VALUE=[] TYPE=Empty
XL-245 CASE=RR+1E154 ERR=5 VALUE=[] TYPE=Empty
XL-245 CASE=RR+1E308 ERR=5 VALUE=[] TYPE=Empty
```

Runnerでは3ケースが有限のDoubleを返し、非整数根と中間Overflowを後段のError 5へ
分類した。`RR+1E154`と`RR+1E308`はNPVのunderflowとpowerのOverflowが同時に
起こるため、underflow単独のError規則を示すケースとは扱わない。Excel実機結果は
未取得である。
