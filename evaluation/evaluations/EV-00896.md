## 評価内容

Stringのcharacter引数へBooleanとDateを渡し、ランナーの結果をExcel実機の結果と比較して変換契約を確定する。

## 実施方法

`ExcelQueueVerification.bas` の `VerifyStringCharacterVariant` を実行し、`String(3, True)` と `String(3, CDate(65))` の結果およびErr.Numberを `XL-222` として記録する。ランナーでは同じ次のVBAを実行する。

```vb
Option Explicit
Public Function Probe() As String
    Dim value As String, errNo As Long, out As String
    On Error Resume Next
    Err.Clear: value = String(3, True): errNo = Err.Number
    out = "BOOL=" & value & " ERR=" & CStr(errNo)
    Err.Clear: value = String(3, CDate(65)): errNo = Err.Number
    Probe = out & "|DATE=" & value & " ERR=" & CStr(errNo)
End Function
```

## 期待値

プログラムとしての暫定期待出力:

```text
BOOL=TTT ERR=0|DATE=111 ERR=0
```

ただしBoolean・DateのVariantを数値コードとして扱うか文字列式として扱うかは、今回の仕様資料だけでは確定しないため、Excel実機結果を根拠として確定する。

## 結果

ランナー実測出力:

```text
BOOL=TTT ERR=0|DATE=111 ERR=0
```

Excel実機の`XL-222`結果は`BOOL= ERR=0`、`DATE=AAA ERR=0`であり、Runnerと異なった。

## 判定

判定状態: bug-found

ExcelのXL-222でBoolean・DateともRunnerと異なる結果を確認した。Stringのcharacter引数に
対する数値Variant共通判定の適用漏れとして記録する。
