## 評価内容

必須引数を持つProperty Getを括弧なしの値式として参照したとき、標準Functionと同じ
静的引数検査へ到達するかを確認する。

## 実施方法

```vba
Private Property Get MyPropertyHasArg(index As Long) As Long
    MyPropertyHasArg = index
End Property

Sub Case_property_get_without_required_argument()
    Dim value As Long
    value = MyPropertyHasArg
End Sub
```

クラス経路では`Property Get Item(index As Long)`を定義し、`result = instance.Item`を
同じように評価する。

## 期待値

期待出力: `Compile error: Argument not optional`

Property Getの裸参照は暗黙呼出しであり、必須引数を省略したまま実行時の関数値評価へ
進めてはならない。

## 結果

実測出力: 修正前はクラスProperty Getが実行時449となり、標準モジュールの裸参照は
静的検査を通らなかった。修正後は`Compile error: Argument not optional`となった。

CompileError.bas由来36ケース、Property Getを含むアリティ行列、既存Property解決テストが
通過した。

## 判定

判定状態: fixed

裸Property Getの静的検査を追加し、Property代入と明示Callを誤検出しないことも回帰で確認した。
Module修飾の裸参照はFZ-GRAMMAR-065へ分離する。
