# 名前付き引数重複とOptional省略

## 評価内容

独立評価では、Optional引数の省略・有効な名前付き引数・重複名前付き引数・位置引数との
衝突を、Class、Collection、配列、文字列、`On Error`、ループ、条件分岐と組み合わせて
複数seedで実行した。

独立評価は公開build成果物で重複指定が実行されたと報告したが、現行ソースを
`npx tsx /tmp/vba-runner-eval/repro-duplicate-named.ts` で再実行すると、両ケースとも
Error 450（Wrong number of arguments）になった。公開build成果物は開発中に更新されない
ことがあるため、この差は製品バグや未解決の実機照合項目ではなく、評価対象を混在させた
ことによる手順上の差分として除外する。

## 結論

Optional省略と有効な名前付き引数は正常で、重複・衝突は拒否される。公開成果物の
パリティ確認は、必要な場合に限りpublish前後の別評価として実施する。今回の評価では
修正コミットを作成しない。
