# 名前付き引数重複とOptional省略

## 評価内容

独立評価では、Optional引数の省略・有効な名前付き引数・重複名前付き引数・位置引数との
衝突を、Class、Collection、配列、文字列、`On Error`、ループ、条件分岐と組み合わせて
複数seedで実行した。

独立評価は公開build成果物で重複指定が実行されたと報告したが、現行ソースを
`npx tsx /tmp/vba-runner-eval/repro-duplicate-named.ts` で再実行すると、両ケースとも
Error 450（Wrong number of arguments）になった。従って現行ソースの製品バグとは判定しない。

## 結論

Optional省略と有効な名前付き引数は正常で、重複・衝突は拒否される。公開成果物との差は
別途リリースビルドの更新確認が必要だが、今回の評価では修正コミットを作成しない。
