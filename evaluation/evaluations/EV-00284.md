# Rateのゼロ利率解

独立評価で、`Rate(10, -10, 100, 0, 0, 0)` がError 5になる問題を確認した。
支払10回の現在価値100と各期支払-10は利率0で厳密に釣り合うため、期待値は
`0`である。Rateだけが利率係数と微分係数を独自計算していたため、0除算が発生した。

係数と微分係数を共通ヘルパーへ移し、利率0では解析的な値を返すよう修正した。
回帰テストで明示的なGuess=0の結果が`Err=0|0`になることを固定した。
