## 評価内容

DateSerialの月0/13、日0/32、閏日、2桁年、4桁年、負年を12ケースで確認する。

## 実施方法

`tests/spec/dateserial-boundary.test.ts`を実行し、各日付ケースの文字列表現とErr.Number、各年ケースのYearまたはエラーを出力する。

## 期待値

期待出力:

```text
DATE-SERIAL 2024,13,1 => 2025/01/01:ERR=0
DATE-SERIAL 2024,0,15 => 2023/12/15:ERR=0
DATE-SERIAL 2024,1,32 => 2024/02/01:ERR=0
DATE-SERIAL 2024,1,0 => 2023/12/31:ERR=0
DATE-SERIAL 2024,2,29 => 2024/02/29:ERR=0
DATE-SERIAL 2023,2,29 => 2023/03/01:ERR=0
DATE-SERIAL-YEAR 0 => 2000
DATE-SERIAL-YEAR 29 => 2029
DATE-SERIAL-YEAR 30 => 1930
DATE-SERIAL-YEAR 99 => 1999
DATE-SERIAL-YEAR 100 => 100
DATE-SERIAL-YEAR -1 => ERR=6
```

## 結果

実測出力:

```text
DATE-SERIAL 2024,13,1 => 2025/01/01:ERR=0
DATE-SERIAL 2024,0,15 => 2023/12/15:ERR=0
DATE-SERIAL 2024,1,32 => 2024/02/01:ERR=0
DATE-SERIAL 2024,1,0 => 2023/12/31:ERR=0
DATE-SERIAL 2024,2,29 => 2024/02/29:ERR=0
DATE-SERIAL 2023,2,29 => 2023/03/01:ERR=0
DATE-SERIAL-YEAR 0 => 2000
DATE-SERIAL-YEAR 29 => 2029
DATE-SERIAL-YEAR 30 => 1930
DATE-SERIAL-YEAR 99 => 1999
DATE-SERIAL-YEAR 100 => 100
DATE-SERIAL-YEAR -1 => ERR=6
```

12ケースすべてで期待値と実測値が一致した。

## 判定

判定状態: verified-no-bug

DateSerialの年補正、月日繰り上げ、閏日、負年エラーに新しい差異は確認されなかった。
