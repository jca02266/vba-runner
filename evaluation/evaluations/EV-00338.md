# ファイル番号Null境界

ファイル番号を受けるEOF/LOF/LOC/SeekにNullを渡すと、修正前はType mismatch
(Error 13)になった。VBAの期待値はInvalid use of Null (Error 94)である。

横展開でファイルI/O文のファイル番号評価にも同じ直接Number変換を確認し、共通の
Null検証経路へ置き換えた。filesystem-extraに4関数とOpenの回帰テストを追加した。
