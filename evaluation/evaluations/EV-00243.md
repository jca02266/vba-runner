# 複数ハンドルのLock範囲競合

独立評価では、Lock Read WriteとSharedのOpen競合がError 70となり、実ExcelのXL-019と
一致した。追加したXL-020で、Shared別ハンドルの交差Lockも実ExcelがError 70を返すことを
確認した。パス単位のLockレジストリとUnlock/Close時の解放を実装し、回帰テストで固定した。
