## 評価内容

`Asc(Chr(code))` のASCII境界と、コードページ依存となる非ASCII境界を確認した。

## 実施方法

```vba
Public Function Probe(ByVal code As Long) As Long
    Probe = Asc(Chr(code))
End Function
```

ASCII範囲と254・255を入力し、メタモーフィック検査および仕様本文を照合した。

## 期待値

期待出力：`Asc(Chr(1..127)) = 1..127`。128以上は仕様上、結果が実装定義であり、特定の数値一致を要求しない。

## 結果

実測出力：ASCII範囲は入力値と一致し、`Asc(Chr(254)) = 63730`、`Asc(Chr(255)) = 63731` だった。後二つはCP932のUnicode表現であり、仕様の実装定義範囲に該当する。

## 判定

判定状態: verified-no-bug

メタモーフィック検査が非ASCIIを無条件に往復すると誤検出することも確認した。これは探索器の仮定が過強であり、vba-runnerの不具合とは判定しない。
