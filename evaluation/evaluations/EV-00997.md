## 評価内容

クラスモジュール内のPrivate TypeをPublic Functionの戻り値型に指定した場合のエラー段階を確認する。

## 実施方法

```vba
' Holder.cls（クラスモジュール）
Option Explicit
Private Type Hidden
    Value As Long
End Type

Public Function MakeHidden() As Hidden
    Dim value As Hidden
    value.Value = 42
    MakeHidden = value
End Function

' Module1.bas
Option Explicit
Public Function Caller() As String
    Dim holder As New Holder
    Dim ignored As Variant
    On Error Resume Next
    Err.Clear
    ignored = holder.MakeHidden()
    Caller = "ERR=" & CStr(Err.Number) & ";DESC=" & Err.Description
End Function
```

`Caller`を実行し、クラス内Private UDT戻り値宣言がコンパイル時に拒否されるか、実行時まで遅延するかを確認する。

## 期待値

プログラム上の期待出力: `Caller`は実行できず、Function宣言の段階でコンパイルエラーになる。

文章での期待: MS-VBAL 5.3.1の制約により、クラスモジュールのFunctionはPrivate Type由来のUDTを戻り値として公開できない。

## 結果

プログラム上の実測出力: 修正後のRunnerは`Compile error: Public class function 'MakeHidden' cannot return a Private UDT`を返した。

文章での結果: クラス内Typeを保持・登録したうえで、Public FunctionのPrivate UDT戻り値をクラス手続きの共通precheckで検出できるようになった。

## 判定

判定状態: fixed（クラス内Private UDT戻り値のコンパイル時制約を検出し、回帰テストを通過）。
