## 評価内容

クラスモジュール内のPrivate TypeをPublic Functionの戻り値型に指定した場合のエラー段階を確認する。

## 実施方法

```vba
' Holder.cls（クラスモジュール）
Option Explicit
Private Type Hidden
    Value As Long
End Type

Public Function MakeHidden() As Hidden
    Dim value As Hidden
    value.Value = 42
    MakeHidden = value
End Function

' Module1.bas
Option Explicit
Public Function Caller() As String
    Dim holder As New Holder
    Dim ignored As Variant
    On Error Resume Next
    Err.Clear
    ignored = holder.MakeHidden()
    Caller = "ERR=" & CStr(Err.Number) & ";DESC=" & Err.Description
End Function
```

`Caller`を実行し、クラス内Private UDT戻り値宣言がコンパイル時に拒否されるか、実行時まで遅延するかを確認する。

## 期待値

プログラム上の期待出力: `Caller`は実行できず、Function宣言の段階でコンパイルエラーになる。

文章での期待: MS-VBAL 5.3.1の制約により、クラスモジュールのFunctionはPrivate Type由来のUDTを戻り値として公開できない。

## 結果

プログラム上の実測出力: `Caller=ERR=91;DESC=Object variable or With block variable not set`。Runnerはクラスを受理し、`ignored = holder.MakeHidden()`の呼び出しで実行時エラー91を発生させた。

文章での結果: 戻り値型の不正をコンパイル時に検出せず、未登録型の実体化を実行時まで遅延させている。仕様で要求されるエラー段階との差異を再現した。

## 判定

判定状態: bug-found（クラス内Private UDT戻り値のコンパイル時制約を実装できていない）。
