## 評価内容

Option Base 1 の `Array("a", "b")` を Filter に渡したとき、内部格納用の先頭要素が結果へ混入しないかを評価した。

## 実施方法

```vba
Option Base 1
Function T() As String
    Dim src As Variant, result As Variant
    src = Array("a", "b")
    result = Filter(src, "", True)
    T = CStr(LBound(result)) & "|" & CStr(UBound(result)) & "|" & result(0) & "|" & result(1)
End Function
```

## 期待値

期待出力: `0|1|a|b`。

Filterは一致した実要素だけを持つzero-based配列を返すため、内部の格納スロットは結果に含めない。

## 結果

実測出力: 修正前は `0|2||a|b`、修正後は `0|1|a|b`。回帰テストも通過した。

FilterがvbaBaseを無視して配列全体を検査していたため、空の隠し要素を実要素として返していた。

## 判定

判定状態: fixed

仕様に反して隠し格納スロットを結果へ混入させていた。Filter側でvbaBase以降だけを処理する修正を適用し、`tests/spec/split-join.test.ts`へ回帰テストを追加した。実Excelでの同一境界は未照合である。
