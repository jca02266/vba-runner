## 評価内容

同じ初期状態でsourceディレクトリと空のdestinationディレクトリを作り、
moveDirectorySync(source, destination)をMemoryFileSystemとNodeFileSystemで実行する。
既存destinationが空の場合にも、既存先を置換せずError相当となりsourceを保持するという
共通契約を検証する。

## 実施方法

各バックエンドに`source`と空の`destination`を作成し、moveDirectorySyncを呼び出す。
例外コード、sourceの存在、destinationの存在、destination内の内容を記録する。
同じ行列でsource不存在、destinationがsource自身・配下、親欠落、非空destinationも
実行し、空destinationだけの差異かを切り分ける。

## 期待値

期待出力:

```text
Memory empty-destination=EEXIST:source=true:destination=true
Node empty-destination=EEXIST:source=true:destination=true
```

既存destinationが空でも移動は失敗し、sourceは保持される。失敗後の状態は両バック
エンドで一致することを期待する。

## 結果

実測出力:

```text
Memory empty-destination=EEXIST:source=true:destination=true
Node empty-destination=ok:source=false:destination=true
```

source不存在、destinationがsource自身・配下、親欠落、非空destinationでは両バック
エンドの操作結果と失敗後状態が一致した。空の既存destinationだけで、NodeFileSystemは
`renameSync`によりdestinationを置換してsourceを削除し、MemoryFileSystemはEEXISTで
sourceを保持した。

## 判定

判定状態: bug-found

同一FileSystem契約を実装する2バックエンドの移動先衝突処理が一致していない。直接原因、
横展開、真因分析、修正方針、回帰テストはBUG-00542で管理する。
