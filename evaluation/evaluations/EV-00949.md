## 評価内容

Joinへ多次元配列を渡した場合の配列ランク契約を評価した。

## 実施方法

```vba
Dim a(0 To 1, 0 To 1) As String
result = Join(a, ",")
```

## 期待値

期待出力: `Err.Number = 13`。Joinは1次元配列以外を受け付けない。

## 結果

実測出力: 修正前は`Err.Number = 0`、修正後は`Err.Number = 13`。

## 判定

判定状態: fixed

Joinに配列ランク検査を追加し、回帰テストを通過させた。
