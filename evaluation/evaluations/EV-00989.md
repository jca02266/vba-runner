## 評価内容

べき乗演算子（`^`）と16進・8進基数リテラルの間に空白がない場合、`^`がLongLong型サフィックスとして誤認されないかを確認する。

## 実施方法

```vba
Function Probe() As Variant
    Probe = 2^&H3
End Function

Function ProbeSpaced() As Variant
    ProbeSpaced = 2 ^ &H3
End Function

Function ProbeOctal() As Variant
    ProbeOctal = 2^&O3
End Function

Function ProbeOctalSpaced() As Variant
    ProbeOctalSpaced = 2 ^ &O3
End Function
```

## 期待値

プログラム上の期待出力: 4つの式はいずれも `8` を返す。

文章での期待: 基数リテラルは数値の字句として認識され、`^`は空白の有無によらずべき乗演算子として扱われる。

## 結果

プログラム上の実測出力: `2^&H3` と `2^&O3` は構文解析エラーになり、空白付きの2式は `8` を返した。

文章での結果: 基数リテラルが隣接すると、Lexerが`^`をLongLongサフィックスとして消費する経路が再現した。符号付き右辺でも同じ隣接条件で結果が変わるため、追加の横展開と仕様確認が必要である。

## 判定

判定状態: in-progress（再現済みだが、期待値の仕様確認と修正前の横展開が未完了）。
