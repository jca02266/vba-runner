## 最小再現

```vba
Public Function ForGoSub() As String
    Dim i As Long, result As String
    For i = 1 To 3
        result = result & CStr(i)
        GoSub Part
    Next i
    ForGoSub = result
    Exit Function
Part:
    result = result & "P"
    Return
End Function
```

Excel期待値は `1P2P3P` だが、runnerはエラーなしで `1P` を返す。
横展開でFor系ループ、If、Selectに同じ症状を確認した。

直接原因は、`executeStatements`が手続き本体でしかGoSub/Return制御例外を処理せず、
ネストしたブロックから外側へ再throwしていること。真因は、GoSub復帰フレームが
Evaluator全体の単純な`number[]`で、手続き・文脈・継続位置を保持していない設計である。
手続き境界の裸Returnが呼び出し元フレームを消費する横展開も確認した。

これはVBA仕様内の制御構文であり、仕様制限やTODOではなく実装修正対象とする。
remediationでは、GoSubターゲットを現在の手続き内で再帰実行し、Returnをターゲット
実行器だけが受け取る継続経路へ変更した。For、For Each、Do While、If、Selectと
手続き境界の回帰テストを追加し、元の最小再現と横展開経路が期待値に一致することを確認した。
