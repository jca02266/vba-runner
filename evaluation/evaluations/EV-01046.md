## 評価内容

CallByNameでDate ByRef引数を括弧付きで渡した場合、呼出し先の代入が呼出し元変数へ
書き戻されない一時値契約になるかを確認する。

## 実施方法

```vba
' Class module: DateMutator
Public Sub Touch(ByRef value As Date)
    value = DateSerial(1899, 12, 30)
End Sub

' Standard module
Function RunCase() As String
    Dim m As New DateMutator
    Dim d As Date
    d = DateSerial(2024, 1, 2)
    CallByName m, "Touch", VbMethod, (d)
    RunCase = DateKey(d)
End Function

Function DateKey(ByVal value As Date) As String
    DateKey = CStr(Year(value)) & "-" & CStr(Month(value)) & "-" & CStr(Day(value))
End Function
```

## 期待値

期待出力：`2024-1-2`

括弧付き引数は一時値となるため、呼出し先がDateを変更しても呼出し元の変数は維持されることを期待する。

## 結果

実測出力：`2024-1-2`

Runnerは括弧付きDate ByRef引数を一時値として扱い、呼出し元のDate値を維持した。

## 判定

判定状態: verified-no-bug

対象のClass CallByName経路で不一致は再現せず、新規Findingは確認されなかった。
