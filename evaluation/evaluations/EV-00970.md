## 評価内容

LockとUnlockのrecordrangeにNullを指定したときのエラー変換を確認する。

## 実施方法

```vba
Function T() As Long
    On Error Resume Next
    Open "x.dat" For Random As #1 Len = 4
    Lock #1, Null To 2
    T = Err.Number
End Function
```

同じ手続きでUnlock、および`1 To Null`も実行する。

## 期待値

Nullを数値範囲へ強制すると、VBAの`Invalid use of Null`であるError 94になるという仮説を検証する。

## 結果

Runnerは4ケースすべてError 1000を返した。Excel実機結果は未取得。
