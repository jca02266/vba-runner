## 評価内容

LockとUnlockのrecordrangeにNullを指定したときのエラー変換を確認する。

## 実施方法

```vba
Function T() As Long
    On Error Resume Next
    Open "x.dat" For Random As #1 Len = 4
    Lock #1, Null To 2
    T = Err.Number
End Function
```

同じ手続きでUnlock、および`1 To Null`も実行する。

## 期待値

Nullを数値範囲へ渡したときのExcel固有のエラー番号を確認する。
期待出力：`LOCK_NULL_TO ERR=94`、`UNLOCK_ONE_TO_NULL ERR=94`

## 結果

Runnerは4ケースすべてError 1000を返した。Excel実機結果は
`XL-257 LOCK_NULL_TO ERR=94` および `XL-257 UNLOCK_ONE_TO_NULL ERR=94` となった。
Nullのrecordrangeに対するエラー変換がExcelと一致していない。
実測出力：`LOCK_NULL_TO ERR=94`、`UNLOCK_ONE_TO_NULL ERR=94`
