## 評価内容

ADODB.StreamのOptional専用ReadTextについて、直接の裸参照、空括弧、明示引数、
CallByNameの引数省略、CallByNameの明示引数を比較する。値PropertyのSizeも同じ
外部動的オブジェクトから取得し、メソッドと値Propertyの評価を混同していないか確認する。

## 実施方法

```vba
Public Function Probe() As String
    Dim stream As Object, value As Variant, errNo As Long, result As String
    Set stream = CreateObject("ADODB.Stream")
    On Error Resume Next
    stream.Type = 2
    Err.Clear: stream.Open: errNo = Err.Number
    result = "OPEN=" & CStr(errNo)
    stream.WriteText "abcd"
    stream.Position = 0
    Err.Clear: value = stream.ReadText: errNo = Err.Number
    result = result & "|READTEXT-BARE=" & CStr(errNo) & ":" & TypeName(value) & ":" & CStr(value)
    stream.Position = 0
    Err.Clear: value = stream.ReadText(): errNo = Err.Number
    result = result & "|READTEXT-PARENS=" & CStr(errNo) & ":" & TypeName(value) & ":" & CStr(value)
    stream.Position = 0
    Err.Clear: value = stream.ReadText(2): errNo = Err.Number
    result = result & "|READTEXT-VALUE=" & CStr(errNo) & ":" & TypeName(value) & ":" & CStr(value)
    stream.Position = 0
    Err.Clear: value = CallByName(stream, "ReadText", VbMethod): errNo = Err.Number
    result = result & "|CALLBYNAME-BARE=" & CStr(errNo) & ":" & TypeName(value) & ":" & CStr(value)
    stream.Position = 0
    Err.Clear: value = CallByName(stream, "ReadText", VbMethod, 2): errNo = Err.Number
    result = result & "|CALLBYNAME-VALUE=" & CStr(errNo) & ":" & TypeName(value) & ":" & CStr(value)
    Err.Clear: value = stream.Size: errNo = Err.Number
    result = result & "|SIZE=" & CStr(errNo) & ":" & TypeName(value) & ":" & CStr(value)
    Probe = result
    On Error GoTo 0
End Function
```

## 期待値

期待出力: `OPEN=0|READTEXT-BARE=0:String:abcd|READTEXT-PARENS=0:String:abcd|READTEXT-VALUE=0:String:ab|CALLBYNAME-BARE=0:String:abcd|CALLBYNAME-VALUE=0:String:ab|SIZE=0:Double:4`

ADO仕様ではNumCharsはOptionalで、省略時はストリーム全体を読み取る。Runnerのモック
では戻り値をStringとして表現するため、4文字の全量と2文字の指定長を期待する。CallByName
経路へのOptional束縛はRunner実装の検証として扱い、ADO仕様から直接導かれるものとはしない。

## 結果

実測出力: `OPEN=0|READTEXT-BARE=0:String:abcd|READTEXT-PARENS=0:String:abcd|READTEXT-VALUE=0:String:ab|CALLBYNAME-BARE=0:String:abcd|CALLBYNAME-VALUE=0:String:ab|SIZE=0:Double:4`

直接呼出しとCallByNameの両方でOptional引数を省略・指定でき、全量・指定長の結果が
一致し、エラーは発生しなかった。Size値Propertyも4を返した。独立評価担当と独立レビュー
担当が同じOptional専用動的経路を確認し、差異を認めなかった。実COMのバイト型Variantの
厳密な戻り値型はRunnerモックの対象外であり、今回の判定はRunnerの束縛契約に限定する。

## 判定

判定状態: verified-no-bug

ADODB.StreamのOptional ReadText契約は、直接評価・空括弧・CallByNameで共通に適用されている。
RC-00070の外部Optional動的メンバー経路について、このRunner実装範囲では新たな不具合を
確認しなかった。TextStream.Readの必須引数契約や外部COMの戻り値型は別の評価範囲である。
