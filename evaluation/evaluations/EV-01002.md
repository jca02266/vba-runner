## 評価内容

クラスモジュールのPublic Functionが、クラス内Private Typeを引数型として公開する宣言境界を確認する。

## 実施方法

```vba
' ClassCase.cls
Option Explicit
Private Type HiddenRecord
    Value As Long
End Type

Public Function Expose(ByVal item As HiddenRecord) As Long
    Expose = 1
End Function

Public Function ExposeSelf() As Long
    Dim item As HiddenRecord
    ExposeSelf = Expose(item)
End Function

' Module1.bas
Option Explicit
Public Function Caller() As Long
    Dim instance As New ClassCase
    Caller = instance.ExposeSelf
End Function
```

クラスをロードして手続き診断を取得し、`Caller`を実行する。宣言時のdiagnosticsと実行結果を、Private UDTを使わない対照と比較する。

## 期待値

プログラム上の期待出力: 宣言時にコンパイルエラー（Private UDTをPublic手続きのパラメータに使用できない）。`Caller`は実行されない。

文章での期待: Private UDTは所有モジュール外へ公開できないため、クラスPublic Functionの署名はVBAのコンパイル時静的制約で拒否される。

## 結果

プログラム上の実測出力: Runnerのロードは成功し、`analyzeProcedureDiagnostics`は`[]`を返し、`Caller`は`1`を返した。Event宣言に同じPrivate UDTを指定した別の最小確認もdiagnosticsなしで受理された。

文章での結果: 署名の型所有スコープと公開境界が検査されず、仕様上不正なPublic Function（およびEvent）を実行可能として扱っている。

## 判定

判定状態: bug-found。

独立評価は最小クラスでロード成功・診断空配列・実行値1を確認した。横展開ではPublic/FriendのFunction、Sub、Property、Eventの署名でも同じ静的検査欠落を確認したが、Privateメンバーは合法なため不具合から除外した。独立RCA提案と反証レビューは、直接原因を署名可視性precheck欠落、根因仮説を型所有モジュール情報の欠落として支持した。Event固有のByRef互換性とFriend境界はRCA-PRIVATE-VISIBILITY-013へ分離し、RC-00123は未確定仮説として扱う。
