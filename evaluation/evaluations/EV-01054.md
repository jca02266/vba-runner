## 評価内容

通常変数と手続き引数の`String * constant-name`が、UDTと同じ固定長宣言契約で解決されるか評価する。

## 実施方法

```vba
Const FIXED_LENGTH As Double = 2.5
Function ContentOf(value As String * FIXED_LENGTH) As String
    Dim localValue As String * FIXED_LENGTH
    localValue = value
    ContentOf = CStr(Len(localValue)) & ":" & localValue
End Function
```

`ContentOf("ABCDE")`を呼び出す。

## 期待値

期待出力：`2:AB`

定数値`2.5`をLongへLet-coercionした長さ2を、引数とローカル変数の両方に適用する。

## 結果

修正前の実測出力：`0:`

パーサーがConst名を消費して捨てていた。修正後の実測出力は`2:AB`となった。

## 判定

判定状態: fixed

固定長文字列の構文保持と長さ解決を、変数・引数・UDTで共通化した。
