# Select CaseのNull比較境界

独立評価でVariant `Null` が `Case Null` に誤一致し、`Case Is <> 0` では誤って
一致し、大小比較ではJavaScript Symbol変換例外になった。Nullを含むexpression、
`To`範囲、すべての`Case Is`演算子を比較前に不一致として扱い、Case Elseや次の
Caseへ進むようにした。回帰テストではNullが例外なくCase Elseへ到達することを確認した。
