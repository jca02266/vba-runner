# Currency整数演算のLong境界

XL-015ではCurrencyの `/` は `Double` として出力された一方、続く `Mod` で
オーバーフローになった。最大Currencyの整数部はLong範囲を超えるため、Decimalと同じく
整数演算の有効型境界でError 6になる。

Currencyの `\\` と `Mod` に、銀行丸め後のLong範囲検査を追加した。
検証マクロはエラーを個別出力するよう更新済みである。
