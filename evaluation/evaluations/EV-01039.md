## 評価内容

WithEvents購読者を明示的に解除した場合と、購読者インスタンス自体を破棄した場合を比較し、発行元に破棄済みハンドラーが残らないことを確認する。

## 実施方法

```vba
Class Emitter
    Public Event Ping()
    Public Sub Fire()
        RaiseEvent Ping
    End Sub
End Class

Class Consumer
    Public WithEvents Source As Emitter
    Public fired As Long
    Public Sub Connect(ByVal publisher As Emitter)
        Set Source = publisher
    End Sub
    Private Sub Source_Ping()
        fired = fired + 1
    End Sub
End Class

Public Function RunProbe() As String
    Dim publisher As New Emitter
    Dim consumer As New Consumer
    consumer.Connect publisher
    publisher.Fire
    Dim before As Long
    before = consumer.fired
    Set consumer = Nothing
    On Error Resume Next
    Err.Clear
    publisher.Fire
    RunProbe = CStr(before) & ":" & CStr(Err.Number)
End Function
```

## 期待値

プログラム上の期待出力: `1:0`。

文章での期待: 購読者を破棄した後の発行では破棄済みインスタンスへのハンドラー呼び出しが発生せず、エラー番号は0になる。

## 結果

プログラム上の実測出力: `1:0`。

文章での結果: 初回発火だけが購読者を1回呼び出し、購読者をNothingにした後の発火はエラーなく終了した。破棄済み購読者への残留呼び出しは観測されなかった。
