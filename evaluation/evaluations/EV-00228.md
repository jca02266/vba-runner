# 財務関数のゼロ・境界引数

IRR/MIRRに正値と負値の両方がない現金フローを渡すと、修正前はVBA Error 5ではなく
`Infinity`、`-Infinity`、または`NaN`を返した。独立評価と横展開調査で同じ経路を
確認し、入力符号と有限性を検証する修正を行った。IPmt/PPmtの確認範囲では新規不具合を
再現しなかった。
