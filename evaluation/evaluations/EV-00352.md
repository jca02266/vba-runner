# FSO DeleteFile Force属性境界

読み取り専用ファイルへ`fso.DeleteFile path, False`を実行すると、修正前runnerは
Error 0でファイルを削除した。Excel VBAではError 70（Permission denied）となり、
`Force=True`の場合だけ削除できる。トップレベルDeleteFileの実装がForce引数を
受け取らず無視していたため、属性確認・Force時の属性解除を共通入口へ追加した。
回帰テストでFalse時の保持とTrue時の削除を確認した。
