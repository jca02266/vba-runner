# Select Caseの数値Variant String等価比較

独立評価でVariantに格納した`"100"`が、`Case 99 To 101`には入る一方で、
先行する`Case 100`には一致しなかった。通常のVBA比較では数値文字列が数値へ
暗黙変換されるため、Select Caseの等価比較だけが経路不一致だった。数値型の
相手を検出した場合に同じ数値変換比較を行い、符号付き・指数形式を含む回帰テストを
追加した。
