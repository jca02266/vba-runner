## 評価内容

固定長`Double()`の`flows=(4, 5, -1)`を渡す
`MIRR(flows, 0.1, ReinvestRate)`について、正キャッシュフローのみのNPV（`npvPos`）がゼロになる
`ReinvestRate=-2.25`の両側と境界値を評価する。

## 実施方法

```vba
Private Sub VerifyMirrReinvestNpvZeroCrossing()
    Dim rates, i As Long, value As Variant, errNo As Long
    Dim flows(0 To 2) As Double
    rates = Array(-2.125, -2.2499990463256836, -2.25, _
        -2.2500009536743164, -2.375)
    flows(0) = 4: flows(1) = 5: flows(2) = -1
    For i = 0 To 4
        On Error Resume Next
        Err.Clear
        value = Empty
        value = MIRR(flows, 0.1, rates(i))
        errNo = Err.Number
        EmitResult "XL-244 RATE=" & CStr(rates(i)) & " ERR=" & CStr(errNo) & _
            " VALUE=[" & CStr(value) & "] TYPE=" & TypeName(value)
        On Error GoTo 0
    Next i
End Sub

Private Sub EmitResult(ByVal line As String)
    Debug.Print line
End Sub
```

## 期待値

期待出力は、Excelでも`ReinvestRate=-2.25`の正キャッシュフローNPVゼロ交差を境に、Error 5から
有限値へ切り替わることである。プログラム上はXL-244の5ケースすべてでRunnerとExcelの
値、`Err.Number`、`TypeName`が一致することを期待する。

## 結果

Runner実測出力:

```text
XL-244 RATE=-2.125 ERR=5 VALUE=[] TYPE=Empty
XL-244 RATE=-2.2499990463256836 ERR=5 VALUE=[] TYPE=Empty
XL-244 RATE=-2.25 ERR=0 VALUE=[-1] TYPE=Double
XL-244 RATE=-2.2500009536743164 ERR=0 VALUE=[-0.9975979729359951] TYPE=Double
XL-244 RATE=-2.375 ERR=0 VALUE=[-0.08792818265226499] TYPE=Double
```

Runnerでは正キャッシュフローNPVが正となる先頭2ケースがError 5、ゼロとなる境界と
負となる後続2ケースが有限のDoubleになった。Excel実機結果は未取得である。
