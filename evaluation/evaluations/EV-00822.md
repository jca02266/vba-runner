## 評価内容

Collection.Itemのindexを省略した`value = items.Item`と`value = items.Item()`を比較し、
有効な`value = items.Item(1)`も確認する。

## 実施方法

```vba
Public Function Probe() As String
    Dim items As Collection, value As Variant, out As String
    Set items = New Collection
    items.Add "alpha"
    On Error Resume Next
    Err.Clear: value = items.Item
    out = "OMITTED=" & CStr(Err.Number) & ":" & TypeName(value)
    Err.Clear: value = items.Item()
    out = out & "|PARENS=" & CStr(Err.Number) & ":" & TypeName(value)
    Err.Clear: value = items.Item(1)
    out = out & "|ONE=" & CStr(Err.Number) & ":" & TypeName(value) & ":" & CStr(value)
    Probe = out
    On Error GoTo 0
End Function
```

## 期待値

期待出力（仮説）: `OMITTED=450:Empty|PARENS=450:Empty|ONE=0:String:alpha`

Itemのindexは必須であると仮定する。Excel実機のXL-203で省略形式のエラー番号と
戻り値を確認するまで、仮説を確定期待値として扱わない。

## 結果

実測出力（Runner）: `OMITTED=0:Object|PARENS=0:Empty|ONE=0:String:alpha`

Runnerは省略形式をエラーなしのObjectとして返し、括弧付き省略もEmptyを返した。
有効なindexではalphaを返した。Excel結果は未取得であり、現時点ではバグ判定しない。

## 判定

判定状態: needs-excel

Collection.Itemの省略引数境界を単独評価として記録した。XL-203の実機結果と
独立レビューを確認してから判定する。
