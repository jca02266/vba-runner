## 評価内容

```text

DATE-WEEK-OPTION 2,3 => 52,5
DATE-WEEK-OPTION 4,1 => 1,3
DATE-WEEK-OPTION 4,2 => 1,3
DATE-WEEK-OPTION 4,3 => 53,3

DATE-WEEK-OPTION 7,1 => 1,7
DATE-WEEK-OPTION 7,2 => 52,7
DATE-WEEK-OPTION 7,3 => 52,7
```

15ケースすべてで期待値と実測値が一致した。
