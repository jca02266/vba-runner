## 評価内容

固定長`Double()`の`flows=(-100, -50, 200)`を渡す
`MIRR(flows, FinanceRate, 0.1)`について、負値NPVがゼロになる
`FinanceRate=-1.5`の両側と境界値を評価する。

## 実施方法

```vba
Sub ProbeMirrFinanceZeroCrossing()
    Dim rates, i As Long, value As Double, errNo As Long
    Dim flows(0 To 2) As Double
    rates = Array(-1.6, -1.5000000001, -1.5, -1.4999999999, -1.4)
    flows(0) = -100: flows(1) = -50: flows(2) = 200
    For i = 0 To 4
        On Error Resume Next
        Err.Clear
        value = 0
        value = MIRR(flows, rates(i), 0.1)
        errNo = Err.Number
        Debug.Print rates(i), errNo, value, TypeName(value)
        On Error GoTo 0
    Next i
End Sub
```

## 期待値

期待出力は、Excelでも`FinanceRate=-1.5`の負値NPVゼロ交差を境に、有限値から
Error 5へ切り替わることである。プログラム上はXL-243の5ケースすべてでRunnerとExcelの
値、`Err.Number`、`TypeName`が一致することを期待する。

## 結果

Runner実測出力:

```text
XL-243 RATE=-1.6 ERR=0 VALUE=2.464101615137754 TYPE=Double
XL-243 RATE=-1.5000000001 ERR=0 VALUE=99998.99587032894 TYPE=Double

XL-243 RATE=-1.4999999999 ERR=5 VALUE=0 TYPE=Double
```

Runnerでは負値NPVが正の有限値を保つ2ケースが成功し、ゼロ以下となる3ケースが
Error 5になった。Excel実機結果は未取得である。
