# FileCopy既存先境界

`FileCopy "copy_src.txt", "copy_dst.txt"` で宛先が既に存在する場合、修正前は
既存内容を上書きして `Err.Number=0` になった。VBAの期待動作は Error 58
(File already exists) である。

組み込みFileCopyの共通入口で宛先存在を検証し、上書きを禁止した。MemoryFileSystem
による回帰テストを追加し、FSOおよびオブジェクトCopy経路も横展開確認した。
