## 評価内容

DateAdd、DateDiff、DatePart、Weekdayの未知interval、無効な週開始日、無効な週初規則、Null相当の既定値を8ケースで確認する。

## 実施方法

`tests/spec/date-option-validation-matrix.test.ts`を実行し、Err.Number、TypeName、値を出力する。

## 期待値

期待出力:

```text
DATE-OPTION DateAdd("zz", 1, #1/1/2024#) => 5|Empty|
DATE-OPTION DateDiff("zz", #1/1/2024#, #1/2/2024#) => 5|Empty|
DATE-OPTION DatePart("zz", #1/1/2024#) => 5|Empty|
DATE-OPTION DatePart("ww", #1/1/2024#, 0, 0) => 0|Integer|1
DATE-OPTION DatePart("ww", #1/1/2024#, 8, 1) => 5|Empty|
DATE-OPTION DatePart("ww", #1/1/2024#, 1, 4) => 5|Empty|
DATE-OPTION Weekday(#1/1/2024#, 8) => 5|Empty|
DATE-OPTION DateDiff("d", #1/1/2024#, #1/2/2024#, 8, 1) => 5|Empty|
```

## 結果

実測出力:

```text
DATE-OPTION DateAdd("zz", 1, #1/1/2024#) => 5|Empty|
DATE-OPTION DateDiff("zz", #1/1/2024#, #1/2/2024#) => 5|Empty|
DATE-OPTION DatePart("zz", #1/1/2024#) => 5|Empty|
DATE-OPTION DatePart("ww", #1/1/2024#, 0, 0) => 0|Integer|1
DATE-OPTION DatePart("ww", #1/1/2024#, 8, 1) => 5|Empty|
DATE-OPTION DatePart("ww", #1/1/2024#, 1, 4) => 5|Empty|
DATE-OPTION Weekday(#1/1/2024#, 8) => 5|Empty|
DATE-OPTION DateDiff("d", #1/1/2024#, #1/2/2024#, 8, 1) => 5|Empty|
```

8ケースすべてで期待値と実測値が一致した。

## 判定

判定状態: verified-no-bug

Date関数のinterval・週オプション検証と0指定の既定値処理に新しい差異は確認されなかった。
