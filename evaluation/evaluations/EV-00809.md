# EV-00802の再評価

## 評価内容
クラスProperty Letの継承・公開呼出し経路を、通常のProperty解決テストと区別して再評価する。

## 実施方法
次の自己完結したVBAソースを実行し、公開インターフェース参照を経由した
Property Letのsetter選択とvalue引数の書戻しを確認する。

```vba
' クラスモジュール IWritable（インターフェース宣言）
Class IWritable
    Property Let Value(ByRef value As Long)
End Property
End Class

' クラスモジュール WritableBox
Class WritableBox
    Implements IWritable
    Private seen As Long
    Public Property Let IWritable_Value(ByRef value As Long)
        seen = value
        value = value + 1
    End Property
    Public Function Read() As Long
        Read = seen
    End Function
End Class

Function VerifyPublicProperty() As String
    Dim concrete As New WritableBox, target As IWritable, source As Long
    source = 7
    Set target = concrete
    target.Value = source
    VerifyPublicProperty = CStr(concrete.Read()) & ":" & CStr(source)
End Function
```

## 期待値
プログラム上の期待出力: `継承Propertyのsetterが1回選択され、呼出元valueは保持される`

公開参照のProperty Letが正しいsetterへ到達し、value引数の実効ByVal規則を維持する。

## 結果
プログラム上の実測出力: `未取得`

既存のProperty解決回帰は一般的なsetter選択を確認するが、EV-00802の継承・公開呼出しを個別の出力として記録していない。
