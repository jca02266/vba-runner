# 配列読み取り共通化の境界保持

## 評価内容

独立評価エージェントがREADMEを読んだ新規利用者として、Class、UDT配列、文字列、
ループ、条件分岐、`On Error` を含むサンプルを作成し、seed `5` と `-3` で実行した。

通常配列とUDT配列メンバーの下限・上限、未定義要素、次元数不一致を確認した結果、
期待動作との差分は見つからなかった。2D配列を1D ByRefへ渡すケースもError 13で
明確に失敗した。

## 独立検証

既存の `array-subscript-bounds.test.ts` と `udt-type.test.ts` を実行し、範囲外・次元数
不一致・UDT配列メンバーの境界エラーが通過することを確認した。独立評価のスクラッチ
ファイルは削除済みである。

評価中、組み込み手続き名との衝突時にモジュール修飾を使う必要がある点が改善候補として
報告されたが、今回の配列読み取りの機能バグではないため別候補として扱う。
