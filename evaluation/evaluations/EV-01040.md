## 評価内容

ClassのDate型ByRef引数について、通常のメソッド呼出しとCallByNameのVbMethod呼出しで、
呼出し先による値の書戻しが一致するかを確認する。

## 実施方法

```vba
' Class module: DateMutator
Public Sub Touch(ByRef value As Date)
    value = CDate(0)
End Sub

' Standard module
Function RunCase() As String
    Dim m As New DateMutator
    Dim d As Date
    d = CDate("2024-01-02")
    m.Touch d
    RunCase = DateKey(d) & "|"
    d = CDate("2024-01-02")
    CallByName m, "Touch", VbMethod, d
    RunCase = RunCase & DateKey(d)
End Function

Function DateKey(ByVal value As Date) As String
    DateKey = CStr(Year(value)) & "-" & CStr(Month(value)) & "-" & CStr(Day(value))
End Function
```

通常呼出しとCallByName呼出しを同じ初期値で実行し、戻り値を連結して比較した。

## 期待値

期待出力：`1899-12-30|1899-12-30`

両経路ともDateのゼロ値を書戻し、呼出し元の変数が同じ日付になることを期待する。

## 結果

実測出力：`1899-12-30|1899-12-30`

Runnerは通常呼出しとCallByNameの双方で同じDate値を呼出し元へ書き戻した。

## 判定

判定状態: verified-no-bug

対象のRunner経路で不一致は再現せず、新規バグは確認されなかった。COM実オブジェクトの
ByRef契約はこの評価の対象外である。
