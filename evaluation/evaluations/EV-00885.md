## 評価内容

DateValueのISO/スラッシュ日付、時刻付き入力、不正暦日、TimeValueの0時・通常時刻・23:59:59を確認する。

## 実施方法

`tests/spec/date-value-time-value-boundary.test.ts`を実行し、各入力の暦日・時刻またはErr.Numberを出力する。

## 期待値

期待出力:

```text
DATE-VALUE date|2024-02-29 => 2024/2/29 0:0:0
DATE-VALUE date|2024/02/29 12:34:56 => 2024/2/29 0:0:0
DATE-VALUE date|2024/02/30 => ERR=13
DATE-VALUE date|02/29/2023 => ERR=13
DATE-VALUE time|00:00:00 => 1899/12/30 0:0:0
DATE-VALUE time|14:30:45 => 1899/12/30 14:30:45
DATE-VALUE time|23:59:59 => 1899/12/30 23:59:59
```

## 結果

実測出力:

```text
DATE-VALUE date|2024-02-29 => 2024/2/29 0:0:0
DATE-VALUE date|2024/02/29 12:34:56 => 2024/2/29 0:0:0
DATE-VALUE date|2024/02/30 => ERR=13
DATE-VALUE date|02/29/2023 => ERR=13
DATE-VALUE time|00:00:00 => 1899/12/30 0:0:0
DATE-VALUE time|14:30:45 => 1899/12/30 14:30:45
DATE-VALUE time|23:59:59 => 1899/12/30 23:59:59
```

7ケースすべてで期待値と実測値が一致した。

## 判定

判定状態: verified-no-bug

DateValue/TimeValueの入力形式、時刻切捨て、不正日付、基準日の時刻境界に新しい差異は確認されなかった。
