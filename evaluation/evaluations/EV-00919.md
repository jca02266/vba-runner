## 評価内容

Like演算子の空文字クラス、降順範囲、未終端の文字リスト、不正なワイルドカード文字列を
仕様どおりに扱えるか評価する。

## 実施方法

次の自己完結VBAをRunnerで実行し、エラー番号と一致結果を記録する。

```vba
' TextModule.bas
Option Compare Text

Public Function Probe(ByVal selector As Long) As String
    Dim value As Boolean, errNo As Long
    On Error Resume Next
    Err.Clear
    If selector = 1 Then value = ("" Like "[]")
    If selector = 2 Then value = ("A" Like "[Z-A]")
    If selector = 3 Then value = ("A" Like "[")
    If selector = 4 Then value = ("a [xyz" Like "a [*")
    errNo = Err.Number
    Probe = "SELECT=" & CStr(selector) & " VALUE=" & CStr(value) & " ERR=" & CStr(errNo)
    On Error GoTo 0
End Function

Public Sub RunProbe()
    Dim selector As Long
    For selector = 1 To 4
        Debug.Print Probe(selector)
    Next selector
End Sub
```

`RunProbe`を入口として4つの文法境界を順に実行する。Option Compareの範囲比較やClassの
呼出し経路は今回の評価対象に含めず、別の評価で扱う。

## 期待値

期待出力: 次のとおりである。

```text
SELECT=1 VALUE=True ERR=0
SELECT=2 VALUE=False ERR=93
SELECT=3 VALUE=False ERR=93
SELECT=4 VALUE=False ERR=93
```

仕様上、`[]`は空文字列に一致し、降順範囲・未終端文字リスト・不正なパターンはError 93
となる。

## 結果

実測出力: Runnerは次のとおりであった。

```text
SELECT=1 VALUE=True ERR=0
SELECT=2 VALUE=False ERR=93
SELECT=3 VALUE=False ERR=93
SELECT=4 VALUE=False ERR=93
```

空文字クラス、無効な範囲、未終端リスト、不正なワイルドカードの各境界で、Runnerは
Microsoft LearnのLike仕様と同じ結果を返した。独立評価でも同じ最小集合を確認した。
