## 評価内容

EventがLong ByRef引数を宣言し、WithEventsハンドラーがString ByRefを宣言した場合の署名互換性を確認する。

## 実施方法

```vba
' Emitter.cls
Option Explicit
Public Event Ping(ByRef value As Long)

Public Sub Fire()
    Dim n As Long
    n = 42
    RaiseEvent Ping(n)
    Debug.Print n
End Sub

' Consumer.cls
Option Explicit
Public WithEvents Source As Emitter
Public seen As String

Private Sub Source_Ping(ByRef value As String)
    seen = "handled:" & value
    value = "changed"
End Sub

' Driver.bas
Option Explicit
Public Function RunCase() As String
    Dim c As New Consumer
    Dim s As New Emitter
    Set c.Source = s
    s.Fire
    RunCase = c.seen
End Function
```

`RunCase`を実行し、ハンドラー署名のdiagnosticsと実行結果を確認する。一致するLong ByRefハンドラーを対照とする。

## 期待値

プログラム上の期待出力: EventとハンドラーのByRef型が不一致のため、署名診断となりハンドラーは実行されない。

文章での期待: Event Handler DeclarationはEventの各引数と型およびByRef/ByVal機構が一致しなければならない。

## 結果

プログラム上の実測出力: 修正前はdiagnosticsが空でハンドラーが実行され`seen="handled:42"`となった。修正後は署名不一致のハンドラーが登録されず`seen=""`。

文章での結果: `bindWithEventsHandlers`が名前だけでハンドラーを登録し、イベント側の型とByRef情報を比較しないため、不一致署名が暗黙変換を経て実行された。

## 判定

判定状態: fixed。

独立評価は最小クラス構成で診断なし・`handled:42`を再現した。EventとSubハンドラーの引数個数、型、ByRef/ByValを登録時に比較する修正と回帰テストにより、不一致ハンドラーを除外できることを確認した。Property候補と標準モジュールfallbackは別評価で修正済み、Interface・ホスト経路は未解決候補として追跡する。
