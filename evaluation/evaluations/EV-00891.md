## 評価内容

既存の宛先ディレクトリに同名のトップレベルファイルと入れ子ファイルがある状態でCopyFolderの上書き経路を実行し、MemoryFileSystemとNodeFileSystemの結果を比較する。

## 実施方法

VBAから見える操作は次のとおりである。評価ドライバーは両バックエンドに同じ`src`/`dst`の初期状態を作り、このCopyFolder相当のコピーを`overwrite=True`で実行して、結果の内容とコピー元の存在を比較する。

```vb
Option Explicit
Public Sub ProbeCopyFolder()
    Dim fso As Object
    Set fso = CreateObject("Scripting.FileSystemObject")
    On Error Resume Next
    fso.CopyFolder "src", "dst", True
    Debug.Print "TOP=" & fso.OpenTextFile("dst\keep.txt", 1).ReadAll
    Debug.Print "NESTED=" & fso.OpenTextFile("dst\sub\value.txt", 1).ReadAll
    Debug.Print "SOURCE=" & CStr(fso.FileExists("src\keep.txt"))
End Sub
```

初期状態は`src\keep.txt=new`、`src\sub\value.txt=nested`、宛先側の同じ2ファイルはそれぞれ`old`、`old-nested`とする。

## 期待値

プログラムとしての期待出力:

```text
Memory={"top":"new","nested":"nested","source":true}
Node={"top":"new","nested":"nested","source":true}
```

overwrite=Trueでは同名のファイル内容が新しい内容へ置換され、入れ子階層も同じ結果になり、コピー元は残る。MemoryとNodeの両バックエンドは同じ結果を返すことを期待する。

## 結果

実測出力:

```text
Memory={"top":"new","nested":"nested","source":true}
Node={"top":"new","nested":"nested","source":true}
```

トップレベル、入れ子ファイル、コピー元保持の3項目が一致し、バックエンド間の差異は確認されなかった。権限障害やI/O途中失敗は今回の対象外である。

## 判定

判定状態: verified-no-bug

overwrite=Trueの既存宛先・入れ子ファイル経路はMemory/Nodeで一致した。残る権限・I/O障害の原子性は別評価境界として扱う。
