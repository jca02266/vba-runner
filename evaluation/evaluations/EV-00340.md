# Put/Get/Seek位置引数Null境界

修正前は`Put #1, Null, value`、`Get #1, Null, value`、`Seek #1, Null`が
`Number`変換を経由して内部エラー1000になっていた。VBAではいずれも
Invalid use of Null（Error 94）である。record/position値を共通入口で検証し、
Nullを明示的にError 94へ変換した。3経路の回帰テストを追加した。
