## 評価内容

正のキャッシュフロー位置を固定しつつ期間数を増やし、ReinvestRate=-1近傍の結果を確認する。

## 実施方法

```vba
Sub ProbeMirrPeriods()
    Dim f() As Double, n As Variant, last As Long
    For Each n In Array(2, 3, 4, 5, 6, 8)
        last = n - 1: ReDim f(0 To last): f(0) = -100
        If last = 1 Then f(1) = 150 Else f(1) = 50: f(last) = 100
        Debug.Print last, MIRR(f, 0.1, -0.9999999999)
    Next n
End Sub
```

## 期待値

期待出力: `XL-240 PERIODS=<1|2|3|4|5|7> VALUE=<value> TYPE=Double`。
各期間数でExcelとRunnerの有限値またはError番号を比較する。

実測出力:


返す一方、Excelは約`1E-10`から`3E-10`の有限値を保持した。
