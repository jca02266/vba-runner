## 評価内容

固定必須引数とParamArrayを同時に持つFunctionについて、固定引数を省略してParamArrayだけを
空にした呼出しが、静的な必須引数検査に到達するかを確認する。

## 実施方法

```vba
Function Target(required As Long, ParamArray values()) As Long
    Target = required
End Function

Sub Caller()
    Dim result As Long
    result = Target()
End Sub
```

同じ境界を`tests/spec/call-arity-matrix.test.ts`のprecheck検査で実行する。

## 期待値

期待出力: `Compile error: Argument not optional`

説明上の期待値: ParamArrayは0個で成立するが、ParamArrayより前の固定必須引数は省略できない。

## 結果

実測出力: 修正前は`Run-time error '449': Argument not optional`、修正後は
`Compile error: Argument not optional`となった。

`call-arity-matrix.test.ts`、ParamArray Property/CallByName行列、TypeScript型検査は通過した。

## 判定

判定状態: fixed

precheckProcのParamArray経路でも固定必須引数を最小引数数へ含めるようにし、実行時検査へ
遅れて到達する差を解消した。Interface・動的COM・Optional混在は別経路として未検証である。
