## 評価内容

Opaqueな2次元配列をModule/ClassのProperty戻り値から受け取り、Long・String・Objectの型付き配列への代入、ByRef、Property Letを、要素型一致・不一致、非0下限、正常添字で比較する。

## 実施方法

次のVBA相当の配列をRunnerのCOMモックから供給し、Module/ClassのProperty、ByRef、Property Letを同じ行列で実行する。

```vba
' opaque source: 2次元 0 To 1, 0 To 2, values 10,11,12,20,21,22
' typed destinations: Long(), String(), Object()
' additional source: 2次元 1 To 2, 1 To 3
' probes: valid read, LBound/UBound, type mismatch, ByRef write-back, Property Let write-back
```

既存回帰 `tests/spec/opaque-array-binder.test.ts` は、配列型メタデータ、ByRef受け渡し、Property Let受け渡し、型不一致を検証する。独立プローブでは同じ契約に多次元形状、非0下限、Module/Class経路を追加した。

## 期待値

期待出力: 同型のLong/String/Object配列は正常に代入でき、LBound/UBoundと値を保持する。要素型メタデータのない配列をLong()へ渡す場合、String()へLong配列を渡す場合、数値混在配列をObject()へ渡す場合はError 13になる。ByRefとProperty Letは同じ形状を保持する。

```text
LONG=ERR=0;L1=0;U1=1;L2=0;U2=2;V=22
STRING_FROM_LONG=ERR=13
STRING=ERR=0
UNKNOWN_TO_LONG=ERR=13
OBJECT=ERR=0;L1=0;U1=1;L2=0;U2=1
OBJECT_MIXED=ERR=13
BYREF=L1=0;U1=1;L2=0;U2=2;V=22
PROPERTY=L1=0;U1=1;L2=0;U2=2;V=22
NONZERO=ERR=0;L1=1;U1=2;L2=1;U2=3;V=11
```

実測出力:

```text

STRING_FROM_LONG=ERR=13
STRING=ERR=0

BYREF_STRING=L2=0;U2=1;V=d

NONZERO=ERR=0;L1=1;U1=2;L2=1;U2=3;V=11
```

## 判定

判定状態: verified-no-bug。Opaque配列の多次元shape・bounds、要素型検証、ByRef、Property Letの代表経路は一貫して仕様どおりだった。SAFEARRAYメタデータと実体形状が矛盾する不正ホスト入力、空次元、3次元以上は本評価の対象外であり、別候補にはしない。
