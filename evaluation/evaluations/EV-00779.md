# Format文字列プレースホルダー充填

ASCII・BMP文字列の@/&/!充填は公式仕様と整合した。単独`@`の空文字と補助平面Unicodeは
Excel照合が必要なため、同じ候補をblockedとして保持する。

独立レビューで、`@`の空白充填、`&`の不足分無表示、`!`の左から右の充填、および
長さ0文字列のセクション選択が公式仕様に対応することを確認した。サロゲートペアの
文字単位と単独`@`空文字の厳密な出力は仕様に明記されていないため、Excel照合待ちとする。
