## 評価内容

String と String$ の数値および Date character 引数について、0〜257の境界と
Dateシリアル値を同じマトリクスで比較し、ANSI文字コードへの変換規則を確定する。

## 実施方法

`ExcelQueueVerification.bas` の `VerifyStringCharacterBoundary` を実行する。
数値 `0, 1, 65, 127, 128, 254, 255, 256, 257` と Date `0, 1, 65, 256, 257`
を `String` / `String$`へ渡し、各ケースの `Err.Number`、`Len`、`AscW`を `XL-226`
として出力する。Runnerでも同じCartesianケースを実行する。

## 期待値

期待出力:

Runnerでは各数値を下位8ビットへ変換し、Dateも同じcharacterコード規則へ従う。
各ケースのErr.Numberは0で、Lenは1となることを暫定期待値とする。Excelの
ANSI文字コードと異なるケースは、実機結果を根拠に別途確定する。

## 結果

実機プローブを追加し、ソースハッシュ一致のWorkbookを準備した。`XL-226`の
実機結果は未取得であり、判定を保留する。

## 判定
