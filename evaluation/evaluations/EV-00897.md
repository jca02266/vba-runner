## 評価内容

DateSerialの年・月・日のInteger幅境界を確認し、範囲外のエラーと範囲内の相対日付正規化を検証する。

## 実施方法

次の自己完結VBAを実行する。

```vb
Option Explicit
Public Function Probe() As String
    Dim value As Variant, errNo As Long, out As String
    On Error Resume Next
    Err.Clear: value = DateSerial(0, 1, 1): errNo = Err.Number: out = "Y0=" & CStr(errNo)
    Err.Clear: value = DateSerial(99, 1, 1): errNo = Err.Number: out = out & "|Y99=" & CStr(errNo)
    Err.Clear: value = DateSerial(-1, 1, 1): errNo = Err.Number: out = out & "|YNEG=" & CStr(errNo)
    Err.Clear: value = DateSerial(10000, 1, 1): errNo = Err.Number: out = out & "|YHIGH=" & CStr(errNo)
    Err.Clear: value = DateSerial(32768, 1, 1): errNo = Err.Number: out = out & "|YWIDTH=" & CStr(errNo)
    Err.Clear: value = DateSerial(2024, 1, 32768): errNo = Err.Number: out = out & "|DWIDTH=" & CStr(errNo)
    Probe = out
End Function
```

## 期待値

プログラムとしての期待出力:

```text
Y0=0|Y99=0|YNEG=6|YHIGH=6|YWIDTH=6|DWIDTH=6
```

0と99は既定の2桁年補正で有効、負数・10000・32768は引数幅超過のError 6、日引数32768も同じError 6になることを期待する。

## 結果

修正前の実測出力:

```text
Y0=0|Y99=0|YNEG=6|YHIGH=6|YWIDTH=6|DWIDTH=0
```

日引数32768だけがJavaScript Dateの正規化で受理され、仕様と不一致だった。`tests/spec/dateserial-conversion-matrix.test.ts`へ回帰テストを追加し、修正後はDWIDTHもError 6になった。

## 判定

判定状態: fixed

DateSerial専用の丸め後Integer幅検査を追加し、年・月・日の範囲外をError 6へ統一した。相対月日と0から99の年補正は既存テストで維持される。年範囲外と大幅な月日正規化の組合せは別候補へ分離した。
