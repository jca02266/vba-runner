# Formatカスタム数値セクション

## 再現

次の入力で、Decimalのゼロ値は第3セクションを使わず `0.00` を返した。

```vba
Format(CDec("0"), "0.00;(0.00);ZERO")
```

また、通常の数値では次の結果が `10.00E+05` になった。

```vba
Format(999999, "0.00E+00")
```

期待値はそれぞれ `ZERO` と `1.00E+06` である。

## 原因と修正

`exactPatternFormat` が負数かどうかだけでセクションを選び、ゼロ値の第3セクションを
無視していた。`formatNumberSection` は科学表記の丸め後に仮数を再正規化せず、10以上の
仮数を許していた。ゼロセクション選択と指数繰り上げを追加した。

## 回帰

`tests/spec/builtins.test.ts` に両方の最小再現を追加し、組み込み関数テストを通過した。
