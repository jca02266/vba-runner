# On Error状態の呼び出し境界

Class、標準手続き、配列、Collection、ループ、再帰、`On Error Resume Next`、ラベル復帰を
組み合わせて評価した。最初にループ後の `Err.Number=23` を不一致と見なしかけたが、
`On Error GoTo 0` はハンドラーを無効化するだけでErrオブジェクトを消去しないため、実際は
既存の配列・Collection結果と同じ正しい挙動だった。新規バグは確認されなかった。
