## 評価内容

Optional引数だけを持つクラスFunctionを、直接の裸参照、空括弧、明示引数、
CallByNameの引数省略、CallByNameの明示引数で呼び出し、動的メンバーの
Optional専用引数契約が共通に適用されるかを評価する。本評価の範囲はVBAクラス
インスタンスだけであり、外部COMオブジェクトのOptionalメンバーは含めない。

## 実施方法

```vba
' Runner用単一入力。Class OptionalBoxはクラスモジュール、Probeは標準モジュール。
Class OptionalBox
    Public Function OptionalOnly(Optional ByVal value As Long = 7) As Long
        OptionalOnly = value + 1
    End Function
End Class

Public Function Probe() As String
    Dim box As New OptionalBox, value As Variant, errNo As Long, result As String
    On Error Resume Next
    Err.Clear: value = box.OptionalOnly: errNo = Err.Number
    result = "DIRECT-OMITTED=" & CStr(errNo) & ":" & CStr(value)
    Err.Clear: value = box.OptionalOnly(): errNo = Err.Number
    result = result & "|DIRECT-PARENS=" & CStr(errNo) & ":" & CStr(value)
    Err.Clear: value = box.OptionalOnly(3): errNo = Err.Number
    result = result & "|DIRECT-VALUE=" & CStr(errNo) & ":" & CStr(value)
    Err.Clear: value = CallByName(box, "OptionalOnly", VbMethod): errNo = Err.Number
    result = result & "|DYNAMIC-OMITTED=" & CStr(errNo) & ":" & CStr(value)
    Err.Clear: value = CallByName(box, "OptionalOnly", VbMethod, 3): errNo = Err.Number
    result = result & "|DYNAMIC-VALUE=" & CStr(errNo) & ":" & CStr(value)
    Probe = result
    On Error GoTo 0
End Function
```

## 期待値

期待出力: `DIRECT-OMITTED=0:8|DIRECT-PARENS=0:8|DIRECT-VALUE=0:4|DYNAMIC-OMITTED=0:8|DYNAMIC-VALUE=0:4`

Optional引数は省略可能で、既定値7が使われるため省略時は8になる。明示した3は
4になる。CallByNameのargsは省略可能なので、同じFunctionを動的に呼んでも結果は
直接呼出しと一致することを期待する。

## 結果

実測出力: `DIRECT-OMITTED=0:8|DIRECT-PARENS=0:8|DIRECT-VALUE=0:4|DYNAMIC-OMITTED=0:8|DYNAMIC-VALUE=0:4`

直接呼出しとCallByNameの双方でOptionalの既定値と明示値が正しく束縛され、エラーは
発生しなかった。独立評価担当は同じ最小ソースを別実行し、直接呼出しとVBAクラスへの
CallByNameが期待値と一致することを確認した。独立レビューでも、Function文のOptional
既定値とCallByNameの省略可能なargsを根拠として、このVBAクラス範囲の判定は妥当と
確認された。TextStreamやDictionaryの必須引数経路は別契約であり、本評価では判定
しない。Excel/外部COM固有のOptionalメンバーは対象外で、別の実機比較を必要とする。

## 判定

判定状態: verified-no-bug

RunnerのVBAクラス直接呼出しとVBAクラスへのCallByName経路は、Optional専用Functionの
省略・明示引数を同じ既定値契約で処理している。この結果はRC-00070全体や外部COMの
契約を反証するものではなく、VBAクラス経路の未解決境界が再現しなかったことだけを示す。
