# CurDir/ChDir引数Null境界

`CurDir(Null)` は修正前、Drive引数を無視してcwdを返し `Err.Number=0` になった。
横展開した`ChDir Null`も、Nullを文字列化する前にPath not found (Error 76)へ
変換されていた。VBAでは両方ともInvalid use of Null (Error 94)である。

CurDirとChDirの各組み込み入口でNullを先に検証し、回帰テストを追加した。ChDrive、
Dir、通常のsandbox相対移動には同じ欠落がないことを確認した。
