# FSO Boolean文字列Variantの暗黙変換

独立評価で、FSOのBoolean引数へ文字列 `"True"` や `"1"` を直接渡すと、VBAの
`CBool`相当の暗黙変換が行われずFalseとして処理されていた。CreateTextFileの上書きと
OpenTextFileの新規作成で再現し、共通判定を `vbaToBoolean` へ委譲した。Nullと不正文字列
の正確な実Excelエラーは別の実機照合待ちとして残した。
