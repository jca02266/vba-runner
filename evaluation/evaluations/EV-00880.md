## 評価内容

source配下の複数階層にファイルを置き、destinationの後段ファイルだけを既存状態にして`overwrite: false`でコピーする。衝突前のファイルが先行コピーされないこと、既存内容とsourceが保持されることをMemoryFileSystemとNodeFileSystemで比較する。

## 実施方法

同じsource/a/first.txt、source/z/conflict.txt、destination/z/conflict.txtを両バックエンドへ作成し、`copyDirectorySync`を実行する。エラーコード、destination/a/first.txtの有無、既存conflict.txtの内容、source/a/first.txtの保持を出力する。

## 期待値

期待出力:

両バックエンドが次の同じ出力になることを期待する。

```text
Memory NESTED=EEXIST:false:old:true
Node NESTED=EEXIST:false:old:true
```

## 結果

実測出力:

```text
Memory NESTED=EEXIST:false:old:true
Node NESTED=EEXIST:false:old:true
```

衝突前のファイルはdestinationへ作成されず、既存destination内容とsourceは両バックエンドで保持された。

## 判定

判定状態: verified-no-bug

入れ子構造の衝突失敗時にも、MemoryFileSystemとNodeFileSystemのエラーと状態は一致した。
