## 評価内容

既存ファイルを移動先に用いたmoveFileSyncをMemoryFileSystemとNodeFileSystemで実行し、
衝突時のエラーとsource/destinationの状態を比較する。正常移動、source不存在、親欠落、
既存ディレクトリも併せて確認し、BUG-00542の移動先衝突仮説をFile経路へ横展開する。

## 実施方法

各バックエンドに同じsourceファイルとdestinationファイルを作り、moveFileSyncを呼ぶ。
例外コード、sourceの存在、destinationの存在、destination内容を記録する。空・非空の
既存ディレクトリ、source不存在、親欠落も同じ行列で実行する。

## 期待値

期待出力:

```text
Memory existing-file=EEXIST:source=true:destination=true
Node existing-file=EEXIST:source=true:destination=true
```

既存destinationはファイルでもディレクトリでも置換せず、衝突時はsourceとdestinationを
変更しないことを期待する。

## 結果

実測出力:

```text
Memory existing-file=EEXIST:source=true:destination=true
Node existing-file=ok:source=false:destination=true
Memory existing-directory=EEXIST:source=true:destination=true
Node existing-directory=EISDIR:source=true:destination=true
FSO-Memory existing-file=Err58
FSO-Node existing-file=Err0
```

NodeFileSystemは既存ファイルをrenameSyncで置換してsourceを削除した。独立評価では
正常移動、source不存在、親欠落でも同じ境界を確認した。既存ディレクトリでは両者とも
sourceとdestinationを保持したが、NodeはEISDIR、MemoryはEEXISTとなった。FSO入口でも
既存ファイルのMemory Err=58／Node Err=0置換を再現し、File経路にも差異が到達することを
確認した。

## 判定

判定状態: fixed

moveFileSyncにもBUG-00542と同じ移動先衝突契約の差異が存在する。BUG-00543として記録し、
共通契約の修正とFSO入口の横展開を続ける。
