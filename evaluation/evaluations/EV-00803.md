# Property Let配列要素ByRefの最小再現

## 評価内容

Property Letの暗黙ByRef引数へ配列要素を渡したとき、呼出元の配列要素が書き換わる経路を
単独で評価した。

## 期待値

Property Letの暗黙ByRef引数へ配列要素を渡した場合、Property Let内で引数へ書き込んだ値が
呼出元の配列要素へ反映されるかを確認する。現時点ではVBA仕様上の期待値を確定していない。

## 実施方法

次の最小VBAモジュールを実行し、`ProbeArrayElement`の戻り値を記録した。

```vba
Class Box
Private seen As Long
Public Property Let Value(ByRef incoming As Long)
  seen = incoming
  incoming = incoming + 1
End Property
Public Function SeenValue() As Long
  SeenValue = seen
End Function
End Class

Function ProbeArrayElement() As String
Dim b As New Box
Dim values(0 To 0) As Long
values(0) = 7
On Error Resume Next
b.Value = values(0)
ProbeArrayElement = CStr(Err.Number) & ":" & CStr(b.SeenValue()) & ":" & CStr(values(0))
End Function
```

## 結果

出力は `actual=0:7:7` だった。Property Letの呼び出し自体は成功し、Property Let内で
受け取った値は7だったが、引数を書き換えた結果は呼出元の配列要素へ反映されなかった。

## 判定

期待値の仕様根拠が未確定のため、現時点ではバグとも非バグとも判定しない。
実Excelまたは公式仕様で書戻し契約を確認した後に、`verified-no-bug`または`bug-found`へ
遷移する。
