# Decimal/Currency名前付きFormat精度

独立評価で、Decimal/CurrencyのGeneral Number、Currency、Fixed、Standard、Percentが
JavaScript Number経路へ入り、高精度の整数・小数を丸めていた。名前付き書式を固定小数点
文字列から直接生成する経路を追加し、General Number、Currencyを含む回帰テストを追加した。
Scientific書式と指数表記は別の未解決境界として記録した。
