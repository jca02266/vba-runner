## 評価内容

As Newクラス変数を通常のLong変数相当のフィールドの前後に宣言した場合、宣言順が遅延生成や既定値に影響するかを確認する。

## 実施方法

次の最小ソースで、As Newフィールドの宣言順だけを変えた2クラスを生成し、同じプローブを実行する。

```vba
Option Explicit
Class Box
End Class

Class HolderBefore
    Public Item As New Box
    Public Count As Long
End Class

Class HolderAfter
    Public Count As Long
    Public Item As New Box
End Class

Public Function Probe() As String
    Dim before As New HolderBefore, after As New HolderAfter
    Probe = CStr(before.Item Is Nothing) & ":" & CStr(before.Count) & ":" & _
        CStr(after.Item Is Nothing) & ":" & CStr(after.Count)
End Function
```

## 期待値

期待出力：`False:0:False:0`。As Newフィールドは最初の参照時に同じクラスインスタンスへ解決され、Longフィールドは0で初期化されるため、宣言順による差は発生しないと仮説する。

## 結果

実測出力：`False:0:False:0`。As Newフィールドの宣言順を前後に変えても両クラスの結果は一致し、宣言順依存の差異は再現しなかった。
