## 評価内容

Date型ByRef引数を変更し、その値をDate戻り値として返すClass FunctionをCallByNameで呼び出す。

## 実施方法

```vba
' Class module: DateMutator
Public Function ReturnDate(ByRef value As Date) As Date
    value = CDate(0)
    ReturnDate = value
End Function

' Standard module
Function RunCase() As String
    Dim m As New DateMutator
    Dim d As Date
    Dim x As Date
    d = CDate("2024-01-02")
    x = CallByName(m, "ReturnDate", VbMethod, d)
    RunCase = DateKey(d) & "|" & DateKey(x)
End Function

Function DateKey(ByVal value As Date) As String
    DateKey = CStr(Year(value)) & "-" & CStr(Month(value)) & "-" & CStr(Day(value))
End Function
```

## 期待値

期待出力：`1899-12-30|1899-12-30`

CallByNameでもByRef引数への書戻しとFunctionのDate戻り値が同じゼロ日になることを期待する。

## 結果

実測出力：`1899-12-30|1899-12-30`

RunnerはCallByName VbMethodでもDate ByRefの書戻しとDate戻り値を同じ値として返した。

## 判定

判定状態: verified-no-bug

対象のClass CallByName経路で不一致は再現せず、新規Findingは確認されなかった。
