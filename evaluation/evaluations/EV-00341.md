# RmDir非空ディレクトリ境界

修正前は、ファイルを含むディレクトリに`RmDir`を実行するとMemoryFileSystemの
実装により成功していた。VBAではPath/File access error（Error 75）である。
RmDirの共通入口で対象の存在、ディレクトリ種別、内容を検証し、非空の場合は
Error 75を返すようにした。回帰テストでファイルを含むディレクトリを固定した。
