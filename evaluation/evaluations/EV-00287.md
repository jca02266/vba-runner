# FSO返却オブジェクトの共通化

独立評価で、`GetFile` の返却値に対する `Name` と `ParentFolder` の参照、`Delete` の
呼出しがError 438になった。`GetFolder` も `Name` だけの軽量オブジェクトを返しており、
FileとFolderの共通パス属性・操作境界が共有されていなかった。

原因はFSOトップレベルの引数metadataではなく、返却オブジェクトを個別のリテラルで
組み立てていた共通化不足である。File/Folderの属性、親フォルダ、操作メソッドと名前付き
引数仕様を共通ファクトリへ移し、元のGetFile経路とGetFolder経路の回帰テストを追加した。
