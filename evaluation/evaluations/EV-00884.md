## 評価内容

TimeSerialの負の時・分・秒、60超過、24時繰り上げを6ケースで確認する。

## 実施方法

`tests/spec/timeserial-boundary.test.ts`を実行し、各入力の時刻表現とErr.Numberを出力する。

## 期待値

期待出力:

```text
TIME-SERIAL 0,0,-1 => 00:00:01:ERR=0
TIME-SERIAL 0,-1,0 => 00:01:00:ERR=0
TIME-SERIAL 0,60,0 => 01:00:00:ERR=0
TIME-SERIAL 24,0,0 => 1899/12/31:ERR=0
TIME-SERIAL -1,0,0 => 01:00:00:ERR=0
TIME-SERIAL 0,0,60 => 00:01:00:ERR=0
```

## 結果

実測出力:

```text
TIME-SERIAL 0,0,-1 => 00:00:01:ERR=0
TIME-SERIAL 0,-1,0 => 00:01:00:ERR=0
TIME-SERIAL 0,60,0 => 01:00:00:ERR=0
TIME-SERIAL 24,0,0 => 1899/12/31:ERR=0
TIME-SERIAL -1,0,0 => 01:00:00:ERR=0
TIME-SERIAL 0,0,60 => 00:01:00:ERR=0
```

6ケースすべてで期待値と実測値が一致した。

## 判定

判定状態: verified-no-bug

TimeSerialの負数・60超過・24時境界に新しい差異は確認されなかった。
