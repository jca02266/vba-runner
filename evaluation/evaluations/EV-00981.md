## 評価内容

WIDTH文の幅引数へNullを渡す経路が、Lock/UnlockのNull境界と同じ設計上の責務欠落を持つか確認する。

## 実施方法

```vba
Sub ProbeWidthNull()
    Open "width-null.dat" For Output As #1
    On Error Resume Next
    Err.Clear
    Width #1, Null
    Debug.Print "WIDTH_NULL ERR=" & CStr(Err.Number)
    Close #1
End Sub
```

## 期待値

プログラム上の期待出力: `WIDTH_NULL ERR=94`。
Lock/Unlockと同じく、幅引数のNullはExcel固有のError 94として扱われる。

## 結果

プログラム上の観測結果: Runnerは `WIDTH_NULL ERR=1000` となった。
実測出力: Excel `WIDTH_NULL ERR=94`、Runner `WIDTH_NULL ERR=1000`。不一致を確認した。
