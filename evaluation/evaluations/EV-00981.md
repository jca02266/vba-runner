## 評価内容

WIDTH文の幅引数へNullを渡す経路が、Lock/UnlockのNull境界と同じ設計上の責務欠落を持つか確認する。

## 実施方法

```vba
Sub ProbeWidthNull()
    Open "width-null.dat" For Output As #1
    On Error Resume Next
    Err.Clear
    Width #1, Null
    Debug.Print "WIDTH_NULL ERR=" & CStr(Err.Number)
    Close #1
End Sub
```

## 期待値

プログラム上の仮説出力: `ERR=<Excelの実測値>`。
Lock/Unlockで確認されたNull固有エラーがWIDTHにも適用されるかを、Runnerの実行結果とExcel実機結果で検証する。

## 結果

プログラム上の観測結果: Runnerは `WIDTH_NULL ERR=1000` となった。
現時点ではソース上の直接変換経路とRunner結果を確認しているが、Excelのエラー契約は未確定である。
