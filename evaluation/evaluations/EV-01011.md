## 評価内容

Public UDTをモジュール修飾して宣言した動的配列を、同じ要素型のByRef配列引数へ渡したとき、型識別と要素書戻しが保たれるかを確認する。

## 実施方法

```vba
' Producer.bas
Option Explicit
Public Type RecordT
    Id As Long
    Label As String
End Type

Public Sub Sum(ByRef values() As RecordT)
    values(0).Id = values(0).Id + 1
    values(1).Id = values(1).Id + 1
End Sub

' Consumer.bas
Option Explicit
Public Function Probe() As String
    Dim values() As Producer.RecordT
    ReDim values(0 To 1)
    values(0).Id = 12
    values(1).Id = 34
    Producer.Sum values
    Probe = CStr(values(0).Id + values(1).Id)
End Function
```

`Probe`を実行し、修飾型配列をByRef引数へ渡した後の要素値を確認する。

## 期待値

プログラム上の期待出力: `48`（要素がそれぞれ13、35へ書き戻される）。

文章での期待: `Producer.RecordT`と`RecordT`は同じPublic UDTを指すため、配列引数の型検査を通過し、ByRef変更が呼出し元へ反映される。

## 結果

プログラム上の実測出力: 修正前は`Run-time error '13': Type mismatch`（`Producer.Sum values`の呼出し）。修正後は`48`。

文章での結果: 配列宣言は受理されるが、修正前は引数側の要素型が`producer.recordt`、手続き側が`recordt`として比較され、同一Public UDTとして一致しなかった。修正後は所有モジュールを考慮して一致し、書戻しが成功した。

## 判定

判定状態: fixed。

独立探索エージェントがリポジトリ外の最小プログラムで再現し、同じ型を指す修飾名と裸名の正規化がByRef配列引数検査で欠落していることを確認した。直接修正前のため、真因は別レビュー後に確定する。
