## 評価内容

DateSerialのyear引数が許容範囲外でも、月の繰り下げで最終日付が範囲内になる場合のExcel契約を確認する。

## 実施方法

`ExcelQueueVerification.bas` の `VerifyDateSerialNormalizationBoundary` を実行し、`DateSerial(10000, -1, 1)` のErr.Numberと戻り値を`XL-223`として記録する。ランナーでは次の自己完結VBAを実行する。

```vb
Option Explicit
Public Function Probe() As String
    Dim value As Variant, errNo As Long
    On Error Resume Next
    Err.Clear: value = DateSerial(10000, -1, 1): errNo = Err.Number
    Probe = "ERR=" & CStr(errNo) & " VALUE=" & CStr(value)
End Function
```

## 期待値

プログラムとしての暫定期待出力:

```text
ERR=6 VALUE=
```

Microsoft仕様のyear上限から、10000を入力年として受理せずエラーになることを仮説とする。具体的なエラー番号とErr後の値はExcel実機で確定する。

## 結果

ランナー実測出力:

```text
ERR=0 VALUE=9999/11/01
```

ランナーは月の繰り下げ後の日付だけを検査し、year=10000を受理している。Excel実機のXL-223結果は未取得である。
