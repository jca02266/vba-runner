## 評価内容

UDTメンバーの固定配列境界にConst名を指定したとき、MS-VBALのconstant-expression契約どおりに解析・実行できるか確認する。

## 実施方法

```vba
Option Explicit
Const UDT_LAST_INDEX As Integer = 1

Type IndexedRecord
    Values(UDT_LAST_INDEX) As Integer
End Type

Function RunCase() As String
    Dim record As IndexedRecord
    record.Values(0) = 7
    record.Values(1) = 9
    RunCase = CStr(record.Values(0)) & "," & CStr(record.Values(1))
End Function
```

## 期待値

期待出力：`7,9`

MS-VBALの配列境界はconstant-expressionを受け付けるため、Const値1が上限として解決され、UDTメンバーの添字0と1への代入・読出しが成功することを期待する。

## 結果

実測出力：`Parse error: Expected 'As' in Type member declaration`

Runnerは`Values(UDT_LAST_INDEX)`のConst識別子を配列境界として消費せず、`As`を期待するパースエラーになった。数値リテラル境界と通常Dim配列のConst境界は別経路で動作した。

## 判定

判定状態: bug-found

仕様差異を再現し、独立RCAレビュー、共通式保持への修正、回帰テストを完了した。Option Baseや修飾Constは別候補で継続する。
