## 再現

```vba
Public Function Probe(ByVal h As Long, ByVal m As Long, ByVal s As Long) As String
    Probe = CStr(TimeSerial(h, m, s))
End Function
```

runnerでは`TimeSerial(0, 0, -1)`が`00:00:01`となり、Excel実機の結果と一致した。
XL-042では負の分・時・複合値も一致した。TimeSerial結果を受け取る各日付関数の
読出し経路をXL-047へ追加し、Hour/Minute/Second/Format/DateDiffの実Excel結果もrunnerと
一致した。

## 真因分析

独立評価では負数を絶対値側へ復元するように見えたが、Excel実機で確認できた
`TimeSerial(0,0,-1)`はrunnerと一致した。したがってこの時点で実装修正は行わず、
残りの負数組み合わせを`needs-excel`として保持する。
