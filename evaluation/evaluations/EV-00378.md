## 再現

```vba
Public Function Probe(ByVal h As Long, ByVal m As Long, ByVal s As Long) As String
    Probe = CStr(TimeSerial(h, m, s))
End Function
```

runnerでは`TimeSerial(0, 0, -1)`が`00:00:01`となった。Excel/VBAの期待値は
前日`23:59:59`である。同様に負の分・時・複合負数でも符号付き繰り下げが失われた。

## 真因分析

独立した横展開調査と真因分析で、直接原因を負小数の復元処理、真因を負Dateシリアルの
表現規約の不一致と特定した。修正前に記録したため、`directFixStatus`と
`rootFixStatus`はともに`planned`である。次のループで直接修正を実装し、回帰テストと
横展開確認を行う。真因の共通化が必要な場合は、発見コミット後の別タスクとして扱う。
