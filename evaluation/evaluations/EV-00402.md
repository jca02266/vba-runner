# クラスメソッドAs Object引数境界

独立評価で`Public Sub Accept(ByVal value As Object)`へprimitive、`Null`、`Nothing`、bound class
objectを渡した。現行runnerはすべてエラーなしで本体を実行したが、Object参照でないprimitiveと
`Null`はError 424になるべきである。
