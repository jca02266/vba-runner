# Decimal整数演算のLong境界

実ExcelのXL-014で、最大Decimal値に対する `\\ 3` がError 6になることを確認した。
旧実装はDecimalの96ビット商をそのまま返しており、実Excelの整数有効型境界と一致しなかった。

`evaluateDecimalOp` の `\\` と `Mod` を、銀行丸め後のLong範囲で検査してから演算するよう修正した。
範囲外はError 6、ゼロ除算はError 11とする。

XL-014では最大Decimal値の `\\ 3` と `Mod` がともにError 6、`-5.5 \\ 2.5` は
`-3`、その後のエラー番号は0だった。エラーになる経路では結果型は存在しないため、
この評価で追加の型照合は不要とする。
