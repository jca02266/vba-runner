## 評価内容

CallByNameでDate ByRef引数へEmptyを渡した場合の変換とエラー契約を確認する。

## 実施方法

```vba
' Class module: DateMutator
Public Seen As Date
Public Sub Touch(ByRef value As Date)
    value = DateSerial(1899, 12, 30)
    Seen = value
End Sub

' Standard module
Function RunCase() As String
    Dim m As New DateMutator, errNo As Long
    On Error Resume Next
    Err.Clear
    CallByName m, "Touch", VbMethod, Empty
    errNo = Err.Number
    On Error GoTo 0
    RunCase = CStr(errNo) & "|" & CStr(Year(m.Seen)) & "-" & CStr(Month(m.Seen)) & "-" & CStr(Day(m.Seen))
End Function
```

## 期待値

期待出力：`0|1899-12-30`

EmptyはDate ByRef引数へ既定値として変換され、呼出し先の代入が実行されたうえでCallByName呼出しがエラーなく完了することを期待する。

## 結果

実測出力：`0|1899-12-30`

RunnerはEmptyからDate ByRefへの変換を許可し、呼出し先のDate代入を実行してCallByName呼出しをエラー0で完了した。

## 判定

判定状態: verified-no-bug

対象のClass CallByName経路で不一致は再現せず、新規Findingは確認されなかった。
