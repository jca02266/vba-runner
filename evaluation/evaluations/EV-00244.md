# Double文字列指数オーバーフロー

独立評価で `CDbl("1E+309")` が `Infinity` と `Err.Number=0` を返した。VBA Doubleの
最大値は約 `1.79769313486231E+308` であり、範囲外はError 6である。`vbaToNumber` が
JavaScriptの非有限値をそのまま返していたため、非有限値をOverflowへ変換するよう修正し、
境界回帰テストを追加した。
