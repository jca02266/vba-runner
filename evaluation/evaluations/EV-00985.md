## 評価内容

Mid関数の開始位置へNullを渡す数値変換経路を確認する。

## 実施方法

```vba
Sub ProbeMidNull()
    Dim value As String
    On Error Resume Next
    value = Mid$("abc", Null, 1)
    Debug.Print "MID_NULL ERR=" & CStr(Err.Number)
End Sub
```

## 期待値

プログラム上の期待出力: `MID_NULL ERR=94`。
NullをMidの開始位置へ渡した場合はError 94になる。

## 結果

プログラム上の観測結果: Runnerは `MID_NULL ERR=94` となった。
実測出力: ExcelとRunnerはともに `MID_NULL ERR=94` で一致した。
