## 評価内容

Functionの過剰引数について、通常の識別子、Classメンバー、Module修飾メンバーの
エラー段階とエラー番号を同じ行列で確認する。

## 実施方法

次の2つの自己完結したVBAソースを個別に実行する。

```vba
Class ArityTarget
Public Function Target() As Long
    Target = 0
End Function
End Class
Sub Caller()
    Dim instance As New ArityTarget
    Dim result As Long
    result = instance.Target(1)
End Sub
```

```vba
Attribute VB_Name = "CallerModule"
Function ModuleTarget(value As Long) As Long
    ModuleTarget = value
End Function
Sub Caller()
    Dim result As Long
    result = CallerModule.ModuleTarget(1, 2)
End Sub
```

Class・Module修飾Functionの呼出しを個別に実行し、実行時エラー番号を記録する。
回帰テストでは同じソースを分離したケースとして検証する。

## 期待値

期待出力:

```text
Class Function excess: runtime Error 13 (Type mismatch)
Module-qualified Function excess: runtime Error 13 (Type mismatch)
Function missing required argument: precheck Error 449 (Argument not optional)
Sub/Property excess argument: precheck Error 450
```

Functionの過剰引数だけは実行時型不一致、それ以外の引数契約違反は既存の静的検査を
維持する。

## 結果

実測出力:

```text
修正前 Class Function excess: precheck Error 450
修正前 Module-qualified Function excess: precheck Error 450
修正後 Class Function excess: runtime Error 13
修正後 Module-qualified Function excess: runtime Error 13
回帰行列: passed
```

修正前は修飾Function経路だけがSubと同じ静的Error 450へ到達していた。修正後は
Functionの過剰引数を実行時バインダーへ渡し、Error 13になった。

## 判定

判定状態: fixed

Class・Module修飾Functionの過剰引数precheckを実行時Error 13経路へ修正し、必須引数不足と
Sub/Propertyの静的エラー契約を維持した。横展開の結果は根因分析とBUG-00527へ反映する。
