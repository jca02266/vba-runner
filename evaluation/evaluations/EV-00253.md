# FSO Boolean Variantの暗黙変換

独立評価と横展開調査で、FSOのBoolean引数に数値1や2を渡すと、VBAではTrueへ
暗黙変換される一方、実装はFalseとして扱っていた。CreateTextFileの上書き・Unicode、
OpenTextFileの新規作成に共通する判定を数値非0へ拡張し、回帰テストを追加した。
文字列やNullなどの型変換は仕様確認が必要なため未解決として残した。
