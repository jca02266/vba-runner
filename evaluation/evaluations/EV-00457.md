# 財務関数の不正引数境界

NPVの同符号・単一・全ゼロ配列を独立再現したところ、RunnerはError 5を返した。
Microsoft VBA仕様もValueArrayに負値と正値の両方を要求しているため、実装差異はない。
過去のBUG-00381は誤った期待値に基づく記録として退役し、正負契約の回帰テストは維持した。
