## 評価内容

ClassのProperty Getについて、必須添字の通常呼出し、引数省略、With内呼出し、0引数
Property Get、戻り値への添字を一つの最小行列で確認する。

## 実施方法

```vba
' Class module: ItemHolder
Private values(1 To 2) As String
Private Sub Class_Initialize()
    values(1) = "one"
    values(2) = "two"
End Sub
Public Property Get Item(index As Long) As String
    Item = values(index)
End Property
Public Property Get Name() As String
    Name = "named"
End Property
Public Property Get Values() As Variant
    Values = Array("vzero", "vone")
End Property

' Standard module
Sub Probe()
    Dim obj As ItemHolder, result As String
    Set obj = New ItemHolder
    result = obj.Item(1)
    With obj
        result = .Item(2)
    End With
    result = obj.Name
    result = obj.Values(1)
End Sub
```

有効な4経路（`obj.Item(1)`、`With obj: .Item(2)`、`obj.Name`、`obj.Values(1)`）は
上記ソースで実行する。必須引数の裸参照は、同じClass定義に対して次の別ソースを
コンパイル前検査へ渡し、プロシージャ本体を実行せずに確認する。

```vba
Sub ProbeMissing()
    Dim obj As ItemHolder, result As String
    Set obj = New ItemHolder
    result = obj.Item
End Sub
```

各ケースを個別に実行し、戻り値またはコンパイルエラーを記録する。標準モジュール修飾は複数モジュールを
注入する別の既存テスト経路であり、この評価のClass行列には含めない。

## 期待値

期待出力: `Item(1)="one"`、`Item`は`Compile error: Argument not optional`、`.Item(2)="two"`、
`Name="named"`、`Values(1)="vone"`。

文章としては、必須引数の省略だけがArgument not optionalとなり、有効な添字・With・
0引数Property Get・戻り値添字は通常の値を返すことを期待する。

## 結果

実測出力: 独立Runner評価は`Item(1)="one"`、裸参照は`Compile error: Argument not optional`、
With内`Item(2)="two"`、`Name="named"`、`Values(1)="vone"`だった。

5経路すべてが期待値と一致し、引数契約の入口差は検出されなかった。Excel、COM、複数
標準モジュール修飾はこの評価の対象外である。

## 判定

判定状態: verified-no-bug

Class/With/Property Get戻り値の添字境界では新規Findingなし。RC-00071の残る標準
モジュール修飾・動的COM範囲は別候補で継続する。
