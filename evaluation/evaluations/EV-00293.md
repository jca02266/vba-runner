# 符号付き型サフィックス最小値の評価順序

独立評価で、`-32768%` と `-2147483648&` がError 6になった。正のMagnitudeを先に
Integer/Longへ検証していたためで、Lexerや個別代入先ではなく、Unary minusと数値リテラル
サフィックスの共通評価順序が原因だった。

Unary minusの共通NumberLiteral経路で、符号付きInteger/Long最小値を最終値として先に
確定する処理を追加し、通常式・代入・括弧境界の回帰テストを追加した。
