## 評価内容

FSO.GetFileの必須pathnameを省略した`Set f = fso.GetFile`と
`Set f = fso.GetFile()`を同じVBA手続きで比較する。TextStream.Readとは別の
COMメンバーについて、引数契約が値式ではなくSet代入にも適用されるかを確認する。

## 実施方法

```vba
Public Function Probe() As String
    Dim fso As Object, f As Object, out As String
    Set fso = CreateObject("Scripting.FileSystemObject")
    On Error Resume Next
    Err.Clear
    Set f = fso.GetFile
    out = "OMITTED=" & CStr(Err.Number)
    Err.Clear
    Set f = fso.GetFile()
    out = out & "|PARENS=" & CStr(Err.Number)
    Probe = out
    On Error GoTo 0
End Function
```

## 期待値

期待出力（仮説）: `OMITTED=450|PARENS=450`

GetFileのpathnameは必須であるため、Excelでは省略形式と括弧付き形式の双方が
引数不足として扱われると仮定する。実機または仕様根拠で検証するまで、この値は
確定期待値として扱わない。

## 結果

実測出力（Runner）:

```text
Set: OMITTED=424|Object;PARENS=449|Object;VALID=0|Object|getfile.txt
Variant: OMITTED=0|Object;PARENS=449|Object
```

Runnerでは、Set代入の省略形式がObject required、括弧付き形式がArgument not optional
となり、Variant代入では省略形式がエラーなしでObjectを返した。有効なpathnameでは
Objectを返した。Excel結果は未取得であり、この時点ではバグ判定を行わない。

## 判定

判定状態: needs-excel

TextStream.Readとは異なるFSOメンバーの最小再現を記録した。独立評価レビュー後、
Excelの同一ソース結果または仕様根拠を確認して判定する。
