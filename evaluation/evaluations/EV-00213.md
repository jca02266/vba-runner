# LongLongとStringの算術型昇格

XL-016で `CLngLng("9007199254740993")` にStringを加減算したところ、Excelは
`ADD=9.00719925474099E+15`、`SUB=9.00719925474099E+15` と出力した。
Runnerはそれぞれ `9007199254740992`、`9007199254740991` を返した。

LongLong単独のBigInt経路ではなく、String混在時のDouble表示経路を修正した。

## 実Excel照合

XL-016では `ADD` と `SUB` がともに `9.00719925474099E+15`、単項マイナスは
`-9007199254740993` となった。XL-017ではCurrencyの指数表記・桁区切り・先頭`+`の
3入力がすべて `900719925474099.3125` となった。LongLong/String混在の乗算・比較・
除算・`Mod` は未照合のため、別候補として残す。
