## 評価内容

SYDの入力領域エラーと、計算結果が有限値でなくなるOverflowを同じエラー出口で扱っていないかを、代表的な符号・境界値で確認する。

## 実施方法

次の最小ソースをランナーで実行し、同じケースをExcel用のXL-211プローブとして追加して比較する。

```vba
Sub ProbeSydBoundaries()
    Dim value As Double, errNo As Long
    On Error Resume Next
    Err.Clear: value = SYD(100, -1, 5, 1): errNo = Err.Number
    Debug.Print "NEG_SALVAGE ERR=" & CStr(errNo)
    Err.Clear: value = SYD(1E+308, -1E+308, 2, 1): errNo = Err.Number
    Debug.Print "NONFINITE ERR=" & CStr(errNo)
    On Error GoTo 0
End Sub
```

## 期待値

プログラム上の期待値は、両ケースのError番号をExcel実機結果で確定することである。仕様上、SYDの引数は正数契約であり、領域違反を一般的なOverflowと同じError 6へ固定してはならない。

## 結果

ランナーの既存テストでは負のSalvage境界と巨大な中間値の回帰は通過したが、上記2ケースに対応するExcelプローブは未作成である。したがって、Error番号の差異と真因の適用範囲は未確定である。

## 判定

判定状態: needs-excel-probe

Excel比較用のXL-211プローブ作成と実機結果の取得が必要である。結果確定後に、SYD固有の領域検証を共通金融関数のOverflow処理から分離するか判断する。
