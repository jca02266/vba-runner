## 評価内容

SYDの入力領域エラーと、計算結果が有限値でなくなるOverflowを同じエラー出口で扱っていないかを、代表的な符号・境界値で確認する。

## 実施方法

次の最小ソースをランナーで実行し、同じケースをExcel用のXL-211/XL-213プローブとして追加して比較する。

```vba
Sub ProbeSydBoundaries()
    Dim value As Double, errNo As Long
    On Error Resume Next
    Err.Clear: value = SYD(100, -1, 5, 1): errNo = Err.Number
    Debug.Print "NEG_SALVAGE ERR=" & CStr(errNo)
    Err.Clear: value = SYD(1E+308, -1E+308, 2, 1): errNo = Err.Number
    Debug.Print "NONFINITE ERR=" & CStr(errNo)
    On Error GoTo 0
End Sub
```

## 期待値

期待出力:

```text
XL-211 NEG-SALVAGE ERR=5
XL-211 NONFINITE ERR=5
XL-213 POSITIVE-NONFINITE ERR=0
```

プログラム上の期待値は、SYDの領域違反はError 5、数学的に有限な正数入力の結果はError 6にならずExcelと同じ値を返すことである。

文章による期待値: SYD固有の入力領域検証と、正数入力での戻り値契約を一般的なOverflow Error 6と混同しない。

Excel照合前は正数入力だけの非有限結果と表現していたが、独立分析により数学的には有限な最終結果を中間乗算がInfinityにした事象と訂正した。仕様上の正数引数契約と、実機で観測したError 0を分けて記録する。

## 結果

実測出力:

```text
XL-211 NEG-SALVAGE ERR=5
XL-211 NONFINITE ERR=5
XL-213 POSITIVE-NONFINITE ERR=0
```

Runnerの対応する正数入力ケースは`ERR=6`となった。

ランナーではXL-211の負Salvage境界がError 5、XL-213の正数入力だけの非有限境界がError 6となった。Excelプローブで両境界を照合し、XL-213だけのError番号差異を確認した。真因の適用範囲は独立レビュー待ちである。

## 判定

判定状態: bug-found

XL-211では負SalvageがError 5、XL-213では正数入力だけの非有限境界がExcel `ERR=0`、Runner `ERR=6`となった。SYD固有の非有限結果分類に差異があり、BUG記録と独立RCAが必要である。
