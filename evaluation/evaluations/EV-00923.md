## 評価内容

ModuleとClassのProperty Getが返す2次元配列について、下限変更、正常添字、上限外、
下限外、ランク不一致、非整数添字を比較する。1次元の下限変更配列も確認する。

## 実施方法

次のModuleとClassを用意し、同じ呼出し行列を実行する。

`ArrayProvider.bas`:

```vba
Option Explicit

Public Property Get Values() As Variant
    Dim data(-2 To 0, 3 To 4) As Long
    data(-2, 3) = 23
    data(0, 4) = 4
    Values = data
End Property

Public Property Get OneDimensional() As Variant
    Dim data(-2 To 0) As Long
    data(-2) = 2
    data(0) = 0
    OneDimensional = data
End Property
```

`ArrayProviderClass.cls`は同じ`Values`と`OneDimensional`のProperty Getをクラスのメンバーとして
定義する。

```vba
Option Explicit

Private values(-2 To 0, 3 To 4) As Long
Private oneDimensional(-2 To 0) As Long

Public Property Get Values() As Variant
    values(-2, 3) = 23
    values(0, 4) = 4
    Values = values
End Property

Public Property Get OneDimensional() As Variant
    oneDimensional(-2) = 2
    oneDimensional(0) = 0
    OneDimensional = oneDimensional
End Property
```

`RunProbe.bas`:

```vba
Option Explicit

Private Sub Probe2D(ByVal label As String, ByRef data As Variant)
    Dim value As Variant, errNo As Long
    Debug.Print label & "-SHAPE=" & LBound(data, 1) & ":" & UBound(data, 1) & ":" & LBound(data, 2) & ":" & UBound(data, 2)
    Debug.Print label & "-VALID=" & CStr(data(-2, 3)) & "," & CStr(data(0, 4))
    On Error Resume Next
    Err.Clear: value = data(1, 3): errNo = Err.Number
    Debug.Print label & "-OUTSIDE=" & CStr(errNo)
    Err.Clear: value = data(0): errNo = Err.Number
    Debug.Print label & "-RANK=" & CStr(errNo)
    Err.Clear: value = data(0, 3.5): errNo = Err.Number
    Debug.Print label & "-FRACTION=" & CStr(errNo)
    On Error GoTo 0
End Sub

Private Sub Probe1D(ByVal label As String, ByRef data As Variant)
    Dim value As Variant, errNo As Long
    Debug.Print label & "-SHAPE=" & LBound(data, 1) & ":" & UBound(data, 1)
    On Error Resume Next
    Err.Clear: value = data(-2.5): errNo = Err.Number
    Debug.Print label & "-FRACTION=" & CStr(errNo)
    On Error GoTo 0
End Sub

Public Sub RunProbe()
    Dim module2D As Variant, module1D As Variant
    Dim instance As ArrayProviderClass, class2D As Variant, class1D As Variant
    module2D = ArrayProvider.Values
    module1D = ArrayProvider.OneDimensional
    Probe2D "MODULE-2D", module2D
    Probe1D "MODULE-1D", module1D
    Set instance = New ArrayProviderClass
    class2D = instance.Values
    class1D = instance.OneDimensional
    Probe2D "CLASS-2D", class2D
    Probe1D "CLASS-1D", class1D
End Sub
```

実際のプローブでは、各呼出しを`On Error Resume Next`で個別に囲み、`Err.Number`、
配列の下限・上限、取得値を行単位で記録する。RunnerにはModule、Class、driverをまとめて渡す。

## 期待値

期待出力: Module/Classの2次元配列は形状`-2:0:3:4`と値を保持し、正常添字だけが値を返す。
範囲外、ランク不一致、非整数添字は全経路でError 9になる。1次元配列`-2:0`も同じ規則に従う。

```text
MODULE-2D-SHAPE=-2:0:3:4
MODULE-2D-VALID=23,4
MODULE-2D-OUTSIDE=9
MODULE-2D-RANK=9
MODULE-2D-FRACTION=9
CLASS-2D-SHAPE=-2:0:3:4
CLASS-2D-VALID=23,4
CLASS-2D-OUTSIDE=9
CLASS-2D-RANK=9
CLASS-2D-FRACTION=9
MODULE-1D-SHAPE=-2:0
MODULE-1D-FRACTION=9
CLASS-1D-SHAPE=-2:0
CLASS-1D-FRACTION=9
```

## 結果

実測出力:

```text
MODULE-2D-SHAPE=-2:0:3:4
MODULE-2D-VALID=23,4
MODULE-2D-OUTSIDE=9
MODULE-2D-RANK=9
MODULE-2D-FRACTION=9
MODULE-1D-SHAPE=-2:0
MODULE-1D-FRACTION=9
CLASS-2D-SHAPE=-2:0:3:4
CLASS-2D-VALID=23,4
CLASS-2D-OUTSIDE=9
CLASS-2D-RANK=9
CLASS-2D-FRACTION=9
CLASS-1D-SHAPE=-2:0
CLASS-1D-FRACTION=9
```

| 経路 | 形状・正常値 | 範囲外 | ランク不一致 | 非整数 |
|---|---|---:|---:|---:|
| Module 2次元 `(-2 To 0, 3 To 4)` | 形状保持、正常値取得 | Error 9 | Error 9 | Error 9 |
| Class 2次元 `(-2 To 0, 3 To 4)` | 形状保持、正常値取得 | Error 9 | Error 9 | Error 9 |
| Module 1次元 `(-2 To 0)` | 下限・上限保持 | — | — | Error 9 |
| Class 1次元 `(-2 To 0)` | 下限・上限保持 | — | — | Error 9 |

Module/Classの配列形状、下限、正常値、範囲外、ランク不一致、非整数添字は一致した。
Variant配列をLong配列へ代入した場合のError 13は別の配列代入契約であり、本評価の添字境界とは分離する。

## 判定

判定状態: verified-no-bug。EV-00922で修正した共通添字検査は、Module/Classの多次元・
下限変更配列にも適用され、追加のバグは確認されなかった。
