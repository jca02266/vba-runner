## 評価内容

Collectionを列挙するFor Eachの制御変数にLongを指定した場合のコンパイル段階を確認する。

## 実施方法

```vba
Sub VerifyForEachControlCoercion()
    Dim value As Long, items As Collection
    Set items = New Collection
    items.Add 1
    items.Add "bad"
    items.Add 3
    For Each value In items
    Next value
End Sub
```

## 期待値

プログラム上の期待出力: 実行前にコンパイルエラーとなり、`For Each`制御変数はVariantまたはObjectでなければならないと報告される。
文章での期待: Collectionの列挙制御変数は値型ではなくVariantまたはObjectでなければならず、列挙中の型変換まで実行されない。

## 結果

プログラム上の実測出力: 修正前Runnerは手続き呼び出し時に実行を開始し、文字列要素で実行時エラー13を返した。修正後Runnerは行4でコンパイルエラーを返す。
文章での結果: Excelのコンパイルエラーと同じ実行前段階へ修正し、CompileError.basおよびFor Each回帰テストで確認した。

## 判定

判定状態: fixed（直接修正・真因対処・回帰検証を完了した）。
