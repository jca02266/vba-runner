## 評価内容

Random Openのレコード長へNullを渡す数値変換経路を確認する。

## 実施方法

```vba
Sub ProbeRandomLenNull()
    On Error Resume Next
    Open "random-len-null.dat" For Random Access Read Write As #1 Len = Null
    Debug.Print "RANDOM_LEN_NULL ERR=" & CStr(Err.Number)
End Sub
```

## 期待値

プログラム上の期待出力: `RANDOM_LEN_NULL ERR=94`。
Nullをレコード長へ渡した場合はNull固有のError 94になる。

## 結果

プログラム上の観測結果: Runnerは `RANDOM_LEN_NULL ERR=1000` となった。
実測出力: Excel `RANDOM_LEN_NULL ERR=94`、Runner `RANDOM_LEN_NULL ERR=1000`。不一致を確認した。
