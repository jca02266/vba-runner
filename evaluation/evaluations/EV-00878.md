## 評価内容

FSOのMoveFile、GetFile(...).Move、MoveFolder、GetFolder(...).Moveで既存destinationを
指定し、MemoryFileSystemとNodeFileSystemのエラー番号とsource/destination状態を比較する。
BUG-00543で確認した低レベルmoveFileSync差異がFSO入口へ到達するかを確認する。

## 実施方法

各バックエンドへ同じVBAソースを実行し、既存ファイル・既存フォルダーへの移動を行う。
各経路のErr.Number、source存在、destination存在を記録し、正常移動の結果も確認する。

## 期待値

期待出力:

```text
Memory MoveFile 58:src=True:dst=True
Memory File.Move 58:src=True:dst=True
Node MoveFile 58:src=True:dst=True
Node File.Move 58:src=True:dst=True
Memory MoveFolder 58:src=True:dst=True
Memory Folder.Move 58:src=True:dst=True
Node MoveFolder 58:src=True:dst=True
Node Folder.Move 58:src=True:dst=True
```

既存destinationはFile/Folderを問わずError 58相当となり、失敗後もsourceとdestinationを
保持することを期待する。

## 結果

実測出力:

```text
Memory MoveFile 58:src=True:dst=True
Memory File.Move 58:src=True:dst=True
Node MoveFile 0:src=False:dst=True
Node File.Move 0:src=False:dst=True
Memory MoveFolder 58:src=True:dst=True
Memory Folder.Move 58:src=True:dst=True
Node MoveFolder 58:src=True:dst=True
Node Folder.Move 58:src=True:dst=True
```

NodeのMoveFileとFile.Moveだけが既存ファイルを置換してsourceを削除した。MoveFolderと
Folder.Moveは両バックエンドで一致した。BUG-00543の影響がFSO File経路へ到達することを
確認し、Directory経路へは波及していない。

## 判定

判定状態: fixed

既存ファイル移動の差異をBUG-00544へ記録し、BUG-00542/00543と同じ修正へ統合する。低レベルAPIだけでなくFSO入口を含む共通
修正と回帰テストが必要であり、Windows上のNode挙動確認は別の未解決境界として残す。
