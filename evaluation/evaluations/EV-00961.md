## 評価内容

異なるモジュールに同名Private Enumと同名メンバーを定義し、各モジュールのメンバー値がロード順によらず保持されるかを確認する。

## 実施方法

次の2モジュールをロードし、それぞれのPrivate Enumメンバーを参照する。

```vba
' ModuleA
Option Explicit
Private Enum Status
    Current = 3
End Enum
Private value As Status
Public Function ProbeA() As String
    value = Current
    ProbeA = CStr(value) & ":" & TypeName(value) & ":" & CStr(VarType(value))
End Function

' ModuleB
Option Explicit
Private Enum Status
    Current = 7
End Enum
Private value As Status
Public Function ProbeB() As String
    value = Current
    ProbeB = CStr(value) & ":" & TypeName(value) & ":" & CStr(VarType(value))
End Function
```

## 期待値

期待出力：Aは`3:Long:3`、Bは`7:Long:3`。Private Enumのメンバーは各モジュールの名前空間に属し、同名でも値を共有しないと期待する。

## 結果

実測出力：Aは`7:Long:3`、Bは`7:Long:3`。後からロードしたModuleBの`Current=7`が共有環境を上書きし、ModuleAの参照値が変化した。

## 判定

判定状態: bug-found

同名Private Enumメンバーのモジュール間汚染を再現した。直接原因と真因仮説を記録し、修正と回帰テストを行う。
