## 評価内容

ReDim前の未割当動的配列でLBound/UBoundのエラー契約を評価する。

## 実施方法

```vba
Dim values() As Long
On Error Resume Next
l = LBound(values)
e1 = Err.Number
Err.Clear
u = UBound(values)
e2 = Err.Number
```

## 期待値

期待出力: LBound/UBoundともError 9。未割当配列には境界が存在しない。

## 結果

実測出力: RunnerはLBound=0 Err=0、UBound=-1 Err=0を返した。

Runnerが未割当状態を境界値として扱っている。Excel実機照合が必要である。

## 判定

判定状態: needs-excel

期待値は未検証仮説であり、Excel実機でLong()/Variant()/String()を照合してから判定する。
