## 評価内容

配列添字へNullを渡す数値変換経路を確認する。

## 実施方法

```vba
Sub ProbeArrayIndexNull()
    Dim values(0 To 1) As Long, value As Long
    values(0) = 7
    On Error Resume Next
    value = values(Null)
    Debug.Print "ARRAY_INDEX_NULL ERR=" & CStr(Err.Number)
End Sub
```

## 期待値

プログラム上の期待出力: `ARRAY_INDEX_NULL ERR=94`。
Nullを配列添字へ渡した場合はNull固有のError 94になる。

## 結果

プログラム上の観測結果: Runnerは `ARRAY_INDEX_NULL ERR=9` となった。
実測出力: Excel `ARRAY_INDEX_NULL ERR=94`、Runner `ARRAY_INDEX_NULL ERR=9`。不一致を確認した。
