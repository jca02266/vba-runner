## 評価内容

同名のFunctionと引数を持つ手続きで、引数を右辺値に使った代入が暗黙Function呼出しとして
誤検出されないかを確認する。

## 実施方法

```vba
Function D(value As Long) As Long
    D = value
End Function
Function Wrapper(d As Long) As Long
    Wrapper = d
End Function
Sub Caller()
    Dim result As Long
    result = Wrapper(1)
End Sub
```

同じ名前影付きが発生する`LibDate.bas`の`AddWorkdays(d As Date, ...)`も実行する。

## 期待値

期待出力: `Caller`と`AddWorkdays`が正常終了し、`LibDate`の既存ケースが全件通過する。

説明上の期待値: VBAの局所引数は同名のモジュールFunctionを隠し、右辺の識別子は変数値として評価される。

## 結果

実測出力: 修正前は`AddWorkdays`の`AddWorkdays = d`で`Compile error: Argument not optional`、
修正後は`LibDate: 全テスト通過`となった。名前影付きの最小回帰も通過した。

## 判定

判定状態: fixed

暗黙Function呼出しの静的検査に局所宣言の影付きを反映した。オブジェクトメンバー、With、
モジュール修飾名の同名解決は別経路として未検証である。
