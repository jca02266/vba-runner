# CallByNameと通常代入のProperty種別境界

独立評価とrootによる最小再現の双方で、`VbSet`がProperty Letを、`VbLet`が
Property Setをエラーなしで実行した。MicrosoftのCallType定義では両者は別の
プロシージャ種別であり、反対アクセサの実行は仕様に反する。

横展開ではCallByNameの2経路だけでなく、通常のLet代入6経路にも同じ曖昧な選択が
見つかった。アクセサ選択を厳密な種別指定へ共通化し、各経路固有の引数評価とByRef
書戻しは維持した。反対アクセサを実行しないことは確定しているが、失敗時の正確な
Excelエラー番号はXL-048で実機照合するため、評価状態は`needs-excel`としている。
