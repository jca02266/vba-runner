## 評価内容

標準モジュールのPrivate UDTを戻り値とするPublic Functionを、呼出し側がVariantで受け取りメンバーを参照できるか確認する。

## 実施方法

```vba
' ModuleA
Private Type T
    X As Long
End Type
Public Function Make() As T
    Dim value As T
    value.X = 7
    Make = value
End Function

' ModuleB
Public Function Caller() As Long
    Dim value As Variant
    value = ModuleA.Make()
    Caller = value.X
End Function
```

ModuleB.Callerを実行する。

## 期待値

プログラム上の期待出力: `Caller=7`。

文章での期待: 標準モジュールのPublic Functionに対するクラス専用のPrivate UDT戻り値禁止規則は適用されず、Variantとして値を消費できる。

## 結果

プログラム上の実測出力: Runnerは`Caller=7`を返した。

文章での結果: Private型名を呼出し側で再解決せず、戻り値のUDT値をVariant経由で参照できた。

## 判定

判定状態: verified-no-bug（仕様適用範囲内の挙動）。
