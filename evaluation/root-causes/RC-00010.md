# 基数値の幅・符号意味論の分散

XL-045の差異は、基数文字列を符号付きの固定幅整数として扱う状態が、数値リテラル、
通常の数値強制、CDec、Valへ分散して失われることで説明できる。ただし、Excelの桁幅規則を
全入口で確定していないため、手順v1では未確定の真因仮説として記録する。
