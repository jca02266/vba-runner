# DateSerial引数幅検査の欠落

DateSerialは各引数をInteger相当として受け取るため、-32768から32767を超える値は
Error 6になる。実装は月日をJavaScript Dateに渡す前の幅検査がなく、範囲外の値を
日付の繰り上げとして受理していた。
