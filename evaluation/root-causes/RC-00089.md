# Boolean・Date character Variant契約

Stringのcharacter引数でBoolean・Dateが文字列化経路へ流れ、Excelの数値コード契約と
一致しない。Currency・Decimalを扱う既存ROOT対処とは別の未適用範囲として検証する。
