# As Object()配列引数のコンテナ境界

通常クラスメソッドの`ByRef values() As Object`へスカラー値を渡しても、現行runnerは
Errorなしで本体を実行する。配列要素の厳密な型互換性は別候補とし、ここでは配列コンテナの
形状検証責務だけを扱う。
