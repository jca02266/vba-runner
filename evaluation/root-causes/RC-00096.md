# クラスモジュールのOption Explicit解析契約

VBEエクスポート形式のクラスモジュールでは、通常モジュールと同じOption Explicitを
ASTへ保存し、後段の意味検査が入口形式を意識しないことが必要である。Option Base等の
別のOption文と、二次入口の前処理はこのRCの対象外として別候補で扱う。
