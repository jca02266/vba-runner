# GoSubエラーハンドラ末尾復帰の真因

GoSub本体で発生したエラーがハンドラで処理された後、GoSub呼出し元の次文へ誤って戻る
ため、エラー処理結果が上書きされていた。ハンドラ末尾到達を手続き終了として扱う。
