# `^` のLongLongサフィックスと指数演算子の文脈分類

EV-00914では、空白なしの符号付き指数だけが空白ありの指数演算と異なる結果になった。
Lexerが指数演算子を後段へ渡す前にサフィックスとして消費している仮説を、独立レビューで
反証可能な形に整理する。
