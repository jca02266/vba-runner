# Formatトークンスキャナの角括弧境界不統一

`stripVbaBracketDirectives` は角括弧内をスキップする一方、
`hasUnescapedFormatChars` は角括弧内の `<` と `>` を検査していた。
そのため条件ディレクティブを含む数値書式がString分岐で文字列プレースホルダー
書式と誤分類され、`Format("Ab9", "[<=1000]0")` が `0` になった。

対処前の影響範囲は、角括弧内に `@&!<>` が現れるFormatのString入力である。
修正では角括弧ディレクティブを不透明領域として共通に扱い、通常の文字列制御文字
だけをドメイン判定へ渡す。角括弧の条件解釈自体は本修正の対象外である。
