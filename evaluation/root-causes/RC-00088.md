# CDate数値範囲外のエラー分類

CDateの数値シリアル範囲外で、RunnerはOverflow（Error 6）を返すがExcelはType mismatch
（Error 13）を返す。CDate固有の境界契約か、数値変換共通のエラー分類かをレビューする。
