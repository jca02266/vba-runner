# String ANSIコードページ・境界契約

XL-226では、Boolean/Dateの分類とは独立したANSIコードページと256境界の差異が
確認された。公開仕様の`character Mod 256`とExcel実機の256結果が一致しないため、
型付き入力を追加照合する。
