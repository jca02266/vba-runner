# File.ParentFolderのFolderオブジェクト契約

`File.ParentFolder`はFolderオブジェクトを返すため、GetFolderと同じ操作・列挙契約を
提供する必要がある。薄いPath/Nameオブジェクトを返す経路を共通生成へ集約する。
