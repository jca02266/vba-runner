# クラスメソッドのAs Object引数境界

通常クラスメソッドの`As Object`引数にprimitiveやNullが渡され、エラーなしで本体が実行される。
初期仮説では、宣言型を記録するだけの引数バインダーへObject参照互換predicateを接続する責務が
欠けているとする。配列パラメータとnamed class型の検証範囲は独立レビューで切り分ける。
