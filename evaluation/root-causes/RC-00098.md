# Module Property Getの配列境界契約

Module修飾Property Getの戻り値を添字化する経路が、Class経路や通常配列アクセスで
共有している境界検査から外れていた。DictionaryやCollectionなど異なる既定メンバー
契約は対象外とし、追加の配列形状境界は別候補へ分離する。
