# 数値文字列のFormat書式ドメイン変換

`Format("123", "0000")` が数値書式を適用せず入力を返す事象について、String値を
数値書式へ渡す変換責務の欠落を仮説として登録する。日付・混在書式・ロケール境界は
この仮説の未解決範囲として別途扱う。
