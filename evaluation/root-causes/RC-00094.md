# LSPクラス属性診断の共通解析契約

VBEエクスポート形式のクラス属性をLSP診断で扱うとき、ヘッダー除去、
クラス解析モード、修飾属性名のParser処理を同じ契約で適用する。
この直接修正の横展開で未適用の入口は、後続評価候補へ分離する。
