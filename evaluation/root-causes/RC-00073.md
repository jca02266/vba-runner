# Function過剰引数の実行時契約

Class・Module修飾Functionの過剰引数が、共通precheckの静的Error 450へ誤分類されていた。
Functionだけはruntime binderのError 13へ渡し、Sub・Propertyの静的引数検査とは分離する。
