# LSP二次入口の.cls前処理契約（仮説）

直接診断経路は修正されたが、テスト実行・デバッグ・折りたたみなどの入口が同じ`.cls`正規化を共有していない可能性を、独立評価で再現した。影響範囲と共通APIは修正前に確定する。
