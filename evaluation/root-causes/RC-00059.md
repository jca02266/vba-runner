# 不正数値列のラベルフォールバック仮説

Lexerの分割自体ではなく、式全体を消費できなかった入力を通常文へ
フォールバックした後、Numberトークンを無条件に行ラベルとして扱う
責務の欠落が、bare evalの空実行を生むという仮説である。
