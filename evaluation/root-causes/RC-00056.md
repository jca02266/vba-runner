# 数値文字列の複数セクションFormat誤分類

数値文字列を複数セクション書式へ渡したとき、未選択セクションの文字が日付トークンと
して解釈され、書式全体が破損する。値に対応するセクションを先に確定する責務が欠けて
いるという仮説を登録する。
