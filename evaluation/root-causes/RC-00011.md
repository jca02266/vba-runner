# MIRR金利境界の契約分散

MIRRは金利境界でExcelの値・エラー分類と異なる。直接にはMIRRの境界計算が最初に差異を
生むが、金利領域を共通化する設計と、計算結果の誤差・エラー分類を分ける契約が不足している。
評価記録と現行ソースのError番号が異なるため、手順v1では未確定とする。
