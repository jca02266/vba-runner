# Likeパターン文法・空文字パターンの欠落

Likeの責務が照合だけに縮退し、無効な実行時パターンをError 93として分類できず、
仕様上の空文字パターン`[]`も表現できていない。RC-00032のlocale範囲問題とは関連するが、
構文妥当性・空文字意味・エラー契約を独立した真因として扱う。
