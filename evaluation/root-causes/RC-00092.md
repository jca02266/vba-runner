# VBA Dateシリアル変換とホストタイムゾーン結合

EV-00912では、日付リテラルの暦日は正しく解釈される一方、歴史的日付でホストの
ローカル時刻補正がVBA Dateシリアルの小数部へ混入した。共通変換の影響範囲と
暦日ベースの受入条件を確定するまで、修正は開始しない。
