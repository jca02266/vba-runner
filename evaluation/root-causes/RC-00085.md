# String character引数の数値Variant契約

`String`のcharacter引数は、JavaScriptのnumberだけでなくVBAの数値Variantを
文字コードとして扱う必要がある。Currency・Decimalを個別分岐へ追加する直接修正は
確認済みだが、数値Variant判定の共通述語化は別の真因対処として残る。
