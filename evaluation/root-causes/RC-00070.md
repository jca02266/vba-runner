# 動的COMメンバー引数契約の未共有

TextStream.Readで、必須引数メタデータがMemberExpression経路に適用されず関数値が漏出した。
同じ動的メンバー評価経路のOptional・With・別COM境界を追加評価してから真因を確定する。
