# CDec・CCur短桁基数符号拡張の真因

CDecとCCurが共通の基数パーサーから16ビット符号拡張を受け取っていたため、
変換先型では正の短桁パターンを負値として解釈していた。これはRC-00010全体の
入口共通化問題から切り出した、限定scopeのconfirmedな子原因である。
