# FileSystemバックエンドのディレクトリコピー失敗状態契約

`copyDirectorySync`の`overwrite=false`衝突は、宛先の変更なしに失敗する契約として
MemoryFileSystemとNodeFileSystemで統一する。今回の修正は衝突ファイルの事前検査までを
対象とし、OS権限や外部I/O障害の完全なロールバックは対象外とする。
