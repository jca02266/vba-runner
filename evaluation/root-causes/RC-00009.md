# 逐次Lock範囲の検証順序

逐次モードはレコード範囲を物理的には持たないため、既存実装は指定範囲を全体ロックへ
正規化していた。しかし正規化が入力検証を短絡し、ExcelがError 70を返す境界を受理していた。
独立レビューで同じ原因を確認し、0 To 1の実機結果を反映した最小修正を行った。
