# SYDの領域エラーとOverflow分類

SYDの中間値が非有限になったとき、共通finiteResultがError 6へ分類する一方、Excelはこの
入力をError 5とする。これはSYDの領域契約と一般的な数値Overflowを同じ出口へ流している
ことを示すが、適用範囲を確定する追加実機照合が必要である。
