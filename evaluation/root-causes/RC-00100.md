# FOREIGN-NAME必須終端契約（仮説）

FOREIGN-NAMEの閉じ角括弧欠落はLexer段階で受理される。必須終端を持つトークンの返却条件を明示する設計契約が不足している可能性を、独立横展開レビューで確認した。
