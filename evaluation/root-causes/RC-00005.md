# CallByName VbSetの添字とObject値の境界

CallByNameのクラス専用経路に、通常Setおよびbuiltins側CallByNameと異なるObject値検証がある。
最初の仮説では、VbSetの最終引数だけをObject参照互換predicateで検証し、先行する添字引数は
配列を含むProperty引数として保持すべきだとする。Excel仕様上の配列添字境界と、As Object
通常引数の横展開範囲は独立レビューで確認する。
