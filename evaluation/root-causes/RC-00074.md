# FSOパスオブジェクトのファイルシステム能力契約

EV-00841では、`GetFolder`が返すFolderオブジェクトの`Copy`がエラーなしに無操作となった。
直接原因は未定義の`cpSync?.`呼び出しだが、より深い原因として、FSOのパスオブジェクト操作と
トップレベル操作が共通のコピー・移動能力契約を持たないことを仮説とする。
