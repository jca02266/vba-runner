# Object引数のNull・省略値・host参照境界

Module手続きのObject引数バインドがClass手続きと同じObject参照契約を適用せず、Nullと省略値を
そのままcalleeへ渡していた。host/COMから返った参照をVariant/Object引数へ渡す経路も、値型の
暗黙変換と同じ境界で扱われている。これは直接のNull・Missing処理だけでなく、Object参照契約を
入口ごとに重複実装している設計上の仮説であり、独立レビュー待ちである。
