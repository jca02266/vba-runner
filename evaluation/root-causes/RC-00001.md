# VBA Object参照と値型の分類

配列だけを除外する局所ガードではなく、VBA実行時値の意味カテゴリを一箇所で定義し、
Object参照互換性とbound Objectを用途別に判定する必要がある、という真因仮説を追跡する。

外部から注入されるraw JavaScript objectは公開API互換のためObject参照へ分類する。一方、
engineが生成するUDTには明示markerを付ける。member accessはObject型判定ではなくhost dispatch
能力の判定であるため、この分類述語へ機械的に置換しない。
