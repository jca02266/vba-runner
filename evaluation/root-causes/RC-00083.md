# copyDirectorySync異種別衝突契約の仮説

NodeFileSystemのcopyDirectorySyncは、source側ディレクトリとdestination側ファイルの
衝突を事前検査せず、Node固有の`ERR_FS_CP_DIR_TO_NON_DIR`を返す。MemoryFileSystemの
`EEXIST`相当と公開エラー契約が異なるため、異種別エントリを含むコピー衝突の共通契約が
欠けていることを真因候補とする。sourceファイルとdestinationディレクトリ、overwrite
有効時、FSO入口の変換は独立確認が必要である。
