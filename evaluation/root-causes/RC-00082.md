# FileSystem移動先衝突契約の欠如

MemoryFileSystemは移動先の存在を拒否する一方、NodeFileSystemは`renameSync`のホスト
意味論へ直接委譲して既存先を置換していた。File/Directory双方とFSO File入口で同じ
差異が確認され、移動先衝突ポリシーの共通契約不足を真因として確定する。
