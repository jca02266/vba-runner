# For Each配列制御変数の静的検査

最初の実装調査では、For Each precheckが`Next`の識別子一致とcollection式の走査だけを
行い、配列時の制御変数型を見ていなかった。MS-VBAL §5.4.2.4の静的意味論に照らすと、
この欠落がLong制御変数を実行へ進めた設計上の真因である。
