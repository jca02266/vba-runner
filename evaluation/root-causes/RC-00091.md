# Chr character幅契約

XL-228では、ExcelのChr$が255を超える入力を受理した一方、RunnerはError 5を返した。
String系の下位8ビット変換とは別の入口で範囲検査が行われている可能性があるため、
独立レビューで仕様上の範囲と互換性方針を確認する。
