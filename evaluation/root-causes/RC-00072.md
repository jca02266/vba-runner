# 10進数リテラルの解析段階有限値域契約

`1E+309`のような有限Double値域外の10進指数リテラルが、解析段階で拒否されず
実行時の型代入まで通過していた。直接修正は`parseNumericLiteral`の有限値検査で行い、
文字列変換や型付き代入の実行時Overflowとは責務を分離する。
