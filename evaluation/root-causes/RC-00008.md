# Object配列要素の型分類

`As Object()`配列要素へbound class objectをSet代入すると、現行runnerは名前文字列の完全一致を
要求してError 13になる。汎用ObjectとNamedClassの要素契約を分け、4つの代入経路で共通述語を
使う必要がある。
