# 基数値の幅超過が0へ折り返される

`CInt("&H10000")`や`CLng("&H100000000")`など、変換先型の幅を超える基数値が
Overflowではなく0へ折り返されていた。幅内のビットパターンだけを符号拡張し、幅超過値は
各変換関数の範囲検査へ渡すよう修正した。
