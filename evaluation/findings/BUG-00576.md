# FilterがOption Base 1の隠し配列要素を返す

## 事象

`Array("a", "b")` を `Option Base 1` の環境で `Filter` に渡すと、修正前のRunnerは空の隠し格納要素を結果へ混入させた。

## 横展開

Filterを確認し、同じ`vbaBase`処理を行うJoinでは問題が再現しないことを確認した。実Excel照合は未完了である。

## 真因分析

設計上の真因は、VBA配列の論理下限とJavaScript格納配列の境界を組み込み関数ごとに統一して扱っていなかったことである。直接原因はFilterが`vbaBase`を無視して全格納領域を処理していたことである。

## 回帰テスト

`tests/spec/split-join.test.ts` のOption Base 1 + Filterテストが修正後に通過する。
