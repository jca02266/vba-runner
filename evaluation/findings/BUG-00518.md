# Property Let/Setの必須インデックス省略が許可される

## 事象

必須`index`と右辺値を取るProperty Let/Setへ右辺値だけを代入すると、Runnerは
Propertyを実行していた。

## 横展開

Property LetとProperty Setの両方で同じ代入バインダー経路を確認した。Property Getや
修飾メンバーは別候補へ分離した。

## 真因分析

直接原因は、右辺値を暗黙の最終引数へ追加する処理が、先行する必須パラメーターの検査より
先に呼出しを整列していたことである。これはRC-00071のmember arity契約未共有仮説を補強するが、
動的メンバー全体の真因確定は未完了である。

## 回帰テスト

`tests/spec/call-arity-matrix.test.ts`でProperty Let/Setの省略インデックスを検証し、通過した。
