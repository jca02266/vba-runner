# Valの64ビットHex基数境界差異

現行ソースハッシュと一致するExcel結果で、`Val`の64ビットHex入力2件がrunnerと一致しない。

- `Val("&H7FFFFFFFFFFFFFFF")`: Excelは`-1`、runnerは`9.22337203685478E+18`
- `Val("&H8000000000000000")`: Excelは`0`、runnerは`-9.22337203685478E+18`

32ビット以下のHex/Octalと64ビットOctalは一致している。Valの64ビットHexを
32ビット下位パターンとして扱う契約が直接原因候補だが、共通の基数幅ポリシーを
どこへ置くかは真因分析中である。
