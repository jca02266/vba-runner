`Shell` の `WindowStyle` と `Environ` の必須引数で Null を共通検証しておらず、
それぞれError 13または空文字列になっていた。`rejectNullArgument` を共有し、
Error 94へ統一した。`Shell` の `PathName`、`Nz`、Empty境界は既存仕様どおりだった。
