# 指数トークン後の末尾カンマ誤フォールバック

`Format(1000000, "0.00E+00,,")` がExcelの `1.00E+06` ではなく
runnerの `1.0000` になる。既存BUG-00496のXL-181差分を、通常数値・指数境界の
独立評価で再現した記録である。
