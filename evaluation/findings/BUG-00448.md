# Property Let/Setのvalue-paramがByRef書戻しされる

MS-VBALではProperty Let/Setのvalue-paramは宣言にByRefがあっても実行時にはByValである。
vba-runnerではProperty LetのLong引数とProperty SetのObject引数の変更が呼出し元へ反映された。
