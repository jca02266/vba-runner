# GoSub内エラーハンドラ後の誤復帰

GoSub本体でErr.Raiseした後、呼出し元のOn Error GoToハンドラが処理しても、
GoSub直後の文へ戻って結果を上書きしていた。GoSub実行器がハンドラ末尾到達を
手続き終了として扱わなかったことが原因であり、ハンドラ末尾をExit相当として
伝播するよう修正した。`gosub-error-resumption-matrix.test.ts`で正常Return、
呼出し元捕捉、Resume Nextを回帰確認済みである。
