# $付き組み込み関数がVariant版へ解決される

`Space$`、`LTrim$`、`RTrim$`、`Trim$`の呼出しで`$`接尾辞がASTから失われ、Variant版のNull伝播が適用される。
String戻り値の関数ではNullを返せず、Error 94になる契約を共通呼出し経路で適用する。
