# FSO File操作の共通能力不足

File Copy/Moveを明示的FileSystem能力へ集約し、Memory/Node双方の回帰を追加した。

## 事象

File操作がoptional backend呼び出しとcopy後unlinkに分散していた。

## 横展開

GetFileとトップレベルCopyFile/MoveFileを比較し、同じFileSystem能力契約を使っていないことを確認した。

## 真因分析

直接原因はFileSystemのFile操作能力がoptionalだったこと、設計原因はFSO入口間で能力契約を共有していなかったことである。

## 回帰テスト

`tests/spec/filesystem-extra.test.ts`でMemory/NodeのFile Copy/MoveとOverwrite境界を検証する。
