# FormatのNull専用セクションが無視される

4セクション数値書式のNull用セクションを指定しても、RunnerはNull入力を無条件に空文字列へ変換する。
VBA仕様のNullセクション選択と、既存の数値・日付・文字列書式を分離して修正する。
