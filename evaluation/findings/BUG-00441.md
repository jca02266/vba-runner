# ModuleのObject引数でNullと省略値が参照契約を失う

Module手続きの`ByVal value As Object`へ`Null`を渡すとNullがそのままcalleeへ入り、
`Optional value As Object`を省略すると`Nothing`ではなくError相当のMissing値が観測される。
Class手続きには既存のObject検証があるが、Module手続きのバインド入口では同じ検証と既定値
正規化が適用されていない。
