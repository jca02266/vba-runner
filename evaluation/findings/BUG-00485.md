# String値への数値・日付Format誤適用

`Format("Ab9", "0.00")`などで、Excelは入力文字列`Ab9`を返すが、runnerは書式文字列
`0.00`を返す。数値・日付書式と文字列プレースホルダー書式の適用ドメインを分離する
分類が不足している疑いがあり、独立RCAレビューと追加境界確認を行う。
