# 固定typed配列がopaque source shapeへ再束縛される

`Long(0 To 1, 0 To 1)` の固定配列へ2x3のopaque host配列を代入すると、Runnerは
エラーを出さず、destinationを2x3へ置換していた。仕様上、whole-array assignmentの
左辺はresizableでなければならないため、固定配列は拒否されるべきである。

固定typed destinationを`precheckProc`で検出し、host/member getterを右辺とする全体代入を
コンパイルエラーに変更した。dynamic配列への代入は許可し、回帰テストで両経路を区別する。
