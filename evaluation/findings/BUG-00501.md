# Formatエスケープ済みQの誤日付分岐

`Format(1234.5, "0.0\"Q\"")` は仕様上 `1234.5"Q"` となるべきだが、runnerは
`0.0"2"`を返す。`containsDateFormatTokens`がエスケープ済みリテラル文脈を
日付トークンとして検出し、数値経路を日付経路へ分岐させる。
