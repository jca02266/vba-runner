# Property Letの配列要素ByRef書き戻し差異（取り下げ）

## 事象

`Property Let Value(ByRef incoming As Long)`へ配列要素を渡し、Property Let内で
`incoming = incoming + 1`を実行した。

初期評価では期待出力を`0:7:8`と誤って確定し、vba-runnerの`0:7:7`を差異と判定した。
実機でも`0:7:7`となったため、期待値未確定の段階で作成したBUGとして取り下げる。

## 横展開

退役理由が期待値の誤りであり、製品バグではないと確認されたため、横展開は対象外とする。
通常のByRef引数、Property Letのスカラー引数、名前付き引数、Optional引数、Interface経路の
調査は、この退役Findingの作業としては実施しない。

## 真因分析

退役理由が期待値の誤りであり、製品バグではないと確認されたため、真因分析は対象外とする。
当初記録した直接原因・設計上の真因は、誤った期待値に基づく仮説として採用しない。

## 回帰テスト

退役理由が期待値の誤りであり、製品バグではないため、回帰テストは対象外とする。
