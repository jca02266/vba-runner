# LongLong基数リテラルの符号拡張欠落

LongLong型接尾辞付きの16進・8進リテラルがJavaScript `Number`を経由し、
2^53超の桁を失ううえ、64ビット最上位ビットを含む値を符号付きLongLongへ
変換できずError 6になっていた。リテラルの正確な基数値を保持し、64ビット
符号付き値へ変換する経路を追加した。
