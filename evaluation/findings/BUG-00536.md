# SYD正数入力の非有限結果分類差異

## 事象

`SYD(1E+308, 0, 2, 1)`について、数学的な最終結果は有限だが、Excelは`XL-213 POSITIVE-NONFINITE ERR=0`、vba-runnerは中間乗算を先に行うため`ERR=6`となる。負SalvageのError 5境界は一致しているため、入力領域検証とは別の数値計算順序の差異である。

## 横展開

SYDの負Salvage境界は一致した。他の金融関数については同じ正数入力非有限境界をまだ照合していないため、横展開を継続する。

## 真因分析

独立レビューでは、`(c - s) * (l - p + 1) * 2`の中間乗算がInfinityとなり、共通`finiteResult`がError 6に分類することを直接原因とした。SYD固有の入力領域Error 5とは別に、数学的に有限な最終結果を中間Overflowさせない計算順序の責務が未定義である。ほかの金融関数へはまだ一般化しない。

## 回帰テスト

`tests/spec/financial.test.ts`に、SYDの数学的に有限な巨大入力、負Salvage Error 5、通常計算を含む回帰テストを追加し、通過した。ほかの金融関数への横展開はRCA-FOLLOWUP-042で継続する。
