# LongLong ByVal引数の型登録漏れ

`Variant`のDecimal値を`ByVal value As LongLong`へ渡しても、パラメーターの型情報が
登録されず、幅検査が行われない。LongLongの最小値未満がError 6にならず、引数境界を
そのまま通過する。
