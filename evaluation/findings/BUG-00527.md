# 修飾Functionの過剰引数エラー段階

## 事象

Class・Module修飾Functionへ過剰引数を渡すと、修正前Runnerは実行前にError 450を返した。
VBAではFunctionの過剰引数は実行時Error 13（Type mismatch）となる経路である。

## 横展開

通常のFunction、Class修飾、Module修飾、With、Interface、Class CallByNameを比較した。
修正対象はClass・Module修飾のprecheckだけで、With・Interfaceは共通runtime binderを通り、
外部CallByNameは既存のError 450契約を維持する。

## 真因分析

最初の誤状態は、Functionの過剰引数をSubと同じ静的`checkArity`で処理していたこと。
直接原因は`precheck.function_excess_static_arity`、設計原因はFunction過剰引数の実行時
型不一致契約が修飾メンバーのprecheckで上書きされていたことである。RC-00073で独立レビューを継続する。

## 回帰テスト

`tests/spec/call-arity-matrix.test.ts`にClass・Module修飾Functionの不足・有効・過剰引数を
含む行列を実装した。修正後は過剰引数がruntime Error 13、不足引数がprecheck Error 449、
Sub・Propertyの過剰引数がprecheck Error 450となる。
