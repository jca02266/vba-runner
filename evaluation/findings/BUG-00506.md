# Format名前付き書式の値型分類差異

XL-184で、Dateに対するGeneral Number/Currency/Fixed/Scientific、Currency・Decimalに
対するGeneral Date、非数値Stringに対するGeneral DateがrunnerとExcelで一致しない。
名前付き書式の値型分類をユーザー定義書式と共通化する必要性を調査する。
