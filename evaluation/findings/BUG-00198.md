causeKey: select-case-nonnumeric-string-error
status: fixed
evaluation: EV-00197
---

Select Case swallowed Type mismatch when a numeric clause was compared with a
nonnumeric or empty Variant String. `Case Is <>` then inverted the failed
equality and matched incorrectly. Preserve the conversion error instead of
falling back to JavaScript comparison.
