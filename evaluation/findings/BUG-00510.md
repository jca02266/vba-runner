# exactScientificFormatのエスケープsuffix差異

## 事象

`Format(CCur("1000000"), "0.00E+00\\,")` と `"0.00E+00\\,\\,"` は、Excelでは
それぞれ `1.00E+06,` と `1.00E+06,,` になる。Runnerはバックスラッシュも
suffixへ残し、`1.00E+06\\,` と `1.00E+06\\,\\,` を返す。

## 横展開

`exactScientificFormat`を共有するCurrency・Decimal・LongLongへ横展開し、
`\\,`、`\\Q`、引用符suffix、ゼロ値を確認対象とする。通常のNumber/Doubleの
`formatNumberSection`経路は今回の直接差異から除外する。

## 真因分析

指数後suffixをraw文字列として連結し、通常数値書式のリテラル・スケーリング
トークン化を共有していない。独立レビュー2件で型別経路の分岐とsuffix処理の
不足を確認し、RC-00069として登録した。直接修正と共通化修正は未実施である。

## 回帰テスト

`tests/spec/format.test.ts`にCurrency・Decimalのエスケープsuffix回帰を追加し、
既存の未エスケープ末尾カンマ回帰と併せて全446 TypeScriptテストおよび全111 VBA
テストが通過した。
