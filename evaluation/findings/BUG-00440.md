# Option Compare TextのLike範囲がアクセント文字を失う

`Option Compare Text`で`"À" Like "[A-E]"`を実行すると、修正前RunnerはFalseを返した。
VBAのLike仕様ではÀ/àはこの範囲に含まれる。正規表現の`/i`依存をlocale-awareな範囲
matcherへ置き換え、BinaryとTextの比較を分離した。
