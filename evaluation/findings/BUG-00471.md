# Property ParamArrayの名前付き引数が受理される

`Property Let Item(ParamArray indexes(), value As Variant)` に
`Item(1, value:=9)` を渡すと、vba-runnerは成功する。VBA仕様ではParamArrayを
含む手続きへの名前付き引数は禁止されるため、Error 448相当で拒否すべきである。

原因候補はPropertyのvalue-tail整列がParamArrayの名前付き引数禁止を迂回すること。
直接修正と回帰テストは未実施であり、通常のParamArray、Property Set、Interface経路を
横展開確認する。
