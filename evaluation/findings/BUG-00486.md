# 数値文字列のFormat数値書式未適用

`Format("123", "0000")` がrunnerでは `123`、`Format(123, "0000")` では `0123` になる。
同様に小数・百分率でもString入力だけ数値書式が適用されない。Microsoft VBA Format仕様の
非ローカライズ数値文字列に対するユーザー定義数値書式の説明に反するため、数値文字列を
数値書式経路へ渡す変換契約の欠落として記録する。
