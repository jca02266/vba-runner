# Formatが非選択セクションのリテラルで日付経路へ入る

数値入力のFormat書式全体を単純な文字検索で日付判定するため、Null第4セクションの引用文字列などに含まれる`m`や`n`が日付トークンと誤認される。
正負ゼロの選択セクションだけを日付判定し、引用符・エスケープ内の文字を判定対象から除外する。
