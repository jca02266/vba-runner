# 不正数値リテラルの空実行

`VBARunner.eval("1.2.3")` と `VBARunner.eval("1..2")` が構文エラーに
ならず `undefined` を返す。Lexerが数値を分割した後、通常文Parserが
数値トークンを行ラベルとして消費し、空の文列として実行している。
