# 日付変換がError値と配列を受理する

`DatePart("yyyy", CVErr(2042))`と`DatePart("yyyy", Array(1, 2))`が、VBAで期待される
Error 13ではなく、それぞれErrorコードと配列表現を文字列化して日付として解釈していた。
共通`parseVbaDate`で日付として許可されない配列、Error値、Booleanを明示的に拒否した。
