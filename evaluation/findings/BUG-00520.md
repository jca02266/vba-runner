# ParamArrayが省略可能なPropertyで引数省略エラーになる

## 事象

ParamArrayだけを持つProperty Getの裸参照が、ParamArrayを必須引数として数えられ、実行時エラー449に
なっていた。Property Let/SetとCallByNameの同じ共通アリティ検査にも影響した。

## 横展開

Class Property Get/Let/SetとCallByNameの行列で再現し、修正後に通過した。Optional、Interface、動的COMは
別のバインダー経路のため未確定である。

## 真因分析

最初の誤状態は`checkArgCountGeneric`の`minParams`計算がParamArrayを固定必須引数と同じように数えたこと。
直接原因は`paramarray-counted-as-required`であり、最小引数計算の共通契約が可変引数を除外していなかった。
`variadic-parameter-minimum-not-shared`は、Optional・Interface・動的COMへの共通適用を確認するまで仮説とする。

## 回帰テスト

`tests/spec/property-paramarray.test.ts`および`tests/spec/property-paramarray-callbyname-matrix.test.ts`で、
裸参照、Property Let/Set、CallByNameのParamArray行列が通過することを確認した。
