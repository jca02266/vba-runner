# 八進基数変換のLongLong・Val符号不一致

Excel実機では、`CLngLng("&O777777777777777777777")`が`LongLong`の最大値として
受理されたが、runnerはError 6になった。また、`Val("&O1777777777777777777777")`は
Excelでは`Double -1`になったが、runnerは`1.84467440737096E+19`という正の近似値を返した。

同じ追加マトリクスの`CInt`短い桁・16ビット境界と`CCur`の64ビット入力は一致したため、
全基数入口の一律修正ではなく、八進値の幅と変換先型ごとの符号拡張を共通契約へ接続する必要がある。
直接修正と回帰テストは未実施である。
