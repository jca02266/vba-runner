# CDec・CCurの32ビット基数値符号拡張不一致

Excel実機では、`CDec("&H80000000")`が`-2147483648`、
`CDec("&HFFFFFFFF")`が`-1`、`CCur("&H80000000")`が`-2147483648`となった。
runnerはこれらを符号なしの正値として返した。一方、同じマトリクスのVal境界は
一致している。

直接修正と回帰テストは未実施であり、CDec・CCurを変換先型別の符号拡張契約へ接続する
必要がある。
