## 事象

`Dim values(0 To 1) As Long`に対して`Dim value As Long`を制御変数にした
For Eachが、Excel仕様では実行前に拒否されるべきところ、修正前Runnerでは
配列を列挙して`3`を返していた。

## 横展開

For Eachの配列・Collection・Dictionary経路を確認した。今回の静的要件は配列に
限定され、Collection経路の型変換エラー境界はEV-00973で別に評価する。

## 真因分析

配列For Eachの制御変数をVariantに限定する静的意味論がprecheckへ実装されて
いなかった。`evaluateForEachStatement`の実行時代入を修正するだけでは、仕様違反を
実行前に拒否する契約を回復できない。

## 回帰テスト

`tests/spec/for-each.test.ts`で、宣言済みLong配列をLong制御変数で列挙する最小ソースが
`For Each control variable on arrays must be Variant`のコンパイルエラーになることを確認する。
