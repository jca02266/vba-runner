# Format条件付きセクションの解釈不一致

Excel実機では`Format(50, "[<100]0;[>=100]0")`が`50`、
`Format(150, "[<100]0;[>=100]0")`が`150`になった。
runnerはそれぞれ`[<1050`、`[<1150`を返した。
条件セクションの条件トークン解釈がExcelと一致していない。
