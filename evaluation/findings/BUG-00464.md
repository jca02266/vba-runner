# Formatユーザー定義書式の記号解釈不一致

Excel実機では`Format(50, "[<100]0;[>=100]0")`が`50`、
`Format(150, "[<100]0;[>=100]0")`が`150`になった。
runnerはそれぞれ`[<1050`、`[<1150`を返した。
これはExcelセル書式の条件式をVBA `Format` に実装すべきという意味ではない。
公式VBA仕様では数値書式のセクションは正負・ゼロ・Nullに分かれ、
`[<100]` はExcelセル書式の条件構文として定義されていない。
実機との出力差は、VBA `Format` がこの未定義記号列をどのように字句化・表示するかの
差として再評価する。
