# CDec・CCur短い基数ビットパターンの符号差異

RadixMatrixのXL-175で、`CDec("&H8000")`、`CDec("&HFFFF")`、
`CDec("&O177777")`および同じCCur入力がExcelでは正の値になる一方、
runnerでは負の値になった。短い基数表記を変換先のDecimal/Currency幅ではなく
16ビット符号付きパターンとして解釈している差異である。

直接修正は未実施。CInt/CLngLng/Valを含む同種の幅・符号契約をRC-00010の
仮説として横展開し、共通ポリシー確定後に修正する。
