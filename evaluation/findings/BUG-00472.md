# Module ParamArrayの名前付き引数が受理される

`Sub Plain(ParamArray values())` に `Plain(values:=1)` を渡すと、vba-runnerは
成功した。VBA仕様ではParamArrayを含む手続きへの名前付き引数は禁止されるため、
Error 448相当で拒否するようModule束縛経路を修正した。
