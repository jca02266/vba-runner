# Format名前付きBooleanの非数値String差異

XL-186の`Format("abc", "On/Off")`でExcelは入力Stringを返すが、runnerはNullを返す。
Empty・Null・数値文字列の結果は一致しており、非数値Stringの名前付きBoolean書式に
限定した値型伝播差異として調査する。
