# Variant経由のtyped配列全体代入がprecheckを迂回する

Excelでは、`source As Variant` に配列を保持させた後、`target() As Long` へ
`target = source` と代入すると、実行前に「配列には割り当てられません」となる。
Runnerはtyped配列どうしの識別子代入だけをprecheckしており、Variant識別子を右辺に
した同じ禁止形を実行時まで遅延させていた。

typed配列左辺と識別子右辺のwhole-array assignmentを`precheckProc`で検査するよう拡張し、
Variant経由でもコンパイルエラーを返す回帰テストを追加した。COM/Property Member
getter経路は既存の実行時binder契約を維持し、別境界として追跡する。
