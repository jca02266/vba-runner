# FSO path errors were inconsistent

FSO folder and file path operations did not consistently translate missing or
duplicate paths to VBA errors. Folder creation could recurse silently, folder
deletion ignored missing paths, and GetFile/GetFolder leaked backend behavior.

The evaluator now checks path existence and maps these boundaries to Error 58,
Error 53, or Error 76. CreateTextFile also maps a missing parent path to Error
76. Regression coverage is in `tests/spec/fso-boundaries.test.ts`.
