# Select Case Text範囲の非ASCII比較不一致

`Option Compare Text` の `Case "A" To "E"` が `"À"` を範囲内と判定せず、`Case Else`へ進んでいた。大文字小文字変換とJavaScriptのコード単位順序だけでは、VBAのLocale依存のアクセント付き文字範囲を表現できない。
