# Decimal Variant の LongLong 境界丸め

`Variant` に `CDec("-9223372036854775809")` を保持し、`LongLong` へ暗黙代入すると、
Error 6 ではなく `-9223372036854775808` へ丸められる。LongLongの許容範囲外を
正確なDecimal値のまま検査できていない可能性がある。
