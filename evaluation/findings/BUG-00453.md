# LongLongと浮動小数点の混在加算が昇格しない

`LongLong` と `Double` または `Single` の加算が浮動小数点型へ昇格せず、
結果の `TypeName` が `LongLong` のままになる。値の精度と演算型契約を壊すため、
加算・減算などの共通数値昇格経路を確認する。
