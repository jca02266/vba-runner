# 文字列Formatのリテラル欠落

文字列に対する`Format`で、通常文字、引用符で囲んだリテラル、バックスラッシュで
エスケープした文字が出力されず、プレースホルダーで埋めた文字だけが返っていた。
文字列書式のトークン列を保持して描画する実装へ修正し、角括弧・引用符・エスケープと
プレースホルダーの回帰テストを追加した。
