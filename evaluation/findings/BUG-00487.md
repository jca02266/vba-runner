# 数値文字列の複数セクションFormat破損

`Format("12", "0.00;NEG;ZERO;NULL")` が `0.00;013H;Z13RO;0ULL` となる。数値入力では
`12.00`になるため、String値の全書式を日付として判定し、未選択セクションの文字を
日付トークンに置換している。値に対応するセクションを先に選択する必要がある。
