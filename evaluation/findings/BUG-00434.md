# typed配列全体代入が実行時まで遅延する

Excelの `target = source` は固定型配列への全体代入としてコンパイル時に拒否される。
Runnerは配列宣言型を保持していたが、`precheckProc` がこの代入規則を検査しておらず、
実行時binderのError 13まで遅延していた。

`precheckProc` に配列識別子の宣言型収集とtyped whole-array assignmentの検査を追加し、
Excelと同じ実行前診断へ変更した。`tests/spec/typed-array-assignment.test.ts`で、
コンパイルエラー、Variant()代入、関数戻り値配列代入を回帰確認している。
