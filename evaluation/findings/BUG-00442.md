# Likeの無効パターンと空文字パターンを誤処理する

`[Z-A]`と未閉鎖の`[ABC`が、VBAのInvalid pattern string (Error 93)ではなく通常のFalseとして
処理される。また、VBA仕様で空文字列を表す`[]`が、空文字列との一致にならない。現在は未修正であり、
有効な文字クラス構文を維持したパターン検証と回帰テストが必要である。
