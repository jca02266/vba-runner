# Likeの無効パターンがError 93にならない

`[Z-A]`、未閉鎖の`[ABC`、空クラスの`[]`と`[!]`が、VBAのInvalid pattern
string (Error 93)ではなく通常のFalseとして処理される。現在は未修正であり、
有効な文字クラス構文を維持したパターン検証と回帰テストが必要である。
