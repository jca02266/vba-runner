# DateDiff時間intervalの境界カウント不一致

`DateDiff("h", "00:00:01", "00:59:59")` はVBAの単位境界数では0ですが、
runnerは経過時間を丸めて1を返す。同様に、`00:59:59`から`01:00:00`の
`DateDiff("h")`はVBAでは1だがrunnerは0を返す。`n`でも同じ境界差がある。

直接原因は、時間系intervalを単位境界へ切り捨てた日時の差ではなく、経過ミリ秒の
`Math.round`で計算していたこと。両端を単位境界へ投影する実装と回帰マトリクスで
h/n/sの正逆方向を修正した。DSTは別候補として未解決である。
